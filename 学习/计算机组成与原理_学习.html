📖 故事线：把电脑当「一家工厂」

零基础学组成原理，先建立地图：电脑像一家工厂——控制器是厂长（发指令）、运算器是车间（算数）、存储是仓库（放料）、输入输出是收发室。9 个模块从“工厂全貌”一路拆到“拧螺丝排故障”，再把数据库、安全、布线收尾，98 题全拿下。

① 总体组成五大部件、裸机、外围设备
② 数据表示进制、原反补、运算、Hash
③ CPU取指执行、寻址、汇编
④ 存储Cache、内存、磁盘、BIOS
⑤ 数据结构栈、队列、广义表
⑥ 组装维护装机、保养、排错
⑦ 数据库SQL 格式化、注入
⑧ 安全防火墙、溢出、Rootkit
⑨ 布线备份线缆认证、海量备份
生活类比：工厂（电脑）= 厂长发单（控制器）+ 车间干活（运算器）+ 仓库存取（存储器）+ 收发室（I/O）。厂长看“生产计数本”（程序计数器）决定下一步做啥；热门料放手边小货架（Cache）不用每次跑大仓（内存）。

1 模块1 计算机系统总体组成（从宏观认识电脑）

电脑不是一块铁，而是“五大部件”协同的机器。先建立全局观，后面再拆到零件。

2 模块2 数据的表示与运算（电脑怎么“数数”）

电脑只认 0/1。人写的十进制、画的图，都要转成二进制与编码。本模块讲进制、原反补码、运算与摘要。

Q24. 十六进制92H的八进制表示为()。
▸ 显示解析
🎯 答案解析：选 B。92H=10010010₂，三位一组 010 010 010＝222₈。📚 知识点讲解：十六→二→八：每 1 位十六进制＝4 位二进制，每 3 位二进制＝1 位八进制。92H=1001 0010，从右分组 010/010/010=222。💡 解题思路：先转二进制再三位一组→222→选 B。🧠 记忆口诀：“十六转八先转二，三位一组 222。”
Q12. 设机器字长为8,则-0的()表示为11111111。
▸ 显示解析
🎯 答案解析：选 A。8 位中 −0 的反码＝11111111（原码取反符号位不变）。📚 知识点讲解：反码里 +0=00000000、−0=11111111（两种 0）；补码里 0 唯一全 0。原码 −0=10000000。💡 解题思路：−0 全 1 是反码特征→选 A。🧠 记忆口诀：“反码负零全是一，补码零唯全零。”
Q23. 机器字长为8位，定点整数X的补码用十六进制表示为B6H, 则 其反码用十六进制表示为()。
▸ 显示解析
🎯 答案解析：选 D。B6H=10110110（负数）。反码＝补码−1＝10110101＝B5H。📚 知识点讲解：负数补码=反码+1，故反码=补码−1。B6H−1=B5H。注意符号位不变。💡 解题思路：负数反码=补码减一→B6H−1=B5H→选 D。🧠 记忆口诀：“负补减一得反码，B6 变 B5。”
Q27. 表示定点数时，若要求数值0在机器中唯一地表示为全0,应采 用()。
▸ 显示解析
🎯 答案解析：选 B。补码中 0 只有一种表示（全 0），+0 和 −0 统一。📚 知识点讲解：原码、反码都有 +0 和 −0 两种（如原码 0000 与 1000）；补码把 −0 并入，0 唯一全 0，简化判别。💡 解题思路：“0 唯一全 0”是补码特征→选 B。🧠 记忆口诀：“补码零唯一，全零最干净。”
Q2. 在定点二进制运算中，减法运算一般通过()来实现。
▸ 显示解析
🎯 答案解析：选 D。减法用“补码加法器”实现：把减数取补码，减法变加法。📚 知识点讲解：计算机只有加法器最省事。定点减法 = 被减数 +（减数补码），溢出等由加法器统一处理，所以硬件只需加法器。💡 解题思路：记住“减法靠补码转加法”，对应补码加法器。🧠 记忆口诀：“减法变加法，补码来当家。”
Q3. 机器字长确定后，()运算过程中不可能发生溢出。
▸ 显示解析
🎯 答案解析：选 C。两负整数相减（X−Y，X、Y 均负）结果不会超出负数范围，不会溢出。📚 知识点讲解：溢出发生在“正+正得负”或“负+负得正”。负−负 = 负+正，结果仍落在可表示区间，故不溢出。💡 解题思路：负减负等于负加正，符号不会翻反→不溢出，选 C。🧠 记忆口诀：“负减负=负加正，符号不翻不溢出。”
Q7. 散列 ( Hash) 算法是()。

🎯 答案解析：选 A。Hash 把任意长度输入映射成固定长度摘要。📚 知识点讲解：Hash（散列）用于快速查表、数字签名、去重。无论原文多长，摘要长度固定（如 MD5 128 位、SHA-256 256 位）。💡 解题思路：关键词“任意→固定”→选 A。🧠 记忆口诀：“Hash 任意进，定长出。”

Q8. ()是采用一系列计算机指令来描述一幅画的内容。

3 模块3 CPU 组成与指令执行（电脑的“大脑”怎么干活）

CPU = 运算器 + 控制器。它取指令、译码、执行，靠程序计数器指路，靠加法器算数。

Q4. CPU中不包括()。
▸ 显示解析
🎯 答案解析：选 A。DMA 控制器不在 CPU 内，它是独立的总线部件，负责外设与内存直接搬运数据。📚 知识点讲解：CPU 内含运算器（算逻单元 ALU）、控制器（程序计数器 PC、指令译码器、指令寄存器）。DMA 控制器是芯片组/外设侧的独立硬件。💡 解题思路：DMA 是直接存储器访问控制器，属外设总线部件，不在 CPU→选 A。🧠 记忆口诀：“DMA 在 CPU 外，直接搬数据。”
Q15. 下列部件中属于CPU中算术逻辑单元的部件是()。
▸ 显示解析
🎯 答案解析：选 B。加法器属算术逻辑单元（ALU），做加减等运算。📚 知识点讲解：ALU 是运算器核心，含加法器、逻辑门。PC、指令寄存器、译码器都属控制器，不在 ALU。💡 解题思路：ALU 干算术→加法器是它的人→选 B。🧠 记忆口诀：“ALU 算数，加法器在内。”
Q19. CPU中用于暂时存放操作数和中间运算结果的是()。
▸ 显示解析
🎯 答案解析：选 C。累加器（ACC）暂存操作数与中间结果。📚 知识点讲解：运算时操作数送累加器，ALU 算完结果也回累加器。数据寄存器（DR）暂存内外交换数据，指令寄存器存指令，PC 存地址。💡 解题思路：“暂存运算中间结果”＝累加器→选 C。🧠 记忆口诀：“累加器，中间结果暂存处。”
Q5. CPU 执行指令时，先根据()的内容从内存读取指令，然后译码并 执行。
▸ 显示解析
🎯 答案解析：选 B。取指令靠 程序计数器（PC） 指出下一条指令地址。📚 知识点讲解：指令周期＝取指→译码→执行。PC 自动指向下一条要取的指令地址；指令取到后暂存于指令寄存器（IR）；地址寄存器存操作数地址。💡 解题思路：“先读指令”靠 PC 给出地址→选 B。🧠 记忆口诀：“取指令，PC 指路。”
Q6. 直接转移指令执行时，是将指令中的地址送入()。
▸ 显示解析
🎯 答案解析：选 D。转移（跳转）指令把目标地址送入 程序计数器 PC，下一条就跳去那里执行。📚 知识点讲解：PC 决定执行流向。转移/调用/循环都靠改写 PC 实现；累加器存运算结果，地址寄存器存数据地址，都不是跳转目标。💡 解题思路：跳转改变执行地址→改写 PC→选 D。🧠 记忆口诀：“跳转改流向，地址送 PC。”
Q17. 在指令中，操作数地址在某寄存器中的寻址方式称为()寻址。
▸ 显示解析
🎯 答案解析：选 D。操作数地址放在寄存器里→寄存器间接寻址。📚 知识点讲解：直接寻址＝地址直接在指令中；寄存器寻址＝操作数本身在寄存器；寄存器间接＝寄存器里存的是“地址”，再去内存取数。💡 解题思路：寄存器里装的是“地址”而非“数”→间接→选 D。🧠 记忆口诀：“寄存器装地址，间接去取数。”
Q16. ()不属于按照寻址方式命名的存储器。
▸ 显示解析
🎯 答案解析：选 A。读写存储器按“存取方式”命名，不是按“寻址方式”。📚 知识点讲解：按寻址方式分：随机存储器（RAM，任意地址直取）、顺序存储器（磁带，顺序找）、直接存储器（磁盘，先直寻区再顺序）。读写是按是否可读可写分。💡 解题思路：随机/顺序/直接都带“寻址”含义，读写不是→选 A。🧠 记忆口诀：“寻址三兄弟：随机、顺序、直接；读写另分类。”
Q20. 在计算机系统中，除了机器语言，()也称为面向机器的语言。
▸ 显示解析
🎯 答案解析：选 A。汇编语言与机器指令一一对应，是面向机器的低级语言。📚 知识点讲解：机器语言是二进制指令；汇编用助记符（如 MOV、ADD）代替，仍直接操控硬件，贴近机器。高级语言（C/Python/SQL）面向问题不直接管硬件。💡 解题思路：除机器语言外，汇编最贴硬件→选 A。🧠 记忆口诀：“汇编贴机器，助记符代替二进码。”

4 模块4 存储系统（数据放哪儿、多快）

存储分层次：寄存器→Cache→内存→外存。BIOS 是开机第一棒，固件固化其中。

Q11. 在高速缓冲存储器(Cache)- 主存层次结构中，地址映像以及和 主存数据的交换由()完成。
▸ 显示解析
🎯 答案解析：选 A。Cache 与主存的地址映射、数据交换由硬件（Cache 控制器）自动完成。📚 知识点讲解：Cache 对程序员透明，全部由硬件电路管理，速度极快；不需要软件干预，也不靠中断。💡 解题思路：Cache 透明且快→硬件自动管→选 A。🧠 记忆口诀：“Cache 映射靠硬件，透明又快。”
Q25. 在 CPU 和主存之间设置"Cache" 的作用是为了解决()的问题。

🎯 答案解析：选 BCD。IN 可等价 OR（empno IN(7782,7876)）；而 BETWEEN（连续范围）、LIKE（模糊匹配）、AND（且，语义不同）都不能替代该 OR。📚 知识点讲解：OR 表示“或”，IN(7782,7876) 完全等价；BETWEEN 7782 AND 7876 是连续区间、LIKE 是模式匹配、AND 是要同时满足，均不等价。💡 解题思路：只有 IN 能替 OR，其余不能→选 BCD。🧠 记忆口诀：“OR 同功用 IN，BETWEEN/LIKE/AND 都不行。”
Q32. 下列代码中，当()时，将造成 SQL 注入。select id from users where username='"+username+"'and password='"+password+"';
▸ 显示解析
🎯 答案解析：选 B。注入 'or'1'='1 使条件恒真，绕过密码验证。📚 知识点讲解：拼接 SQL 时用户输入未转义，' 闭合原字符串，or '1'='1' 让 where 永远成立，于是无需密码也能登录。这是最经典的 SQL 注入。💡 解题思路：要“恒真绕过”→ or '1'='1'→选 B。🧠 记忆口诀：“SQL 注入 'or'1'='1'，条件恒真门大开。”

Q31. 防火墙是指()。
▸ 显示解析

Q33. 应按照对业务服务的重要次序来指定()分配优先级别，保证在网络 发生拥堵的时候优先保护重要主机。
▸ 显示解析
🎯 答案解析：选 D。网络拥堵时按重要次序分配 带宽 优先级（QoS）。📚 知识点讲解：带宽/网络带宽是网络拥塞时的稀缺资源，QoS（服务质量）给重要业务更高带宽优先级。CPU/内存是主机资源，非网络拥堵对象。💡 解题思路：“网络拥堵”→网络资源带宽→选 D。🧠 记忆口诀：“网络拥堵保重要，带宽优先级先调。”

🃏 速查卡：一张表背完核心考点

必背清单

  • 五大部件：运算器、控制器、存储器、输入、输出；CPU＝运算器+控制器
  • 运算速度：MIPS（每秒百万指令）
  • 减法：补码加法器（减法变加法）
  • 取指/跳转：程序计数器 PC 指路
  • 原反补：−0 反码全 1；补码 0 唯一全 0；负数反码＝补码−1
  • Cache：硬件管映射，解 CPU↔内存速度差；SRAM 快贵不刷、DRAM 慢便宜要刷
  • 存储单位：字节 Byte 为基本单位
  • 栈/队列：栈先进后出（反序）、队列先进先出（保序）
  • BIOS：ROM 固化，含 POST/CMOS Setup/自举；CMOS 才靠电池
  • SQL 注入：'or'1'='1 恒真绕过
  • 防火墙：网络边界守门员
  • 缓冲区溢出：危险但非“一定”被利用
  • 固件：固化不可随意动态改写
