① IP地址是什么：网络世界的"家庭住址"

目标：理解 IP 地址的作用、结构（网络号+主机号），以及配错地址会发生什么。

1.1 什么是 IP 地址

IP 地址（Internet Protocol Address）是联网设备在网络中的唯一编号，就像每部手机有唯一手机号、每家每户有唯一家庭住址。数据包要在网络中找到目标设备，就必须依靠 IP 地址来"寻址"。

我们 currently 最常用的 IPv4 地址由 32 个二进制位组成，为了好记，把它分成 4 段（每段 8 位），每段转成十进制，段与段之间用点隔开，这叫点分十进制。例如 192.168.10.1。

类比：32 位二进制就像一长串 32 个数字的身份证号，太难读。于是我们把它"4 段分组 + 十进制"，就像把一长串身份证号分段写成"省-市-县-序号"，人看一眼就懂。
例子：11000000.10101000.00001010.00000001（二进制）= 192.168.10.1（点分十进制）。每段 8 位，最大值 255（二进制 11111111）。

1.2 IP 地址的两段结构：网络号 + 主机号

一个 IP 地址由两部分组成：

  • 网络号（网络地址段）：标识"设备在哪一个网络/哪一片小区"。同一网络内的设备，网络号相同。
  • 主机号（主机地址段）：标识"这个网络里的具体哪一台设备/哪一户"。
类比：IP 地址 = "北京市朝阳区建国路 88 号"。网络号相当于"北京市朝阳区建国路"（整片小区的位置），主机号相当于"88 号"（具体的某一户）。邮递员先按"路"找到小区，再按"门牌"找到你家。
例子：在 192.168.10.1 中，如果约定前 3 段是网络号，则网络号 = 192.168.10，主机号 = 1。同网络的其他设备可能是 192.168.10.2、192.168.10.3……它们的网络号都一样。
记忆点：考试常考这句话——"IP 地址由网络号和主机号两部分组成"，这是正确的（题库第 14、28 题都考到）。进阶时还会细分为"网络号 + 子网号 + 主机号"三段（见模块④⑤）。

1.3 两台设备配了同一个 IP 会怎样？

IP 地址要求同一网络中唯一。如果同一网段两台工作站配置了相同 IP，就会发生地址冲突：双方都会收到冲突警告，但先上线（先入网）的那台能继续工作，后上线（后入网）的那台无法正常工作。

例子：就像两户人家同时挂了"88 号"门牌，邮递员不知道该把信送谁家；物业（系统）会报警，先搬进来的那户暂且能用，后搬进来的被拦在门外。

  • B. 双主都不能工作，都得到网址冲突的警告

② IP地址分类：A、B、C、D、E 五类

目标：看到任意 IP 的首字节，能判断它是哪一类；知道 D 类用于组播。

2.1 五类地址怎么分

IPv4 按"首字节（第一段）的范围"把地址分成五类。分类的本质是看前几位二进制是什么：

类别首字节范围首字节二进制开头网络/主机位用途
A 类1 – 1260……（第1位为0）网络8位 / 主机24位大型网络
B 类128 – 19110……网络16位 / 主机16位中型网络
C 类192 – 223110……网络24位 / 主机8位小型网络
D 类224 – 2391110……（无网络/主机之分）组播 Multicast
E 类240 – 2551111……—保留/科研
类比：就像电话号码分"手机号/固话/特服号"。以 110 开头的是报警特服，以 138 开头的是移动手机号——IP 地址靠"开头几位"判断类别，规律一模一样。
例子：192.168.1.1 首字节 192，落在 192–223，且二进制 11000000 以 110 开头 → C 类。10.0.0.1 首字节 10 → A 类。230.1.1.1 → D 类组播。
易错点（题库第 14 题）：题干说" C 类 IP 地址的第一个八位段以 100 起始"——这是错误的！C 类是 110 开头（192），不是 100。A 类是"第1位为0"，所以可变的网络号位数是 7 位（首位固定为0），这个说法是对的。

2.2 D 类地址 = 组播地址

D 类地址（224–239）通常作为组播地址，用于"一对多"通信（一份数据同时发给一组接收者），不是某台具体主机地址。

例子：视频会议把画面同时发给会议室里所有人，就适合用组播地址，而不是挨个单播。

③ 私有地址 vs 公有地址

目标：能区分哪些 IP 能上公网、哪些只能在局域网里用；看到地址能判断它能否在因特网路由。

3.1 什么是私网 / 公网地址

互联网上的公有（公网）IP 需要向机构统一申请、全球唯一，才能直接在因特网中被路由（找到）。而 RFC 1918 预留了三段私有（私网）地址，专门给企业内部、家庭局域网自由使用，不能直接通过 Internet 访问（出网要靠 NAT 转换）：

私网地址段范围说明
10.0.0.0/810.0.0.0 – 10.255.255.255大型私网
172.16.0.0/12172.16.0.0 – 172.31.255.255中型私网
192.168.0.0/16192.168.0.0 – 192.168.255.255家庭/小型私网（最常见）
类比：公网 IP 像"能在全国寄信的真实门牌号"；私网 IP 像"小区内部自编号"（比如3栋2单元501），出了小区别人不认，必须换成真实门牌（公网IP）才能寄到外面。
例子：192.168.0.55、10.172.13.44、172.16.223.15 都是私网地址，不能在因特网直接路由；198.215.43.254 不在上述三段内，是公网地址，可以路由。
易错点（题库第 8/37 题）：私网地址的特点不是"必须向 IANA 申请"（恰恰相反，私网不用申请）、也不是"通过 DHCP 分配"（DHCP 只是分配方式之一）。它的本质是"不能通过 Internet 访问"。

④ 特殊 IP 地址：网络地址、广播、回环

目标：分清哪些地址"不能作为普通主机地址"，以及广播地址的判定规则。

4.1 主机位全 0 = 网络地址；主机位全 1 = 广播地址

在一个网络里：

  • 网络地址：主机号（主机位）全为 0，代表"整个这个网络"，不能分配给某台具体设备。
  • 广播地址：主机号（主机位）全为 1，代表"发给本网络内所有设备"，也不能作为单台主机地址。
类比：小区里"0 栋"代表整个小区（网络地址），"999 栋"代表向全小区广播喊话（广播地址），这两栋都不是某户人家能住的真门牌（主机地址）。
例子：在 192.168.1.0/24 这个网络里，主机位是最后 8 位。192.168.1.0（主机全0）= 网络地址；192.168.1.255（主机全1）= 广播地址。真正能分给电脑的是 192.168.1.1 ~ 192.168.1.254，共 254 个。
口诀："全0是网络，全1是广播，两头不能当主机"。所以一个网络里可用主机数 = 2^主机位数 − 2（减去全0和全1）。

4.2 回环地址 127.x：本机自检专用

127.0.0.0/8（常见 127.0.0.1）是回环（Loopback）地址，永远指向"本机自己"，用于网络软件自检。它不是任何对外通信的主机地址。

例子：你在自己电脑上 ping 127.0.0.1，是在测本机 TCP/IP 协议栈是否正常，不会真的发到网络上。127.0.10.1 也属于 127 段，不能作主机地址。
补充：还有 0.0.0.0（表示"本机所有地址/默认"）和 169.254.x.x（DHCP 失败自动配置的链路本地地址），考试也可能碰到，先记住"它们都不是普通可用的主机地址"即可。

⑤ 子网掩码：如何"切"出网络号和主机号

目标：懂掩码的作用与正确写法；会用掩码判断"哪些地址是有效主机地址"；会算可用主机数。

5.1 子网掩码是什么、怎么写才对

子网掩码（Subnet Mask）用来告诉设备：IP 地址里哪几位是网络号、哪几位是主机号。规则是：

  • 掩码里，对应"网络位"的位置全部写 1；
  • 掩码里，对应"主机位"的位置全部写 0。

所以它本身也是一个 32 位数，长相类似 IP（如 255.255.255.0）。255 = 二进制 8 个 1，表示这一段全是网络位。

类比：掩码像一把"尺子"——尺子上标 1 的地方量的是"省市（网络）"，标 0 的地方量的是"门牌（主机）"。没有这把尺子，光看 IP 不知道哪部分是网络。
例子：192.168.10.1 配掩码 255.255.255.0，表示前 3 段（24 个 1）是网络号 192.168.10，最后 1 段（8 个 0）是主机号。也可简写为 192.168.10.1/24，"/24" 就是"掩码有 24 个 1"。
易错点（题库第 3 题）："子网掩码设置正确的是——对应于网络地址的所有位都为 1"。选项里"网络位为0""主机位为1"都是错的。记住：网络位=1，主机位=0。

5.2 用掩码判断"有效主机地址"

判断一个地址在某掩码下是否可作有效主机地址，就两步：

  1. 先按掩码求出它所在网络的网络地址（主机位全0）和广播地址（主机位全1）；
  2. 该地址只要既不是网络地址、也不是广播地址，就是有效主机地址。
例子（题库第 36 题）：掩码 255.255.255.240（即 /28，最后一段 240=11110000，主机位 4 位）。块大小 = 2^4 = 16，所以每段主机范围按 16 个一组划分：0–15、16–31、32–47、48–63、64–79、80–95、96–111……
对选项 B 92.11.178.93：只看最后一段 93，它落在 80–95 组 → 网络地址是 80，广播是 95，93 既不是 80 也不是 95 → 是有效主机地址。
A ...63：63 是 48–63 组的广播地址 → 不行；C ...159：159 是 144–159 组的广播 → 不行；D ...192：192 是 192–207 组的网络地址 → 不行。
因此只有 B 正确。（注：题库原文把掩码误写成 244，244 不是合法连续掩码；按能得出答案 B 的标准 /28=240 讲解，特此说明。）

5.3 可用主机数计算

掩码决定主机位数 h。可用主机数 = 2^h − 2（减去网络地址和广播地址）。

例子（题库第 1 题）：网络 192.168.10.0/24，主机位 8 位 → 可用主机 = 2^8 − 2 = 254 个。选项中 256 是"没减2"的典型干扰项，要当心。
速查：/24→254，/25→126，/26→62，/27→30，/28→14，/29→6，/30→2（常用于点对点链路）。

⑥ 网络 ID 与网段判断：IP 属于哪个网络？

目标：掌握"IP AND 掩码求网络号"和"块大小/步长法"，能判断地址归属、写出网络 ID。

6.1 什么是网络 ID（网络号）

网络 ID就是"把主机位全部置 0 后得到的那个网络地址"。判断两个 IP 是否在同一网段，就看它们的网络 ID 是否相同。

6.2 块大小（步长）法——最快的判断技巧

把掩码写成 /n 后，看"最后一个被掩码覆盖的字节"里有几位主机位，块大小 = 2^主机位数。网络的起始地址一定是块大小的整数倍。只需要用"目标字节值 ÷ 块大小，向下取整 × 块大小"就能得到网络起点。

例子（题库第 39 题）：地址 220.117.123.7/20。/20 = 前 20 位网络：前两字节(16位)+第3字节高4位。第3字节有 4 位主机位 → 块大小 = 2^4 = 16。123 ÷ 16 = 7 余 11，向下取整 7，起点 = 7×16 = 112。所以网络 ID = 220.117.112.0/20。
为什么是 /20 不是 /21？题目问的是"所属的网络 ID"，网络位必须保持 /20（不能缩短成 /21）。所以答案锁定 220.117.112.0/20，选 B。

6.3 判断"某地址属于哪个网段"

同一思路：先确定块大小，再看目标地址落在哪个块区间内。

例子（题库第 34 题）：网络 202.15.200.0/21。/21：第3字节有 3 位主机位 → 块大小 = 2^3 = 8。200 ÷ 8 = 25 余 0 → 起点 200，该网段覆盖 200–207（即 202.15.200.0 ~ 202.15.207.255）。
选项：A 202.15.198.0（在 192–199 块，❌）；B 202.15.206.0（在 200–207 块，✅）；C 202.15.217.0（216–223，❌）；D 202.15.224.0（224–231，❌）。故选 B。
小块速查：/21→块8；/20→块16；/19→块32；/22→块4（在第3字节）。记不住就现场算 2 的几次幂。

⑦ CIDR 与超网汇聚：把多个网络"合并"

目标：理解 CIDR 的 /n 写法；会做"把几个连续 C 类网络聚成一个大网（超网）"的题目；知道 VLSM。

7.1 CIDR 是什么

CIDR（无类别域间路由）用"IP/n"表示法取代死板的 A/B/C 分类，让网络划分更灵活、地址分配更省。其中的 /n 就是"掩码中 1 的个数"。

例子：192.168.0.0/22 表示掩码 255.255.252.0，主机位 10 位，可容纳 2^10=1024 个地址。比硬套 C 类（/24）更灵活。

7.2 超网（路由汇聚）：把连续的小网合成一个大网

当多个连续且对齐的小网络（如几个 C 类 /24）聚在一起时，可以合并成一个更大的网，减少路由表条目，这叫超网（路由汇聚）。算法就是"找它们二进制前多少位是相同的"，相同位数就是新的 /n。

例子 1（题库第 9 题）：4 个连续 C 类 /24 合并。4 = 2^2，相当于把主机位再借 2 位给网络 → 新前缀 = 24−2 = /22。答案 B。
例子 2（题库第 38 题）：把 158.15.12.0/24 和 158.15.15.0/24 汇聚。第3字节 12=00001100、15=00001111，前 6 位相同（000011），即第3字节有 6 位网络位 → 总前缀 16+6 = /22，网络起点 12 → 158.15.12.0/22。答案 B。（注：题库原文首网段被截断，按答案为 /22 反推应为 12.0/24 段。）
规律：合并 k 个连续 /24（k=2^m），结果前缀 = 24−m。2个→/23，4个→/22，8个→/21，16个→/20。

7.3 VLSM：可变长子网掩码

VLSM（Variable Length Subnet Mask）允许同一个主网络下使用不同长度的掩码来划不同大小的子网，提高地址利用率。

例子：一个 /24 网络，给有 50 台的主机群分配 /26（62地址），给点对点链路分配 /30（2地址），这就是 VLSM。
易错点（题库第 12/41 题）：RIPv2 相比 RIPv1 新增的重要特性就是支持可变长度子网掩码（VLSM）。RIPv1 是有类、不支持 VLSM 的。

⑧ IPv6 与相关技术串联（NAT / DNS / DHCP / 防火墙）

目标：了解 IPv6 基础；把 NAT、DNS、DHCP、防火墙等"围绕 IP 地址工作"的技术串起来，正好覆盖题库剩余考点。

8.1 IPv6 基础

IPv4 地址只有 32 位，约 43 亿个，早已不够用。IPv6 把地址扩大到 128 位，数量近乎无限。

  • IPv6 地址长度 = 128 位（题库第 30 题答案 C）。
  • 组播地址：格式前缀 11111111（即 FF00::/8，题库第 6/35 题答案 D）。
  • 可聚合全球单播地址：格式前缀 001（题库第 13/42 题答案 C）。
  • 无状态自动配置：主机把自己的 MAC 地址附加到网络前缀后面，自动生成链路本地地址（题库第 4/32 题答案 B）。
类比：IPv4 像老式 8 位座机号（位数少、不够分）；IPv6 像加了国际区号+超长分机的号码，空间大到给地球上每粒沙子分配都够。

8.2 NAT：让私网主机共享公网 IP 上网

NAT（网络地址转换）把局域网内的私网地址，在出口路由器上转换成公网地址再访问外网，既节省了公网 IP，又隐藏了内部拓扑（"隐私保护"）。

  • 工作原理：地址绑定 → 地址查找与转换 → 地址解绑定（题库第 25 题判断"正确"）。
  • 缺点：报文 IP 头被改动，含 IP 的信息不能被加密；调试更困难；高速链路上有性能开销。但它不会去改数据部分里包裹的 IP 文本（题库第 27 题选"说法错误"的 D）。
  • 反向 ARP（RARP）：用已知的 MAC 地址去查对应的 IP 地址（题库第 29 题判断"正确"）。

8.3 DNS：为什么"IP 能访问、域名不能访问"

我们输入的是域名（如 www.xxx.com），电脑要先问 DNS 服务器把域名翻译成 IP。如果"用 IP 能访问、用域名不能访问"，说明问题出在域名解析环节：本机 DNS 设置错误、本地 DNS 服务器故障或断网都会导致。但"本机与 DNS 服务器是否在同一子网"并不是原因——DNS 服务器可以跨网段（只要路由可达）。

例子（题库第 11/40 题）：问"原因不包括"哪一项 → 答案 C（不在同一子网）。A、B、D 都是 DNS 解析故障的典型原因。

8.4 DHCP：自动发 IP 与"地址池"

  • 客户机若请求一个非法或重复的 IP，DHCP 服务器回 DHCP NAK 拒绝，逼它重新获取合法地址（题库第 20 题多选答案 CD）。
  • 地址池 = 作用域里"可分配"的 IP 范围。它要排除的不仅是"保留地址"，还有"排除范围"，所以"地址池就是作用域除保留外剩余的 IP"这种说法不完整、错误（题库第 43 题判断"错误"）。

8.5 防火墙与 IP：网络边界的守门人

  • 防火墙建在内部网络与外部网络的交界处（题库第 2 题答案 C）。
  • 它应支持"除许可外拒绝所有"策略、能按 IP 过滤、能审计、能提供 NAT 隐藏内网（题库第 19 题多选 ABCD 全对）。
  • 防火墙不能查杀病毒（那是杀毒软件/IDS 的事），题库第 26 题选"错误"的 B。
  • 路由器依据网络地址（路由表）转发数据（题库第 23 题答案 D）。
  • VPN 能提供访问控制、数据加密、身份认证，但不负责划分子网（题库第 18 题多选 ABC）。
