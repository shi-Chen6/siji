## 模块一 网络与局域网基础

### 知识点 1.1　什么是网络？局域网、城域网、广域网怎么分？

**一句话理解**
计算机网络就是把多台电脑（和设备）用「线」连起来，让它们能互相传数据。根据「覆盖范围有多大」，网络分成三兄弟：

| 类型 | 英文 | 覆盖范围 | 生活类比 |
|------|------|----------|----------|
| 局域网 | LAN | 一栋楼、一个公司、一个校园内（小范围） | 公司内部的内部电话网 |
| 城域网 | MAN | 一座城市 | 全市的公交调度系统 |
| 广域网 | WAN | 跨城市、跨国、全球（互联网就是最大的广域网） | 全国/全球的移动电话网 |

> 题库原话：「区分局域网、城域网和广域网是以接入的计算机之间的距离来定义的。」—— ✓ 正确。距离（覆盖范围）就是划分标准。

**生活类比**
把网络想象成「朋友圈」：
- 局域网 = 你家和邻居组成的「小区群」，人少、消息秒回；
- 城域网 = 整个城市的「业主大群」；
- 广域网 = 全世界的「微信」，人超多、靠运营商中转。

**详细讲解**
- 局域网（LAN）一般为一个单位所建、自己管理，比如公司办公室网络、家里 WiFi。
- 广域网（WAN）比如互联网，连接各不相同的地方。
- 「无线广域网（WWAN）」是用蜂窝移动网络（4G/5G）让设备在任何有信号的地方上网，不是 WiFi。

**📌 考点自测**

**题目（对应题库 Q24 / Q40 / Q42）**
- 【多选】按照网络覆盖范围的大小来划分，可以分为（　）。
  A. 城域网　B. 局域网　C. 全球网　D. 广域网
- 【判断】区分局域网、城域网和广域网是以接入的计算机之间的距离来定义的。（　）
- 【单选】下列不属于有线传输的是（　）。
  A. 双绞线　B. 光纤　C. 超五类双绞线　D. 电磁波

**解析**
- **🎯 答案解析**：Q24 答案 **ABD**（标准分类是局域/城域/广域，没有「全球网」这种标准说法）；Q40 答案 **正确**；Q42 答案 **D**（电磁波是无线传输，双绞线/光纤/超五类都是「有线」）。
- **📚 知识点讲解**：网络按覆盖范围分 LAN/MAN/WAN 三类；传输介质分「有线」（双绞线、同轴电缆、光纤）和「无线」（电磁波、无线电）。
- **💡 解题思路**：排除法——「全球网」不是规范术语，排除 C；电磁波看不见摸不着、靠空气传播，明显不是「有线」传输。
- **🧠 记忆口诀**：「局城广，按距离；有线线，无线波。」

### 知识点 1.2　局域网有什么特点？

**一句话理解**
局域网是「小圈子高速网」：地方小、速度快、出错少、单位自己建。

**详细讲解（对应题库 Q28）**
局域网的特点（标准答案 ABD）：
- **A. 较少的地域范围**——就一小块地方；
- **B. 高传输速率和低误码率**——因为线短，信号衰减小，所以又快又准；
- **D. 一般为一个单位所建**——公司、学校自己掏钱自己管。
- 选项 C「一般侧重共享位置准确无误及传输的安全」不是局域网的典型特点，排除。

**生活类比**
局域网像公司食堂的内部广播：广播范围只在大楼里（地域小）、喊一声大家立刻听见（高速低误码）、是公司自己装的（单位自建）。

**📌 考点自测**

**题目（对应题库 Q28）**
- 【多选】属于局域网的特点有（　）。
  A. 较少的地域范围　B. 高传输速率和低误码率
  C. 一般侧重共享位置准确无误及传输的安全　D. 一般为一个单位所建

**解析**
- **🎯 答案解析**：**ABD**。
- **📚 知识点讲解**：局域网三特征 = 地域小 + 高速低误码 + 单位自建。
- **💡 解题思路**：C 说的是「位置准确、传输安全」，这是特定系统的要求，不是局域网普遍特点，排除。
- **🧠 记忆口诀**：「局域三特征：地小、速高、自己建。」

### 知识点 1.3　传输介质总览：有线 vs 无线

**一句话理解**
传输介质 = 数据走的「路」。有线的「路」是实实在在的线（双绞线、同轴电缆、光纤）；无线的「路」是空气里的电磁波。

**详细讲解（对应题库 Q34）**
局域网的传输介质主要包括：**光纤、双绞线、同轴电缆**（答案 ACD）。注意「数据线」是个笼统词，不是标准分类，不入选。

**生活类比**
- 双绞线 = 家里拧在一起的电话线；
- 同轴电缆 = 早年有线电视那根粗线；
- 光纤 = 玻璃/塑料做的「光管」，里面跑光信号；
- 电磁波 = 看不见的无线电，WiFi、手机信号都靠它。

**📌 考点自测**

**题目（对应题库 Q34）**
- 【多选】局域网的传输介质主要包括哪些？（　）
  A. 光纤　B. 数据线　C. 双绞线　D. 同轴电缆

**解析**
- **🎯 答案解析**：**ACD**。
- **📚 知识点讲解**：局域网三大有线介质 = 双绞线、同轴电缆、光纤；「数据线」不是标准术语。
- **💡 解题思路**：B 太宽泛、不专业，排除；其余三个是教材标准答案。
- **🧠 记忆口诀**：「局域介质三兄弟：双绞、同轴、光纤。」

## 模块二 双绞线（最常用有线介质）

> 双绞线（Twisted Pair）是局域网里用得最多的线，就是里面「两根铜线拧成一股」的网线。

### 知识点 2.1　双绞线的类别与速率（CAT3/4/5/5e/6）

**一句话理解**
双绞线按「等级（CAT）」分，等级越高，跑得越快。

| 类别 | 最高速率 | 说明 |
|------|----------|------|
| CAT3 | 10 Mbps | 老式电话/早期网络 |
| CAT4 | 16 Mbps | 较少用 |
| **CAT5** | **100 Mbps** | 常见百兆网（题库考点） |
| CAT5e（超五类） | 1000 Mbps | 千兆，主流 |
| CAT6（六类） | 1000 Mbps+ | 性能更好 |

> 题库原话：「5 类双绞线（CAT5）的最高传输速率为 100 Mbit/s」—— ✓ 正确。

**生活类比**
把双绞线想象成「公路」：CAT3 是乡道（10 码），CAT5 是双向两车道省道（100 码），CAT6 是高速公路（1000 码）。等级越高路越宽、车跑越快。

**详细讲解（对应题库 Q5 / Q36 / Q48）**
- 最大传输速率能达到 100 Mb/s 的双绞线 = **CAT5**（答案 C）。
- CAT6 更快（可达千兆），但它不是「最大能达到 100M」的那一档；CAT3/CAT4 都不到 100M。

**📌 考点自测**

**题目（对应题库 Q5 / Q36 / Q48）**
- 【单选】最大传输速率能达到 100 Mb/s 的双绞线是（　）。
  A. CAT3　B. CAT4　C. CAT5　D. CAT6
- 【判断】5 类双绞线（CAT5）的最高传输速率为 100 Mbit/s。（　）

**解析**
- **🎯 答案解析**：单选 **C**；判断 **正确**。
- **📚 知识点讲解**：CAT5 = 百兆（100M）；CAT5e/CAT6 = 千兆；CAT3 只有 10M。
- **💡 解题思路**：题目问「能达到 100M」的，CAT5 正好卡在 100M；CAT6 虽也能跑 100M 但它是千兆线，考点要的是「百兆代表 = CAT5」。
- **🧠 记忆口诀**：「CAT5 上百兆，CAT6 上千兆。」

### 知识点 2.2　双绞线线序：568A / 568B 与「交叉线」

**一句话理解**
网线里 8 根线有固定颜色顺序。两台电脑**直接**用网线连，线序要「交叉」一下才能通。

**详细讲解**
- **EIA/TIA 568A 线序**（绿白、绿、橙白、蓝、蓝白、橙、棕白、棕）—— 答案 D「绿白绿橙白蓝蓝白橙棕白棕」。
- 标准网线（电脑连交换机）两头都用 **568B**；两台电脑**直连**要用「交叉线」：一头 568A、一头 568B，对应线序就是 **1↔3、2↔6** 交叉。
  - 题库正确线序：**1--3、2--6、3--1、4--4、5--5、6--2、7--7、8--8**（答案 B）。

**生活类比**
像对讲机：A 的「说」要接到 B 的「听」。电脑的「发」脚（1、2）必须接到对方的「收」脚（3、6），所以要把 1↔3、2↔6 对调，这就是交叉线的由来。

**📌 考点自测**

**题目（对应题库 Q23 / Q11）**
- 【单选】EIA/TIA 568A 规定的线序为（　）。
  A. 橙白橙绿白蓝蓝白绿棕白棕　B. 蓝白蓝绿白绿橙白橙棕白棕
  C. 绿白绿橙白蓝蓝白橙棕白棕　D. 绿白绿橙白橙蓝白蓝棕白棕
- 【单选】如果要将两计算机通过双绞线直接连接，正确的线序是（　）。
  A. 1--1、2--2…8--8　B. 1--3、2--6、3--1、4--4、5--5、6--2、7--7、8--8
  C. 1--2、2--1、3--6…　D. 两计算机不能通过双绞线直接连接

**解析**
- **🎯 答案解析**：Q23 **D**（568A = 绿白绿橙白蓝蓝白橙棕白棕）；Q11 **B**（交叉线 1↔3、2↔6）。
- **📚 知识点讲解**：568A 以「绿」开头；两台电脑直连需交叉线（发对接收）。
- **💡 解题思路**：568A 第一根是「绿白」，直接排除 A/B/C（它们分别以橙/蓝/绿白绿橙白橙开头但中间顺序错）；交叉线核心就是 1-3、2-6 对调，锁定 B。
- **🧠 记忆口诀**：「568A 绿带头；电脑直连要交叉（1-3、2-6）。」

### 知识点 2.3　双绞线布线系统与避雷净距

**一句话理解**
实际工程中双绞线分「五类 / 超五类 / 六类」布线系统；而且网线不能离避雷线太近，要隔开 1 米。

**详细讲解（对应题库 Q38 / Q31）**
- 目前网络布线主要有：**五类、超五类、六类**布线系统（答案 ABD）。四类（CAT4）已基本淘汰，不列入主流应用。
- 双绞线与避雷引下线之间的最小平行净距 = **1000 mm（1 米）**（答案 A）。因为避雷线泄放雷电流时产生强电磁场，会干扰网线甚至引入危险。

**生活类比**
网线像怕吵的人，避雷线像打雷时的「大喇叭」。两者不能贴着走，至少隔开 1 米，不然网线「听不清」数据还会被电到。

**📌 考点自测**

**题目（对应题库 Q38 / Q31）**
- 【多选】目前在网络布线方面，主要有几种双绞线布线系统在应用，即（　）。
  A. 五类布线系统　B. 超五类布线系统　C. 四类布线系统　D. 六类布线系统
- 【单选】双绞线与避雷引下线之间的最小平行净距为（　）。
  A. 1000mm　B. 400mm　C. 800mm　D. 600mm

**解析**
- **🎯 答案解析**：Q38 **ABD**；Q31 **A**。
- **📚 知识点讲解**：主流布线 = 五类/超五类/六类；避雷净距 = 1 米（1000mm）。
- **💡 解题思路**：四类早已不用，排除 C；避雷净距是「最小 1 米」，选最大的 A。
- **🧠 记忆口诀**：「布线五四六（5/5e/6）；避雷隔开一米（1000）。」

## 模块三 光纤（高速长距离介质）

> 光纤（Optical Fiber）是用「光」在玻璃/塑料丝里传数据的线，又快又远又抗干扰，就是有点「怕水」。

### 知识点 3.1　光纤通信原理：光的全反射

**一句话理解**
光在光纤里不是直着跑，而是一直「撞壁反弹」往前走，因为发生了「全反射」。

**详细讲解（对应题库 Q22）**
光纤通信的原理主要基于光的 **全反射**（答案 C）。
- 光纤芯子折射率高、外层折射率低，光以合适角度射入后，在界面上全部反射回芯子，不会「漏」出去，于是沿光纤一路传到底。

**生活类比**
把光纤想象成「全镜面的弯水管」：手电筒光从一头打进去，光在水管壁上来回反弹前进，永远跑不出管壁，直到从另一头出来。这就是「全反射」——光被「关」在管里走。

**📌 考点自测**

**题目（对应题库 Q22）**
- 【单选】光纤通信的原理主要基于光的（　）。
  A. 折射原理　B. 散射原理　C. 全反射原理　D. 透视原理

**解析**
- **🎯 答案解析**：**C**（全反射）。
- **📚 知识点讲解**：光纤靠「光在纤芯-包层界面全反射」把光锁在纤芯里传输。
- **💡 解题思路**：折射是拐弯、散射是散开、透视是看穿——只有「全反射」能解释光为啥不跑掉，选 C。
- **🧠 记忆口诀**：「光纤传光靠全反射，光壁反弹不跑掉。」

---

### 知识点 3.2　单模 vs 多模：纤芯粗细与传输距离

**一句话理解**
光纤分两种：单模「细管子、跑得远」；多模「粗管子、跑得近」。

| | 单模（SMF） | 多模（MMF） |
|--|------------|------------|
| 纤芯粗细 | 很细（约 9μm） | 较粗（50/62.5μm） |
| 光源 | 激光 | 发光二极管（LED） |
| 传输距离 | 远（可达几公里，如 5000m） | 近（一般几百米，如 550m） |
| 成本 | 高 | 较低 |

> 题库纠错题：
> - 「单模光纤收发器传输距离远，需要的光纤纤芯稍微比多模的粗」—— ✗ **错误**（单模纤芯更细）。
> - 「多模光纤收发器传输距离远比单模远」—— ✗ **错误**（单模更远）。

**生活类比**
单模像「细吸管吸远距离的水，集中有力」；多模像「粗水管，近处流量大但送不远」。

**详细讲解（对应题库 Q27 / Q35 / Q29）**
- 1000BASE-LX：**单模**光纤可到 **5000 米**；**多模**光纤约 **550 米**（答案 CD：单模5000m、多模550m）。

**📌 考点自测**

**题目（对应题库 Q27 / Q35 / Q29）**
- 【判断】单模光纤收发器传输距离远，需要的光纤纤芯稍微比多模的粗。（　）
- 【判断】多模光纤收发器传输距离远比单模式远。（　）
- 【多选】光纤传输距离正确的是（　）。

### 知识点 3.3　光纤的优缺点：怕水

**一句话理解**

**详细讲解（对应题库 Q43）**

- A 体积大（错，光纤很细很小）；
- D 抗电磁干扰能力弱（错，光纤**最不怕**电磁干扰，因为它是光信号不是电信号）；
- C 成本高——虽也是缺点，但本题题库标准答案选 **B 怕水**（水会导致光纤材料氢损、强度下降）。

**生活类比**
光纤像「怕潮的精密仪器」：别的好处都占全了，就是不能泡水里，一进水就容易坏。

### 知识点 3.5　光纤收发器：光电转换的小盒子

**一句话理解**
光纤收发器（光电转换器）是把「电信号 ↔ 光信号」互相翻译的小设备，让普通网线能借光纤传远。

**详细讲解（对应题库多题）**
- **本质是光电转换**：把以太网电信号变成光信号（发），或把光信号变回电信号（收）——「光纤收发器是电信号和光信号互换的以太网传输媒体转换单元，也称光电转换器」 ✓ 正确（Q13）。
- **工作波长**：一般 **1310 nm 或 1550 nm**。注意：波长数值越大，频率**越低**（λ=c/f），所以「数值越大频率越高」是 ✗ **错误**（Q17）。
- **双纤要区分收/发**：双纤收发器接纤时**需要区分**两条纤（哪条发、哪条收），不能说「不需要区分」—— ✗ **错误**（Q26）。
- **中继延长**：传输距离超过标称距离时，可用 2 台收发器「背对背」中继延长 ✓ 正确（Q7）。
- **光口灯亮 ≠ 收发都正常**：光口工作指示灯亮只说明收到光，不代表收发双向都正常—— ✗ **错误**（Q19）。
- **不控制带宽**：光纤收发器是透明传输设备，**不能控制**用户上网带宽—— ✗ **错误**（Q30）。
- **只接一台电脑也会冲突？**：「光纤收发器只接一台计算机，以太网口不会产生冲突」——题库答案 ✗ **错误**（Q8，以太网口仍处在一个冲突域，接 Hub 等多设备时仍可能冲突；该说法过于绝对）。

**生活类比**
收发器像「翻译官」：中文（电信号）进，翻成外语（光信号）走光纤；另一头再翻回来。两个翻译官「背对背」接力（中继）就能把话传得更远。但翻译官不管你说话快慢（不控带宽），也不保证对方一定听清（灯亮≠双向通）。

**📌 考点自测**

**题目（对应题库 Q13 / Q17 / Q26 / Q7 / Q19 / Q30 / Q8）**
- 【判断】光纤收发器是一种将电信号和光信号进行互换的以太网传输媒体转换单元，也称光电转换器。（　）
- 【判断】光纤收发器工作波长一般是 1310nm 或 1550nm，数值越大表示频率越高。（　）
- 【判断】双纤的光纤收发器在接纤时不需要区分两条纤。（　）
- 【判断】传输距离超过光纤收发器的标称距离时，条件允许的情况下，可采用 2 台收发器背对背进行中继。（　）
- 【判断】光纤收发器光口工作指示灯亮时，说明光纤收发都正常。（　）
- 【判断】光纤收发器可以控制用户上网带宽。（　）

**解析**
- **🎯 答案解析**：Q13 **正确**；Q17 **错误**（波长↔频率反比）；Q26 **错误**（要区分收发）；Q7 **正确**；Q19 **错误**（灯亮仅表收到光）；Q30 **错误**（不控带宽）。
- **📚 知识点讲解**：收发器 = 光电翻译器；波长 1310/1550nm；双纤分收发；可背对背中继；灯亮≠全通；不控带宽。
- **💡 解题思路**：抓住「翻译官」本质——只转换不控制（带宽❌）、要分收发（区分✓）、灯亮只证明收到（≠收发都好）。波长越大频率越小是物理常识。
- **🧠 记忆口诀**：「收发器：电光互转；双纤分收发；灯亮非全通；不控带宽；波长越大频越低。」

### 知识点 3.6　千兆以太网标准：1000BASE-CX / T / LX / SX

**一句话理解**
「1000BASE-XXX」是千兆（1000M）以太网的不同物理层标准，后缀代表「用什么介质、跑多远」。

| 标准 | 介质 | 距离 | 说明 |
|------|------|------|------|
| 1000BASE-T | 非屏蔽双绞线（铜线） | 约 100 m | 普通网线就能上千兆 |
| 1000BASE-CX | 铜缆（双轴电缆） | 约 25 m | 短距离、非无线 |
| 1000BASE-SX | 多模光纤 | 约 550 m | 短波、多模 |
| 1000BASE-LX | 单模/多模光纤 | 单模可达 5000 m | 长波、**支持 >550 m** |

> 题库考点：
> - 支持大于 550 米距离的光纤以太网 = **1000BASE-LX**（答案 C，Q6/Q49）。
> - 正确描述（Q9）：**A** 1000BASE-T 支持非屏蔽双绞线 ✓；**C** 1000BASE-LX 支持单模光纤 ✓；**D** 1000BASE-SX 支持多模光纤 ✓。（B「1000BASE-CX 支持无线」是错的，CX 是铜缆。）

**生活类比**
千兆以太网像「四种快递方式」：T 是普通货车跑短途（网线 100m）、CX 是摩托跑超短（25m）、SX 是省内大巴（多模 550m）、LX 是跨省高铁（单模 5000m，跑最远）。

**📌 考点自测**

**题目（对应题库 Q6 / Q9 / Q49）**
- 【单选】下面的标准中，支持大于 550 米距离光纤以太网的是（　）。
  A. 1000Base-CX　B. 1000Base-T　C. 1000Base-LX　D. 1000Base-SX
- 【多选】关于千兆以太网物理层标准的描述中，正确的有（　）。
  A. 1000BASE-T 支持非屏蔽双绞线　B. 1000BASE-CX 支持无线传输介质
  C. 1000BASE-LX 支持单模光纤　D. 1000BASE-SX 支持多模光纤

**解析**
- **🎯 答案解析**：Q6/Q49 **C**（LX 单模 >550m）；Q9 **ACD**。
- **📚 知识点讲解**：T=双绞线、CX=铜缆（非无线）、SX=多模、LX=单模且最远。
- **💡 解题思路**：问「>550m 的光纤」，SX 多模才 550m 封顶，只有 LX 单模能到几公里；多选里 B 说 CX 支持无线，明显错（CX 是铜缆），排除。
- **🧠 记忆口诀**：「T 双绞、CX 铜、SX 多模、LX 单模最远。」

## 模块四 无线传输

### 知识点 4.1　无线局域网 WLAN（WiFi）

**一句话理解**
无线局域网（WLAN）就是用无线电代替网线，设备通过「接入点（AP）」上网，最典型的就是 WiFi。

**详细讲解（对应题库 Q32 / Q18 / Q39 / Q45）**
- **标准**：WLAN 的 802.11 标准家族有 **a / b / g** 等；**802.11c 不是** WLAN 的常用标准（答案 C，Q32）。
- **自动选 AP**：当客户端进入多个 AP 覆盖范围，会根据「信号强弱 + 误包率」自动选最好的那个 AP 连接 ✓ 正确（Q18）。
- **无线加密方式**：**WEP、WPA、WPA2**（答案 ABD，Q39）。注意 **MD5 是哈希算法，不是无线加密方式**，排除。
- **公共 WIFI 支付风险**：不用公共 WIFI 做支付，是因为**存在个人信息泄露风险**（答案 C，Q45）。

**生活类比**
WLAN 像「无线对讲网络」：多个基站（AP）像对讲机中继台，你的手机自动连信号最好的那台；聊天内容要加密（WEP/WPA/WPA2），不然在公共频道说话会被偷听——所以在公共 WiFi 上别输密码付钱。

**📌 考点自测**

**题目（对应题库 Q32 / Q18 / Q39 / Q45）**

- 【判断】当一个 WLAN 客户端进入一个或者多个接入点的覆盖范围时，它会根据信号的强弱和误包率自动选择一个接入点进行连接。（　）

  A. WEP　B. WPA　C. MD5　D. WPA2
- 【单选】不使用公共 WIFI 进行支付操作，是因为什么（　）。
  A. 公共无线易断开　B. 公共无线网速慢
  C. 存在个人信息泄露的风险　D. 公共无线连接复杂

**解析**
- **🎯 答案解析**：Q32 **C**（802.11c 非 WLAN 标准）；Q18 **正确**；Q39 **ABD**；Q45 **C**。
- **📚 知识点讲解**：WLAN 标准 a/b/g；自动选最强 AP；加密 WEP/WPA/WPA2；公共 WiFi 有泄露风险。
- **💡 解题思路**：802.11c 是桥接相关、不在 WLAN 常用标准里；MD5 是摘要算法不是加密方式；支付题直选「泄露风险」最合理。
- **🧠 记忆口诀**：「WLAN：a/b/g 标准；加密 WEP/WPA/WPA2；公共 WiFi 不付钱。」

### 知识点 4.2　无线广域网 WWAN

**一句话理解**
无线广域网（WWAN）是用手机蜂窝网络（4G/5G）让设备在「大范围、还能移动」时上网。

### 知识点 5.2　光纤布线测试指标

**一句话理解**
光纤布线完工后要「体检」，测几项关键指标；但「近端串扰」是测双绞线的，光纤不测这项。

**详细讲解（对应题库 Q3 / Q46）**
光纤布线系统的测试指标包括：**波长窗口参数、回波损耗、最大衰减**；**不包括近端串扰（NEXT）**（答案 B）。
- 近端串扰是双绞线（铜缆）的测试项——两根线挨太近会「串音」，光纤是光信号不存在这个问题。

**生活类比**
光纤体检 = 量「光的波长对不对、反射厉不厉害、衰减大不大」；近端串扰像「两根电话线串音」，光纤根本没这毛病，所以不测。

**📌 考点自测**

### 知识点 6.4　光纤多路复用：WDM 波分复用

**一句话理解**

## 速查卡与反直觉陷阱

### ① 单模 vs 多模

| | 单模 SMF | 多模 MMF |
|--|----------|----------|
| 纤芯 | 细（~9μm） | 粗（50/62.5μm） |
| 距离 | 远（千兆 5000m） | 近（~550m） |
| 口诀 | 单模细而远，多模粗而近 | |

### ② 千兆以太网 1000BASE 四标准

| 标准 | 介质 | 距离 |
|------|------|------|
| T | 非屏蔽双绞线 | ~100m |
| CX | 铜缆（非无线） | ~25m |
| SX | 多模光纤 | ~550m |
| LX | 单模光纤 | 可达 5000m（>550m） |

### ③ 无线加密 & 介质分类

- **无线加密**：WEP / WPA / WPA2（MD5 是哈希算法，**不是**加密方式）。
- **有线介质**：双绞线、同轴电缆、光纤；**无线**：电磁波（WiFi、蜂窝）。

### ④ 反直觉陷阱速记

- 波长越大 → 频率**越低**（λ=c/f），不是越高。
- 单模纤芯更**细**，却传得更**远**。
- 光纤**怕水**（不是体积大、也不是抗干扰弱）。
- 近端串扰只测**双绞线**，光纤不测。
- 防火墙**不能**代替杀毒软件。
- 光纤收发器灯亮 ≠ 收发都正常；且**不控**带宽。
