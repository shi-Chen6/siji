# 安全标准与评估

> 零基础通关 · 零基础通关 · 从 TCSEC 到等级保护与变更管理

## 故事线

怎么判断一个系统「够安全」？→ 先得有把「尺子」= 安全标准（国外 TCSEC 七级制、国内 GB 17859 奠定基础）→ 标准要落地：分组织（区域/国家）、分企业（南网三类）、靠实施（推广+普及）→ 落到等保与评估（涉密三密级、第三级是督查非强制）→ 日常靠变更管理三类型与资产管理。

## 知识点讲解

## ① 安全标准概念与经典标准
- 安全标准 = 给系统安全程度定「尺子」，像酒店评星。
- TCSEC（美国 1985 橙皮书）：分 **7 个级别**（D/C1/C2/B1/B2/B3/A1），归为 **4 个大类**（D/C/B/A）。
- GB 17859：我国计算机信息系统安全保护等级划分准则，是等保的基础（判断「奠定基础」为正确）。
- EMC 标准：保证 **系统和设备** 在电磁环境下正常工作且不干扰他人。
- 易混：Q1「定义了几个等级」答 7（级别）；Q19「分为几个等级、7 个级别」答 4（大类）。

## ② 标准的分类、组织与实施
- 区域标准化组织（如 CEN）：职能 = **制定/协调/发布**（BCD），推广非本职。
- 国家标准（GB）：**政府/国家级机构** 制定、**全国范围** 适用（ABD）；行业级是行业标准。
- 南方电网安全技术标准分 **三类**。
- 标准实施 = **推广 + 普及**（BD）。
- 桌面终端系统最多支持 **三级以上** 级联。

## ③ 等级保护与评估
- 涉密信息系统按最高密级分三等级：**秘密 / 机密 / 绝密**，不含「商密」（选 A）。
- 第三级等保是 **监督检查**，不是「强制监督」——题干拔高，判 **错误**。
- IT 系统成功看多维（可用性/安全/成本），**性能非唯一标准**——「唯一」太绝对，判 **错误**。

## ④ 变更管理三类型
- 复杂变更：高复杂/高影响，需跨专业定方案（Q4）。
- 标准变更：中复杂/中影响，按既定流程（Q14）。
- 简单变更：低复杂/低影响，有作业指导书即可（Q18）。

## ⑤ 资产管理与履约（偏题区，了解即可）
- IT 硬件报废：淘汰无配件/严重质量/强制淘汰/技术落后 → **ABCD 全选**（Q9）。
- IT 软件原则：**ACD**（谁使用谁负责是坑）（Q15）。
- 履约评价：严禁收好处吃请降标 → 正确（Q13）。
- Excel 标准图表：**ACD**（气泡图非标准）（Q8）。
- GBJ232 电缆：符合 **0.5m**（Q11）。

## 自测区（20 题）

**1. 美国国防部发布的可信计算机系统评估标准（TCSEC）定义了（ ）个等级。** 

- 选项：A.五 / B.六 / C.七 / D.八
- **答案：** C

- 🎯答案解析：本题选 C（七）。TCSEC 把计算机系统安全由低到高划分为 7 个级别（D、C1、C2、B1、B2、B3、A1），所以「定义了几个等级」答案是七。
- 📚知识点讲解：TCSEC 是美国 1985 年发布的可信计算机系统评估标准，用 D/C/B/A 四大类套 7 个级别给系统「评级」，就像酒店从一星到七星定级。它为后来的全球安全标准（包括我国 GB 17859）奠定了基础。
- 💡解题思路：题干问「定义了几个等级」，TCSEC 的核心就是 7 级评级体系，直接选 C 七。
- 🧠记忆口诀：TCSEC 七级制，DCBA 四分类；评级像星级，七级最高位。

**2. EMC 标准是为了保证（ ）正常工作而制定的。** 

- 选项：A.网络 / B.媒体 / C.信息 / D.系统和设备
- **答案：** D

- 🎯答案解析：本题选 D（系统和设备）。EMC 电磁兼容标准，目的是让电子设备在电磁环境中既能正常工作、又不干扰别人。
- 📚知识点讲解：EMC（电磁兼容）指设备在其电磁环境中能正常工作，且不对同环境中其他设备造成不可承受的电磁干扰。所以答案是「系统和设备」。
- 💡解题思路：EMC 保证的是设备自身和整个系统在电磁环境下正常工作，选 D。
- 🧠记忆口诀：EMC 管电磁，保全系统设备乖；不扰人也不被扰，正常工作是底盘。

**3. 桌面终端标准化管理系统最多可以支持（ ）级联。** 

- 选项：A.一级 / B.二级 / C.三级 / D.三级以上
- **答案：** D

- 🎯答案解析：本题选 D（三级以上）。桌面终端标准化管理系统支持三级以上的级联部署。
- 📚知识点讲解：级联（cascade）指一级管一级、层层下挂。桌面终端管理系统采用树状级联架构，上级管下级，规模大了可以多级挂接，所以上限是「三级以上」。
- 💡解题思路：「最多支持」问上限，选 D 三级以上。
- 🧠记忆口诀：桌面管控可级联，上级管下级；最多三级上，层层来挂接。

**4. 根据《中国南方电网有限责任公司信息运行调度业务指导意见（2015 年）》，（ ）指操作复杂度高或影响程度高。如系统的投退运，系统的迁移，转生产环境等重大工作，或者需要跨运维专业共同制定变更方案的变更。** 

- 选项：A.标准变更 / B.紧急变更 / C.简单变更 / D.复杂变更
- **答案：** D

- 🎯答案解析：本题选 D（复杂变更）。题干描述的「复杂度高、影响大、需跨专业制定方案」正是复杂变更的定义。
- 📚知识点讲解：变更分三类——复杂变更（高复杂/高影响，如系统迁移、投退运，要跨专业定方案）、标准变更（中复杂，按既定流程）、简单变更（低复杂低影响，用作业指导书即可）。
- 💡解题思路：关键词「复杂度高或影响程度高」＋「跨专业制定方案」→ 复杂变更，选 D。
- 🧠记忆口诀：变更三兄弟：复杂高、标准中、简单低；题干说高又跨专，复杂变更没跑哩。

**5. 区域标准化组织是指同处一个地区的某些国家组成的标准化组织，其主要职能是（ ）。** 

- 选项：A.推广 / B.制定 / C.协调 / D.发布
- **答案：** BCD

- 🎯答案解析：本题选 BCD（制定、协调、发布）。区域标准化组织（如欧洲 CEN）的主要职能是制定、协调、发布同区域国家的标准。
- 📚知识点讲解：标准化组织分国际（ISO）、区域（CEN、PASC）、国家（SAC）等层级。区域组织把同地区多国的标准「协调」统一、「制定」并「发布」，避免各搞各的；「推广」更多是实施环节的事。
- 💡解题思路：区域组织的核心动作是制标准（制定）、对齐（协调）、发出来（发布），选 BCD。
- 🧠记忆口诀：区域标准三件活：制定、协调、再发布；推广不算它本职，BCD 三个握得住。

**6. GB 17859 与目前等级保护所规定的安全等级的含义不同，GB 17859 中等级划分为现在的等级保护奠定了基础。** 

- 选项：A.正确 / B.错误
- **答案：** 正确

- 🎯答案解析：本题选 正确。GB 17859 是我国计算机信息系统安全保护等级划分准则，它确为后来的等级保护制度奠定了基础（虽具体含义有演进）。
- 📚知识点讲解：GB 17859-1999《计算机信息系统安全保护等级划分准则》把系统分五级，是等保的「老祖宗」标准。题干说「含义不同但奠定基础」——这是事实，判断为正确。
- 💡解题思路：GB 17859 是等保基础标准，奠定划分框架，题干表述正确，选 正确。
- 🧠记忆口诀：GB 17859 老地基，等保高楼它撑起；含义虽改框架在，奠定基础是常理。

**10. 国家标准是由（ ）或（ ）的机构制定或批准的、适用于（ ）的标准。**

- 📚知识点讲解：国家标准（GB）是由国务院标准化行政主管部门（国家）制定/批准，在全国范围统一适用的标准。所以「政府/国家级机构制定」＋「全国范围适用」= ABD。C「行业级」对应的是行业标准（如 YB、JB），不是国标。

**12. 标准的实施过程，实际上就是（ ）和（ ）已被规范化的实践经验的过程。**
