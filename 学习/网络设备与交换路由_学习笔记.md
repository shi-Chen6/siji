## 故事线：从零搭一张公司网

把全部知识点串成一条线，零基础也能"长在一条逻辑上"记住：

1. **认设备（模块一）**：先分清交换机、路由器、集线器、网桥、网关各自干啥、在哪一层干活。
2. **布内网（模块二）**：用交换机把办公室电脑连起来，交换机按 MAC 地址"派件"，每口一个冲突域。
3. **划部门（模块三）**：用 VLAN 把同楼不同部门逻辑隔开，广播只在自己 VLAN 内跑。
4. **连外网（模块四）**：用路由器把内网连到互联网，按 IP 地址"跨区投递"，隔离广播防风暴。
5. **学路由（模块五）**：路由器之间用 RIP / OSPF / BGP 等协议交换"怎么走最近"，自动算路。
6. **加安全（模块六）**：链路聚合提带宽、四层交换看内容、防火墙挡攻击、IDS 抓异常。

## 模块一 网络设备总览与 OSI 分层

### 1.1 常见网络设备与它们"在哪一层干活"

网络设备按 OSI 参考模型分层，记住"越低层越傻、越高层越聪明"：

| 设备 | 工作的层 | 一句话定位 |
|------|----------|------------|
| 中继器 / 集线器（Hub） | 物理层（第1层） | 只会"放大复制信号"，所有口共享一条总线，**整个是一个冲突域** |
| 网桥 / 交换机（Switch） | 数据链路层（第2层） | 按 MAC 地址精准派件，每端口一个冲突域 |
| 路由器（Router） | 网络层（第3层） | 按 IP 地址跨网络投递，隔离广播域 |
| 网关（Gateway） | 传输层及以上 | 连接两个"语言不通"的异构系统（如不同协议网络） |

> 题库原话：路由器"是因特网中最重要的设备，它是网络与网络连接的桥梁"（Q4）；"工作于 OSI 参考模型数据链路层的设备是广域网交换机"（Q59）；"交换机技术工作在第三层上……容易形成广播风暴"是**错误**的，交换机工作在**第二层**（Q82）。

**生活类比**：把 OSI 七层想成快递公司的 departments——物理层是"搬运工"（只管把包裹从 A 搬到 B），数据链路层是"本市分拣员"（按门牌 MAC 派件），网络层是"跨市邮局"（按邮编 IP 投递），网关是"翻译官"（把中文快递单翻成英文交给外国公司）。

### 1.2 冲突域与广播域

- **冲突域**：同一时间只能有一台设备发数据、否则"撞车"的范围。集线器所有口共享一个冲突域；交换机**每个端口一个冲突域**。
- **广播域**：广播帧（"大伙都听听"）能到达的范围。交换机**整机是一个广播域**；路由器**不转发广播**，所以能分隔广播域。

> 经典题（Q10）：一个 48 端口的交换机，冲突域 = **48**（每口一个），广播域 = **1**（整机一个）。答案 C（48,1）。

### 考点自测

**【自测1】下面关于网桥和交换机的论述，正确的是（  ）**
A. 网桥端口比交换机少，所以转发速度快  B. 交换机是一种多端口网桥，而网桥通常只有两个端口  C. 交换机不转发广播帧，而网桥转发广播帧  D. 使用网桥和交换机都增加了冲突域的大小

- 🎯 **答案解析**：选 **B**。交换机本质就是"多端口的网桥"，网桥一般只有两个口，交换机有十几个到几十个口。
- 📚 **知识点讲解**：网桥和交换机都工作在数据链路层，都靠 MAC 地址转发，都能分割冲突域；区别只是"口多少"。两者**都转发广播帧**（广播不被隔离），也**都缩小/分割冲突域**而非"增大"。
- 💡 **解题思路**：A 错（转发快慢不取决于口少）；C 错（两者都转发广播）；D 错（是"分割/减小"冲突域不是增大）；只有 B 正确。
- 🧠 **记忆口诀**："交换机 = 多口网桥；广播都转发，冲突都分割。"

**【自测2】一个 48 端口交换机，冲突域和广播域个数分别是（  ）**
A. 1,1  B. 48,48  C. 48,1  D. 1,48

- 🎯 **答案解析**：选 **C**。冲突域 48（每端口一个），广播域 1（整机一个）。
- 📚 **知识点讲解**：交换机每个端口独立处理冲突 → 48 个冲突域；广播帧会泛洪到所有端口 → 整台交换机同属一个广播域。
- 💡 **解题思路**：交换机"分冲突、不分广播"，所以冲突域=端口数，广播域=1。
- 🧠 **记忆口诀**："口数即冲突域，整机一个广播域。"

## 模块二 交换机工作原理

### 2.1 交换机怎么"派件"：MAC 地址与映射表

交换机内部有一张"端口 ↔ MAC 地址映射表"，靠两种方式建立：
- **地址学习（动态）**：收到帧时，把"来源 MAC + 入端口"记下来（Q80、Q89）。
- **手工添加**：管理员手动写静态表项（Q89）。

转发依据：**二层交换机根据 MAC 地址（不是 IP）转发数据包**（Q5）。交换机端口还能**绑定 MAC 地址**（端口只允许特定 MAC 接入，Q1）。

> 类比：交换机像公司前台，记住"张三在 3 号工位（端口3）"。来包裹写"张三"，前台查表从 3 号口递进去；新人不认识就先广播问问"张三在哪"，记住后再精准投递。

### 2.2 交换机带宽与架构

- **最大带宽 = 所有端口带宽之和**（全双工下每口独享带宽，Q54 → D）。
- **架构优点**：箱体模块式（维修方便、配置灵活、高可靠 → "以上都是"，Q78）；模块化网络架构（对各模块分别规划、增删模块扩展功能，Q79 → D）。
- **交换机图元（信息图元）**：二层交换机、三层交换机、ATM 交换机都算；**电话交换机不算**（Q70 → ABC）。

### 2.3 网线怎么接：直连线 vs 交叉线

- **交叉线**（一端 568A、一端 568B）：用于**同类设备对等连接**——PC↔PC（网卡对网卡，Q6、Q13）、交换机↔交换机（非 Uplink 口）。
- **直连线**：用于**异类设备**——PC↔交换机、PC↔路由器、交换机↔路由器。
- **级联特例**：下级交换机**有 Uplink 口**时，上级普通口用**直连线**连 Uplink（Q7 → D）。

> 类比：对讲机 A 的"说"要接 B 的"听"。同类设备"说/听"脚位置一样，所以要把线交叉对调（交叉线）；异类设备出厂已经错开，用直连线即可。

### 考点自测

**【自测3】以太网交换机根据（  ）转发数据包。**
A. IP 地址  B. MAC 地址  C. LLC 地址  D. PORT 地址

- 🎯 **答案解析**：选 **B**。二层交换机看 MAC 地址（数据链路层）转发。
- 📚 **知识点讲解**：交换机是二层设备，转发决策基于帧里的"目的 MAC 地址"查映射表；IP 地址是三层路由器才看的。
- 💡 **解题思路**：二层=MAC、三层=IP，交换机在二层 → 选 MAC。
- 🧠 **记忆口诀**："二层交换机，认 MAC 不认 IP。"

**【自测4】采用交叉双绞线连接的设备组合是（  ）**
A. PC 与 PC  B. PC 与交换机  C. 交换机与路由器  D. PC 与路由器

- 🎯 **答案解析**：选 **A**。交叉线接同类设备，PC 对 PC（网卡对网卡）。
- 📚 **知识点讲解**：交叉线把 1↔3、2↔6 对调，解决同类设备"说/听"脚一致的问题；其余三项都是异类设备，用直连线。
- 💡 **解题思路**：记住"同类交叉、异类直通"，PC-PC 是同类 → 交叉线。
- 🧠 **记忆口诀**："同交叉、异直通；PC 对 PC 用交叉。"

## 模块三 VLAN 虚拟局域网

### 3.1 什么是 VLAN

VLAN（虚拟局域网）是把**逻辑上**相关的一批用户/端口划成一个组，它们不一定物理上连同一台设备（Q32 → 正确）。核心特征：
- 是**同一广播域内的一组端口**（Q53 → C）；
- 能**逻辑地划分网段**（Q15 → A），这是它最大的优点；
- 建立 VLAN 主要**提高管理效率**（Q39 → D）。

> 类比：同一栋楼里，财务部在 3 层、研发部在 5 层，但老板要"财务的人互发广播、别打扰研发"——VLAN 就像给两部对讲机编到同一频道，物理位置不重要，逻辑分组才重要。

### 3.2 VLAN 编号与 Trunk

- **VLAN ID 范围 0–4095**：0 和 4095 保留，**可用的是 1–4094**（Q90 → ABCD 全对：端口 ID 0 表示不传 VLAN 流量；1–4094 标记对应流量；"全部"可传任意 VLAN）。
- **vlan 1 是默认 VLAN，不能删**（Q21 → A：no vlan 1 无法执行）。
- **Trunk 端口**：承载带不同 VLAN ID 的帧，实现跨交换机同 VLAN 互通；跨厂家互通标准是 **802.1q**（Q45 → 正确）。
- **Trunk 易错点**（Q48 → AD 错误）：Trunk 端口的 **PVID 可以修改**（A 说"不可改"错）；Trunk 上**并非所有帧都带 VLAN ID**（无标签帧会打上 PVID，D 说"都是带 ID"错）。

### 3.3 交换机配置模式

- 配置交换机**管理地址（设备管理 IP）**必须在 **`Switch(config-if)#`** 接口模式下（Q20、Q113 → D）。
- 同 VLAN 内主机通过**广播**互通（Q94 → 正确）。

### 考点自测

**【自测5】下面选项中，属于 VLAN 的优点是（  ）**
A. 允许逻辑地划分网段  B. 减少了冲突域的数量  C. 增加了冲突域的大小  D. 减少了广播域的数量

- 🎯 **答案解析**：选 **A**。VLAN 的核心价值是"逻辑划分网段、方便管理"。
- 📚 **知识点讲解**：VLAN 是在**一个广播域内部**做逻辑分组，它**不减少广播域数量**（广播域靠路由器才分隔），也不改变冲突域（冲突域由交换机端口决定）。所以只有 A 对。
- 💡 **解题思路**：VLAN = "逻辑划网段"，其他三项都与 VLAN 机制不符。
- 🧠 **记忆口诀**："VLAN 优在逻辑划，不管冲突与广播。"

**【自测6】不同厂家设备间实现 VLAN 互通的标准是（  ）**
A. 802.1q  B. 802.1x  C. 802.3  D. 802.11

- 🎯 **答案解析**：选 **A（802.1q）**。题库判断题 Q45 明确"不同厂家设备间实现 vlan 互通的标准是 802.1q" → 正确。
- 📚 **知识点讲解**：802.1q 是 VLAN 标签协议，给以太网帧打上 VLAN ID，让不同厂商交换机都能识别。
- 💡 **解题思路**：VLAN 标签标准记"802.1q"；802.1x 是认证、802.3 是以太网、802.11 是无线。
- 🧠 **记忆口诀**："跨厂 VLAN 互通，认准 802.1q。"

## 模块四 路由器与路由基础

### 4.1 路由器是干嘛的

- 连接"逻辑上分开的**多个**网络"（Q27 → D）；是**网络层设备**（Q88 → ABD 正确：丰富接口、网络层设备、支持多种路由协议；注：路由器按**网络层/IP** 信息转发，不是链路层，C 错）。
- 主要作用：实现**多个局域网互联**、实现**内外网连接**（Q37 → CD）。
- 因特网互连靠**路由器**（Q86 → A）；不同网络层协议转换也靠**路由器**（Q35 → C）。

### 4.2 路由器的"缺点"与转发

- **缺点**：可能成为**网络瓶颈**（转发能力跟不上时卡滞，Q51 → D；Q103 → 正确）。
- 转发依据**路由表**（查看"网络地址"转发，Q100 → C 错在"路由数固定不变"，路由会动态变化）；**IP 数据包不合法则直接丢弃**（Q41 → D）。

### 4.3 默认路由（缺省路由）

- 内部网络**对外只有一个出口**时，最好配**缺省路由**（Q33 → 正确）。
- 配置命令：`ip route 0.0.0.0 0.0.0.0 下一跳`（Q22、Q115 → D）。`0.0.0.0/0` 表示"所有未知目的地址都走这条"。
- 用路由器分段的好处：**不转发广播帧，避免广播风暴**（Q23、Q116 → A）。注意路由器**并不便宜也不必然更快**（B、C 错），且它**仍转发必要广播**而非"禁止所有广播"（D 错）。

### 考点自测

**【自测7】用路由器对网络进行分段，其优点有（  ）**
A. 路由器不转发广播帧，避免了网络风暴的产生  B. 路由器比交换机价格便宜  C. 路由器速度比交换机快  D. 路由器禁止了所有广播机制

- 🎯 **答案解析**：选 **A**。路由器是三层设备，不转发广播，能隔离广播域、防广播风暴。
- 📚 **知识点讲解**：路由器工作在 IP 层，广播帧不过路由，所以分段后能遏制广播泛滥。B/C 价格速度说法无依据；D 错在"禁止所有广播"——必要广播仍可在本网段内存在。
- 💡 **解题思路**：路由器分段核心价值 = "隔离广播防风暴"，只 A 符合。
- 🧠 **记忆口诀**："路由分段，广播不过、风暴不来。"

**【自测8】配置默认路由器的命令是（  ）**
A. ip route 172.16.1.0 255.255.255.0 0.0.0.0  B. ip route 172.16.1.0 255.255.255.0 172.16.2.1  C. ip route 0.0.0.0 255.255.255.0 172.16.2.1  D. ip route 0.0.0.0 0.0.0.0 172.16.2.1

- 🎯 **答案解析**：选 **D**。默认路由目的网络/掩码都是 `0.0.0.0`，指向出口下一跳。
- 📚 **知识点讲解**：`0.0.0.0 0.0.0.0` 是"任意地址"的通配符，代表"其他所有不知道往哪走的包，都交给这个下一跳"。
- 💡 **解题思路**：默认路由 = "全零目的 + 全零掩码"，只有 D 满足。
- 🧠 **记忆口诀**："默认路由全零配，不知去向它背锅。"

## 模块五 路由协议（RIP / OSPF / BGP / EIGRP）

### 5.1 静态路由与动态路由总览

- **静态路由**：由管理员**手动配置**（Q84 → 正确）。
- **路由权值（metric）**：衡量"哪条路好"，可基于单一或多种属性计算；不同协议计算方法不同（Q56 → AC 正确：权值可单/多属性、各协议算法不同；B 错在"多条最佳都进表"通常只优选一条；D 错在"优先级与权值一致"）。
- **路由表内容**：含目的地址、下一站、距离（跳数/开销）等，**不含"时钟"**（Q64 → 错误）。

### 5.2 RIP（距离矢量协议）

- 按**跳数（hop）**算 metric（Q63、Q83 → 正确）；**最大 15 跳**，16 跳即不可达（Q60 → B：15）。
- **默认更新周期 30 秒**（Q16、Q25、Q109、Q118 → A）。
- **路由保持（hold-down）机制防止路由环路**（Q26、Q74、Q119 → 正确）。
- 路由项 **180 秒未更新变为不可达**（Q44 → 正确）。
- **RIP-1 不支持手工路由聚合**；RIP-2 支持（Q42 → A）。
- RIP "只关心到达目的网段的**距离和方向**"（Q91 → AB：RIPv1/RIPv2 是距离矢量；OSPF 是链路状态，不只看距离方向）。

### 5.3 OSPF（链路状态协议）

- **不是距离矢量，是链路状态协议**（Q96 → A 错误说法，即选 A）。
- **cost（metric）范围 1–65535**（Q92 → 正确）。
- **单区域**内：每台路由器 **LSDB（链路状态库）相同**，但算出的**路由表不同**（Q69 → AC）。
- 邻接状态 **Full = 拓扑数据库已同步**（Q93 → 正确）。
- **DR/BDR 选举**：**优先级为 0 的路由器一定不参加选举**（Q77 → D）；注意"优先级最高不一定当选 DR"（还看其他因素）、"接口 IP 最大/Router ID 最大"也不是绝对规则，只有"优先级 0 不参选"是铁律。
- **接口网络类型**：HDLC → **P2P（点到点）**（Q58 → C）；ATM → **NBMA**（Q52 → B）。
- 链路故障时会发 **link-state update** 广播网络变化（Q38 → 正确）。
- 配置 OSPF **必须手动**做的：开启进程、创建区域、指定区域包含的网段（Q61 → BCD；Router-ID 可自动选，非必须手动）。

### 5.4 BGP 与 EIGRP

- **BGP**：在**自治系统 AS 之间**传播路由（Q73 → 正确）；**公认属性**有 Origin、AS_PATH、Next_Hop、Local_Pref（Q49 → ABCE；**MED 不是公认属性**，是可选非传递）。
- **EIGRP**：**思科专有协议**（Q72 → 正确）。
- 多路径复杂拓扑控路由、降成本，用 **BGP** 调优先级最有效（Q76 → B）。

**【自测9】在 RIP 协议中，默认的路由更新周期是（  ）秒。**
A. 30  B. 60  C. 90  D. 100

- 🎯 **答案解析**：选 **A（30 秒）**。RIP 每 30 秒向邻居广播一次完整路由表。
- 📚 **知识点讲解**：RIP 是老牌距离矢量协议，靠定时"喊话"同步路由，间隔固定 30 秒；180 秒没收到就判定邻居挂了。
- 💡 **解题思路**：RIP 周期记"30 更新、180 失效、240 刷新"，本题问更新 → 30。
- 🧠 **记忆口诀**："RIP 三十秒，喊话报路由。"

**【自测10】关于 OSPF 协议以下说法不正确的是（  ）**
A. OSPF 是一种距离矢量路由协议  B. OSPF 协议的默认管理距离是…  C. OSPF 是一种内部网关协议  D. OSPF 是一种链路状态路由协议

- 🎯 **答案解析**：选 **A**。OSPF 是**链路状态**协议，说它是"距离矢量"是错的。

- 💡 **解题思路**：找"不正确"的——A 把 OSPF 说成距离矢量，明显错。
- 🧠 **记忆口诀**："OSPF 链路状态，不是距离矢量。"

## 模块六 链路聚合 · 四层交换 · 安全

### 6.1 链路聚合

把多条物理链路绑成一条逻辑链路（Q29 → ABC）：
- **增加链路带宽**；
- 实现**数据负载均衡**；
- 增加链路**可靠性**（一条断了其他顶上）。
- 注意：链路聚合**不能避免环路**（防环路靠生成树 STP，D 错）。

> 类比：原来一条单车道的路堵，现在把三条单车道并成一条三车道——更宽（带宽）、车流分摊（均衡）、一条施工还有两条能用（可靠）。

### 6.2 四层交换

- **第四层交换**：不仅看源/目的地址，还**根据数据包内容（端口/应用）决定传输策略**（Q102 → D）。二层看 MAC、三层看 IP、四层看端口/应用。

### 6.3 安全相关设备与机制

- **防火墙**：企业内外网之间检查数据是否构成威胁的主要设备（Q3 → B）；控制对外访问、抵御外部攻击的最佳选择（Q46 → C）。
- **网络嗅探器**：把网卡设为**混杂模式**，能接收**流经接口的所有数据帧**（Q14、Q107 → D）。
- **IDS（入侵检测）**：交换环境下需对交换机配**端口镜像**（把流量复制一份给 IDS，Q85 → B）。
- **防范 IP 欺骗**：源 IP **反向路径转发 RPF**（反查路由表）+ **IP 与 MAC 绑定**（Q55 → AC；目的 IP 查表、IDS 部署不是防欺骗手段）。
- **防病毒端口**：应关闭 135/445/1433 等危险端口，但**不应关闭 22（SSH 远程管理）**（Q40 → C）。
- **上网行为管理**工作模式支持程度：路由模式 > 网桥模式 > 旁路模式（Q50 → 正确）。

### 考点自测

**【自测11】链路聚合的作用是（  ）**
A. 增加链路带宽  B. 可以实现数据的负载均衡  C. 增加了交换机间的链路可靠性  D. 可以避免交换网环路

- 🎯 **答案解析**：选 **ABC**。链路聚合增带宽、能均衡、提可靠；但**不能避免环路**（D 错，防环靠生成树）。
- 📚 **知识点讲解**：聚合是把多条链路当一条用，容量叠加、流量分摊、冗余备份；环路是另一回事，由 STP 解决。
- 💡 **解题思路**：ABC 都是"扩容/冗余"好处，D 是防环不属于聚合 → 选 ABC。
- 🧠 **记忆口诀**："聚合三好：带宽、均衡、更可靠；防环另算。"

**【自测12】网络嗅探器使网络接口处于混杂模式，此时接口（  ）**
A. 只收匹配本机 MAC 的帧  B. 只收本网段广播  C. 只收组播  D. 能接收流经接口的所有数据帧

- 🎯 **答案解析**：选 **D**。混杂模式下网卡"来者不拒"，抓所有经过的帧（用于抓包分析，也说明嗅探能窃听）。

- 💡 **解题思路**："混杂"= 不挑不拣全收，对应 D。
- 🧠 **记忆口诀**："混杂模式全收，嗅探窃听无忧（加密才防）。"

## 速查卡与反直觉陷阱

### 速查卡

| 主题 | 要点 |
|------|------|
| 设备分层 | 物理层=集线器/中继器；数据链路层=交换机/网桥；网络层=路由器；传输层以上=网关 |
| 冲突/广播域 | 交换机：每口一个冲突域，整机一个广播域；路由器分隔广播域 |
| 线序 | 同类交叉（PC-PC、交换机-交换机），异类直通；有 Uplink 用直连 |
| VLAN | 逻辑划网段、提管理效率；ID 1–4094；vlan1 不可删；跨厂 802.1q |
| 默认路由 | `ip route 0.0.0.0 0.0.0.0 下一跳`；单出口必配 |
| RIP | 距离矢量、跳数 metric、最大 15、更新 30s、防环 hold-down、RIP-1 不聚合 |
| OSPF | 链路状态、cost 1–65535、单区域 LSDB 同/路由表异、Full=同步、优先级 0 不参选 |
| BGP | AS 之间；公认属性 Origin/AS_PATH/Next_Hop/Local_Pref（MED 非公认） |
| EIGRP | 思科专有 |
| 安全 | 防火墙挡内外威胁；嗅探=混杂全收；IDS=端口镜像；防骗=RPF+IP-MAC 绑定；别关 22 |

### 反直觉陷阱（零基础最容易选反的）

1. **交换机工作在第二层，不是第三层**（Q82 说"第三层易广播风暴"是错的）。
2. **路由器的"分段优点"是隔离广播，不是"更便宜/更快"**（Q23 的 B/C/D 都是坑）。
3. **vlan 1 不能删**（很多人以为随便删）。
4. **Trunk 上并非所有帧都带 VLAN ID**（无标签帧会打 PVID）。
5. **RIP 最大 15 跳，不是更大**（16 跳即不可达）。
6. **OSPF 是链路状态，不是距离矢量**（Q96 的 A 是错误说法）。
7. **BGP 的 MED 不是公认属性**（Q49 公认属性不含 MED）。
8. **Q98 存疑**：题库标"传输层以上互连设备"答案为 A 路由器，但**标准答案应为 C 网关**（网关才工作在传输层以上连接异构系统）。考试以题库为准，学习以正确概念为准。
