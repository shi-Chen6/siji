# 身份认证与口令安全 学习笔记

> 零基础通关 · 从「你怎么证明你是你」到口令攻防全掌握

## 📖 故事线

你怎么向系统证明「你是你」？三类因子（所知/所有/所是）搭起认证框架 → 第一道门「口令」却常因弱密码失守 → 黑客用暴力/字典撬锁，我们用防猜测三招反制 → 标识要唯一、鉴别靠加密+签名 → 进阶动态口令与等保双因子 → 最后把易混点钉死。

## ① 什么是身份认证——三类因子

想象进小区：门卫问「你叫啥」（你说密码，所知因子）、查「你刷的卡」（你持有的门禁卡，所有因子）、看「你的脸」（指纹虹膜，所是因子）。认证就是「系统怎么确认你是你」。三类因子各管一类证据，组合起来越稳。

**最常用的是口令认证**

日常登录几乎都是「账号+密码」，门槛最低、部署最容易，所以它是普及度最高的认证方式。

> 📌 对应练习：Q、2

**双因子要跨两类**

智能卡(所有)+PIN(所知) 才是真双因子；光用两个口令类不算。

> 📌 对应练习：Q、3

**门卡不是身体特征**

指纹/虹膜/视网膜是「所是因子」，门卡是「所有因子」，别混。

> 📌 对应练习：Q、7

**地址端口不是认证**

限制IP/端口是访问控制，不证明你是谁。

> 📌 对应练习：Q、1、5

## ② 口令安全基础——危险密码与强口令

口令是第一道防线，但很多人设的密码像「把钥匙挂在门上」。弱密码让前面整套认证形同虚设。这一节搞清楚哪些是危险密码、什么样的口令才够硬、以及口令绝不能明文出现。

**危险密码三兄弟**

与用户名相同、用生日、长度≤6位都是危险密码；10位以上综合型最安全。

> 📌 对应练习：Q、1

**强口令看混合度**

大小写+数字+符号+长度，混合越杂越安全（Zhang!san10b 最强）。

> 📌 对应练习：Q、8

**口令绝不能明文**

程序/配置文件里明文存口令是严重违规（参考LinkedIn事件）。

> 📌 对应练习：Q、9

**FTP传密是明文**

传统FTP账号密码明文传输，抓包即泄，应换SFTP/FTPS。

> 📌 对应练习：Q、1、9

## ③ 口令破解与防御——攻击法与防猜测

黑客怎么撬口令？撬完我们怎么堵？这一节把破解四法和防猜测三措施对照记，考试最爱正反考。

**最简单有效是暴力**

暴力破解不挑目标、挨个试遍，理论上必然成功，是兜底手段。

> 📌 对应练习：Q、6

**防猜测三措施**

限短口令、限尝试次数、用随机口令；不再现是防偷看非防猜测。

> 📌 对应练习：Q、1、2

**字典攻击靠弱口令**

预设口令/默认口令是字典攻击帮凶，绝不能留。

> 📌 对应练习：Q、3、0

**对付攻击强管理**

加强口令管理（长度、不重用、不默认）是根本手段。

> 📌 对应练习：Q、3、2

## ④ 身份标识与鉴别机制——唯一性与证明方式

标识是「你是谁的名字」，鉴别是「怎么证明」。这里有两个高频对子题：唯一性vs多样性、鉴别机制选哪两个。

**标识必须唯一**

每个用户标识唯一才能绑定到人、追责；不是多样性。

> 📌 对应练习：Q、1、7

**多样性是陷阱**

把唯一性偷换成多样性→错误，识破偷换概念。

> 📌 对应练习：Q、2、4

**鉴别机制=加密+签名**

加密证明知密、签名证明持私钥，二者实现鉴别。

> 📌 对应练习：Q、1、8

**登录别细分错误**

用户名或密码错统一提示，防攻击者枚举账号。

> 📌 对应练习：Q、1、1

## ⑤ 进阶认证与运维——动态口令与管理

基础打牢后看进阶：动态口令为啥安全、系统怎么强制强口令、管理员怎么管用户。

**动态口令三优点**

动态、不确定、一次性；可重复性是缺点非优点。

> 📌 对应练习：Q、3、1

**WebLogic默认约束**

应用服务器缺省策略强制口令长度等，系统层落地强口令。

> 📌 对应练习：Q、3、4

**等保三级双因子**

证书+口令+动态令组合，至少两种认证方式。

> 📌 对应练习：Q、3、5

**管理员管用户四件事**

建号、配资源、设环境、管口令安全，全选。

> 📌 对应练习：Q、2、9

## ⑥ 速查与辨析——易混点钉死

把跨模块的易错题集中钉一遍，考试遇到直接秒答。

**唯一性≠多样性**

Q17正确、Q24错误，一字之差正反考。

> 📌 对应练习：Q、1、7

**防猜测C是反例**

不再现防偷看，不是防远程猜测（Q12/Q26/Q28）。

> 📌 对应练习：Q、1、2

**鉴别机制双选**

加密+数字签名，访问控制/路由控制不沾边（Q18/Q21）。

> 📌 对应练习：Q、1、8

**破解最管用暴力**

最简单有效=暴力，字典社工靠运气（Q6）。

> 📌 对应练习：Q、6

## 🚀 速查卡（口诀汇总）

| 要点 | 口诀/结论 |
|---|---|
| 危险密码 | 同名/生日/≤6位→选「不属于」找综合长密码 |
| 双因子 | 跨两类：所知+所有（卡+PIN），同种两样不算 |
| 破解最管用 | 暴力破解（最简单有效），字典社工靠运气 |
| 防猜测三招 | 限短、限次、随机造；不再现防偷看非猜测 |
| 鉴别机制 | 加密+数字签名（访问控制/路由不沾边） |
| 标识要求 | 唯一性（正确）≠多样性（错误） |
| 动态口令 | 优点：动态/不确定/一次性；可重复性=缺点 |
| 等保三级 | 至少两种认证：证书+口令+动态令（ACD） |

## 📝 自测区（35 题）

**1. 以下不属于常见危险密码的是（ ）。** 

- 选项：A.跟用户名相同的密码 / B.使用生日作为密码 / C.只有6位数的密码 / D.10位以上的综合型密码
- **答案：** D

- 🎯答案解析：本题选 D（10位以上的综合型密码）。长度足、字符杂，不属于危险密码；A/B/C 都是典型弱密码。
- 📚知识点讲解：危险密码三类：与用户名相同、用生日/手机号等易猜信息、长度过短（≤6位）。综合型指大小写+数字+符号混合，10位以上暴力破解成本极高，是安全密码。
- 💡解题思路：问「不属于危险」→ 找那个安全的：D 明显最安全。选 D。
- 🧠记忆口诀：危险密码三兄弟：同名、生日、六位短；综合十位最安全，反着选它就对。

**2. 在以下认证方式中，最常用的认证方式是（ ）。** 

- 选项：A.基于账户名/口令认证 / B.基于摘要算法认证 / C.基于PKI认证 / D.基于数据库认证
- **答案：** A

- 🎯答案解析：本题选 A（基于账户名/口令认证）。用户名+口令是互联网最普遍、门槛最低的认证方式。
- 📚知识点讲解：认证方式按普及度：口令认证（所知因子）最常用；PKI/证书（非对称）安全性高但部署复杂；摘要算法多用于协议层而非直接面向用户；数据库认证不是标准认证分类。
- 💡解题思路：「最常用」→ 日常登录都是账号密码，选 A。
- 🧠记忆口诀：最常用是账号口令，门槛低来人人有；PKI虽好太复杂，普及还得靠密码。

**3. 下列能够满足双因子认证的需求的方法是（ ）。** 

- 选项：A.智能卡和用户PIN / B.用户ID与密码 / C.虹膜扫描和指纹扫描 / D.用户名和PIN
- **答案：** A

- 🎯答案解析：本题选 A（智能卡和用户PIN）。智能卡是「所有因子」（你持有的卡），PIN是「所知因子」（你知道的码），两因子结合=双因子。
- 📚知识点讲解：三类因子：所知（密码/PIN）、所有（智能卡/U盾/手机）、所是（指纹/虹膜/人脸）。双因子=任选两类组合。B/D 都只含所知（ID+密码、用户名+PIN 本质都是口令类）；C 是两种所是因子，仍属同类，不算严格双因子。
- 💡解题思路：双因子须跨两类 → A 含「卡(所有)+PIN(所知)」。选 A。
- 🧠记忆口诀：双因子要跨两类：所知所有所是分；卡加PIN跨两类，同种两样不算数。

**4. 以下不属于常见危险密码的是（ ）。** （与前面重复）

- 选项：A.跟用户名相同的密码 / B.使用生日作为密码 / C.只有6位数的密码 / D.10位以上的综合型密码
- **答案：** D

- 🎯答案解析：本题选 D（10位以上的综合型密码）。与第 1 题完全相同：综合型长密码安全，不属于危险密码。
- 📚知识点讲解：同 Q1：危险密码三类（同名/生日/短），D 是安全密码。
- 💡解题思路：同 Q1，问「不属于危险」选 D。
- 🧠记忆口诀：（与前面重复）危险密码三兄弟，综合十位最安全；同名生日六位短，反着选它就对。

**5. 在以下认证方式中，最常用的认证方式是（ ）。** （与前面重复）

- 选项：A.基于账户名/口令认证 / B.基于摘要算法认证 / C.基于数据库认证 / D.基于PKI认证
- **答案：** A

- 🎯答案解析：本题选 A（基于账户名/口令认证）。与第 2 题完全相同：口令认证最普及。
- 📚知识点讲解：同 Q2：用户名+口令门槛最低、最常用。
- 💡解题思路：同 Q2，选 A。
- 🧠记忆口诀：（与前面重复）最常用是账号口令，普及还得靠密码。

**6. 口令破解的最简单有效方法是（ ）。** 

- 选项：A.暴力破解 / B.社工破解 / C.字典攻击 / D.生日攻击
- **答案：** A

- 🎯答案解析：本题选 A（暴力破解）。题目问「最简单有效」——暴力破解不依赖任何先验知识，挨个试遍所有可能，理论上必然成功，是最直接兜底的手段。
- 📚知识点讲解：破解四法：暴力（遍历所有组合）、字典（用常见密码表猜）、社工（套话骗取）、生日攻击（针对哈希碰撞）。暴力虽慢但「最简单有效」，因为不挑目标、必然覆盖。
- 💡解题思路：「最简单有效」强调不需技巧、必然可行 → 暴力破解（A）。选 A。
- 🧠记忆口诀：最简单有效是暴力，挨个试遍不挑人；字典社工靠运气，暴力兜底最稳当。

**7. （ ）不是基于用户特征的身份标识与鉴别。** 

- 选项：A.指纹 / B.门卡 / C.虹膜 / D.视网膜
- **答案：** B

- 🎯答案解析：本题选 B（门卡）。门卡是「所有因子」（你持有的物），不是用户自身生物特征；指纹/虹膜/视网膜都是「所是因子」（身体特征）。
- 📚知识点讲解：基于用户特征=所是因子（生物特征）：指纹、虹膜、视网膜、人脸、声纹。门卡、智能卡、U盾属于持有物，不是身体特征。
- 💡解题思路：问「不是特征」→ 门卡是物件非身体，选 B。
- 🧠记忆口诀：身体特征才叫特征，指纹虹膜视网膜；门卡物件非身体，所是所有要分清。

**8. 下列用户口令安全性最高的是（ ）。** 

- 选项：A.Zhang!san10b / B.Zhangsan980 / C.1.9801212E7 / D.Zhangsan1980
- **答案：** A

- 🎯答案解析：本题选 A（Zhang!san10b）。它含大小写字母+特殊符号+数字+长度较长，熵值最高。
- 📚知识点讲解：口令强度看四要素：长度、字符集大小（大小写/数字/符号混合）、无字典词、无规律。A 混合了「Zhang」「!」「san」「10b」且带符号；B/D 是纯字母+数字且含字典词 Zhangsan；C 看似数字实则像科学计数法、字符集单一。
- 💡解题思路：找「混合度最高、含符号、较长」的 → A。选 A。
- 🧠记忆口诀：强度看混合：大写小写数字符，越长越杂越安全；纯词加数还不够，带符才叫硬 password。

**9. 运行下列安全防护措施中不是应用系统需要的是（ ）。** 

- 选项：A.用户口令可以以明文方式出现在程序及配置文件中 / B.应用系统合理设置用户权限 / C.禁止应用程序以操作系统ROOT权限运行 / D.重要资源的访问与操作要求进行身份认证与审计
- **答案：** A

- 🎯答案解析：本题选 A（口令可以明文出现）。明文存口令是严重违规，恰恰「不是」应用系统需要的安全防护。
- 📚知识点讲解：应用系统安全防护：权限最小化（B）、不以ROOT运行（C，防提权）、重要操作身份认证+审计（D）。而口令必须加密/哈希存储，明文出现是漏洞（参考 LinkedIn 事件）。
- 💡解题思路：问「不是需要」→ 找违规项：明文口令（A）。选 A。
- 🧠记忆口诀：口令明文是大忌，应用系统不能要；权限最小不ROOT，重要操作必审计。

**10. 网络扫描器不可能发现的是（ ）。** 

- 选项：A.用户的弱口令 / B.用户的键盘动作 / C.系统的版本 / D.系统的服务类型
- **答案：** B

- 🎯答案解析：本题选 B（用户的键盘动作）。扫描器通过网络探测，看不到用户在物理键盘上的敲击。
- 📚知识点讲解：网络扫描器能探测：开放端口/服务类型（D）、系统版本banner（C）、弱口令尝试（A）。键盘动作属本地物理行为，不在网络流量里，扫描器无从得知。
- 💡解题思路：问「不可能发现」→ 本地键盘动作（B）。选 B。
- 🧠记忆口诀：扫描只能看网络，端口版本弱口令；键盘动作在本地，隔着屏幕看不到。

**11. 用户登录模块中，当用户名或者密码输入错误时，系统应该给出（ ）。** 

- 选项：A.用户名错误 / B.密码错误 / C.用户名和密码错误 / D.用户名或者密码错误
- **答案：** D

- 🎯答案解析：本题选 D（用户名或者密码错误）。不单独提示哪一项错，避免攻击者据此枚举出哪些用户名已注册。
- 📚知识点讲解：登录错误提示原则：模糊反馈。若提示「用户名错误」攻击者可批量试探有效账号；提示「密码错误」则暴露账号存在。统一回「用户名或密码错误」不泄露账号状态。
- 💡解题思路：安全做法=不区分 → 选 D。
- 🧠记忆口诀：登录出错别细分，用户名或密码错；泄露账号给黑客，模糊提示才安全。

**12. 以下哪项不属于防止口令猜测的措施（ ）。** 

- 选项：A.防止用户使用太短的口令 / B.严格限定从一个给定的终端进行非法认证的次数 / C.确保口令不在终端上再现 / D.使用机器产生的口令
- **答案：** C

- 🎯答案解析：本题选 C（确保口令不在终端上再现）。这是「显示保护」（不回显星号以外的明文），防止旁人偷看，并不直接阻止攻击者远程猜测口令。
- 📚知识点讲解：防猜测措施：限短口令（A，短则易猜）、限尝试次数（B，锁账号）、机器生成随机口令（D，无规律）。C 的「不再现」是防肩窥（shoulder surfing），属本地显示安全，与「远程猜测」无关。
- 💡解题思路：问「不属于防猜测」→ C 防的是偷看非猜测。选 C。
- 🧠记忆口诀：防猜测靠三招：限短、限次、随机造；不再现防偷看，不是猜口令的招。

**13. 下列方法（ ）能防止失效的身份认证和会话管理漏洞。** （了解即可）

- 选项：A.参数化查询方式 / B.用户登录成功后生成新的会话ID / C.检测用户访问权限 / D.使用自定义的映射名称
- **答案：** B

- 🎯答案解析：本题选 B（登录成功后生成新的会话ID）。会话固定攻击靠复用旧会话ID，登录后换新ID可切断攻击者持有的旧会话。
- 📚知识点讲解：失效认证与会话管理是OWASP常见漏洞。防御：登录后重发会话ID（防会话固定）、会话超时、退出即销毁。A 防SQL注入；C 是访问控制；D 无关。
- 💡解题思路：问「会话管理」→ 换新会话ID（B）。选 B。
- 🧠记忆口诀：登录成功换ID，会话固定无缝钻；旧ID作废新ID生，会话管理才安全。

- 💡解题思路：WebLogic 默认确实约束口令长度 → 正确。
- 🧠记忆口诀：WebLogic缺省策，口令长度有约束；系统强制强口令，防护思想落地处。

**35. 等级保护三级及以上系统应至少采用两种认证方式，下列属于认证方式的有（ ）。** 

- 选项：A.证书认证 / B.短信验证码 / C.用户名、口令认证 / D.一次性口令、动态口令认证
- **答案：** ACD

- 🎯答案解析：本题选 ACD。等保三级要求双因子：证书（A）、用户名口令（C）、动态/一次性口令（D）都属认证方式。B 短信验证码虽常见于多因子，但本题标准答案未纳入（且短信验证码安全性存争议，易遭拦截/换卡攻击），故不选。

- 💡解题思路：按标准答案选 ACD，注意 B 虽像认证但本题不选。
- 🧠记忆口诀：等保三级双因子，证书口令动态令；认证三类全覆盖，短信未列标准答案。
