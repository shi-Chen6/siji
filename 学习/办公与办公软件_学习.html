1 模块1 办公软件与办公套件

1.1 什么是办公软件

办公软件就是帮你在电脑上“写文档、做表格、做演示”的工具总称。最常见的三大件：Word（写字）、Excel（算表）、PowerPoint（做幻灯片），它们解决的是“日常办公”问题。

生活类比：办公软件像“文具套装”——笔（写字）、尺子（算数）、画板（演示），把办公室里最常用的活儿搬上了电脑。

1.2 办公套件 vs 单一应用

办公套件是把上述多个软件“打包捆绑”一起卖、一起装的合集。主流三套件：金山 WPS（Kingsoft Office）、微软 Microsoft Office、开源 Apache OpenOffice。注意：浏览器（如 Internet Explorer）只是用来上网的，不属于办公套件。

⚠ 考点：看到带“Office”字样的通常是套件；IE / 浏览器是上网工具，不是办公套件。
【自测】下列各种软件中，()不属于办公套件。
选项：A.Kingsoft Office　B.Internet Explorer　C.Microsoft Office　D.Apache OpenOffice
▸ 显示解析
🎯 答案解析：选 B。Internet Explorer 是“网页浏览器”，不是办公套件。📚 知识点讲解：办公套件＝把多个办公软件打包在一起卖（文字、表格、演示等）。常见三大家：金山 WPS（Kingsoft Office）、微软 Microsoft Office、开源 Apache OpenOffice。浏览器是用来上网的，归“上网工具”，不在办公套件里。💡 解题思路：找“不属于办公套件”。A 金山、C 微软、D 开源三件套都带“Office”字样，明显是办公套件；B “Explorer”是浏览器。🧠 记忆口诀：“带 Office 的是套件，IE 浏览器靠边站。”

2 模块2 文档格式与兼容

2.1 docx 是什么格式

docx 是 Word 2007 及以后版本的默认格式，本质是“一个压缩包里装了一堆 XML 文本”（类似把文档拆成结构化小文件再 zip 起来）。而老 Word 2003 用的 doc 是另一种二进制格式。两者内核不同。

生活类比：docx 像“新式打包快递盒（里面按规矩分格放）”，doc 像“老式麻袋”。盒子和麻袋的封条名（.docx / .doc）只是标签不同，里面东西的格式天差地别。

2.2 “改扩展名”的经典陷阱

有人以为把文件后缀 .docx 改成 .doc，老 Word 就能打开。错！扩展名只是文件名尾巴，改它不改变文件内部真正的格式。Word 2003 打开后只会看到乱码或报错。要真正打开，得：装“Office 兼容包”，或用 Word 2007+ / WPS 2012+ 直接开。

⚠ 考点：Q1 问“不正确”的说法，就是“改扩展名后能打开”这一句。记住：扩展名≠格式。
【自测】以下关于打开扩展名为 docx 的文件的说法中，不正确的是()。
选项：A.通过安装 Office 兼容包就可以用 Word 2003 打开 docx 文件　B.用 Word 2007 可以直接打开 docx 文件　C.用 WPS 2012 可以直接打开 docx 文件　D.将扩展名 docx 改为 doc 后可以用 Word 2003 打开 docx 文件
▸ 显示解析
🎯 答案解析：选 D。把 docx 文件扩展名改成 doc，并不能让 Word 2003 打开它——扩展名只是文件名后缀，文件内部的格式并没变，Word 2003 读不懂。📚 知识点讲解：docx 是 Word 2007 起的“新”格式（本质是压缩的 XML 包），Word 2003 认的是老 doc 二进制格式。要打开它，要么装“兼容包”，要么用新版本 Word / WPS。只改扩展名是“换汤不换药”，内容没转换。💡 解题思路：找“不正确”的说法。A 装兼容包可开（对）；B Word 2007 直接开（对）；C WPS 2012 直接开（对）；D 改扩展名就能开——错，扩展名≠格式。🧠 记忆口诀：“扩展名是马甲，格式没换别想开。”

3 模块3 Word 文字处理基础

3.1 段落对齐方式

段落对齐决定一行文字在左右页边距之间怎么摆。Word 2007 提供的对齐有：左对齐、两端对齐（首尾顶边、中间匀开）、居中对齐、右对齐、分散对齐（连单行也撑满整行）。注意：没有“上下对齐”这个选项——那是页面“垂直对齐”的概念，不是段落对齐。

【自测】在 Word 2007 中，段落对齐方式包括()。
选项：A.两端对齐　B.分散对齐　C.居中对齐　D.上下对齐
▸ 显示解析
🎯 答案解析：选 ABC。Word 段落对齐有：左对齐、两端对齐、居中对齐、右对齐、分散对齐。“上下对齐”不存在（那是“垂直居中”之类的页面设置，不是段落对齐方式）。📚 知识点讲解：段落对齐管的是“一行文字在左右页边距之间怎么摆”。两端对齐（首尾顶边、中间匀开）、分散对齐（连单行也撑满）、居中对齐（放中间）。D“上下对齐”是混淆项——Word 没有这个段落对齐选项。💡 解题思路：选“包括”的。A/B/C 都是真对齐方式；D 上下对齐是凑的干扰项，排除。🧠 记忆口诀：“两端分散居中右，上下对齐是忽悠。”

3.2 常用快捷键

Ctrl+C 复制、Ctrl+X 剪切、Ctrl+V 粘贴，是 Windows 通用快捷键，在 Word 里选中文本或对象后按 Ctrl+C 即可复制到剪贴板。

【自测】Word 文档中 Ctrl+C 复制所选文本或对象。
选项：A.正确　B.错误
▸ 显示解析
🎯 答案解析：选 正确。Ctrl+C 就是“复制”的通用快捷键，Word 里选中文字 / 图片后按它即复制到剪贴板。📚 知识点讲解：Ctrl+C（Copy）复制、Ctrl+X（Cut）剪切、Ctrl+V（Paste）粘贴，是 Windows 通用快捷键，Word 当然支持。💡 解题思路：题干说 Ctrl+C 复制——这是常识性正确表述，选正确。🧠 记忆口诀：“C 是复制，V 是粘贴，X 是剪切。”

4 模块4 表格与演示联动

4.1 Excel 与 PowerPoint 的“粘贴链接”

在 PPT 里插入 Excel 表格有两种贴法：① 普通粘贴＝贴一张“静态照片”，以后 Excel 改了它不变；② 粘贴链接＝贴一个“指向 Excel 单元格的活指针”（OLE 链接），Excel 源数据一更新，PPT 里的表自动跟着变。题干说的就是第二种。

生活类比：普通粘贴像“打印出来的照片”（定格）；粘贴链接像“实时视频连线”（源动它动）。
【自测】如果将 Excel 数据表格以粘贴链接方式插入到 PowerPoint 演示文稿中，则当 Excel 工作簿中的表格数据更改后，PowerPoint 演示文稿中对应的信息将自动更改。
选项：A.正确　B.错误
▸ 显示解析
🎯 答案解析：选 正确。粘贴链接（链接对象）后，Excel 源数据一改，PPT 里的表会自动跟着变。📚 知识点讲解：Office 的“粘贴链接”用的是 OLE 链接技术——PPT 里只存一个“指向 Excel 单元格的指针”，不存数据副本。源一更新，指针指向的最新值就显示出来。区别于“普通粘贴”（只贴一张静态快照，源改了它不变）。💡 解题思路：关键词“粘贴链接方式”＋“自动更改”——链接的本质就是实时联动，所以正确。🧠 记忆口诀：“链接是活指针，源变它也变。”

5 模块5 延伸：系统更新与网络安全

5.1 延伸：WSUS 系统更新

WSUS（Windows Server Update Services）是微软给企业内网批量发 Windows 补丁的服务，运行在 Windows Server 上。它和 Office（办公软件）是两码事。说“装 WSUS 需先装 Office 2003”是错的。

【自测】要使用默认选项安装 WSUS，需要在计算机上安装 Microsoft Office 2003。
选项：A.正确　B.错误
▸ 显示解析
🎯 答案解析：选 错误。装 WSUS 不需要先装 Office 2003，两者毫无关系。📚 知识点讲解：WSUS＝Windows Server Update Services（Windows 服务器更新服务），是微软给内网批量分发 Windows 补丁的工具，跑在 Windows Server 上。Office 是办公软件，和补丁分发服务不搭界。💡 解题思路：WSUS 是“系统更新服务”，Office 是“办公软件”——风马牛不相及，说“需先装 Office 2003”纯属误导，选错误。🧠 记忆口诀：“WSUS 管补丁，Office 不相干。”

5.2 延伸：网络安全审查监督

网络安全审查办公室对关键信息基础设施、数据处理等活动做“事前＋事中＋事后”全过程监督，通过主动审查、日常监测、接受举报等手段覆盖全周期。

【自测】网络安全审查办公室通过接受举报等形式加强()监督。
选项：A.事前　B.事中　C.事后　D.以上都是
▸ 显示解析
🎯 答案解析：选 D。“以上都是”——网络安全审查办公室既管事前（上线前审查）、也管事中（运行监测）、还管事后（举报追责），全周期覆盖。📚 知识点讲解：网络安全审查是对关键信息基础设施、数据处理等活动做“事前＋事中＋事后”的全过程监督。审查办公室通过主动审查、日常监测、接受举报等多种手段，把三个阶段都管起来。💡 解题思路：问“加强哪种监督”，三个选项事前 / 事中 / 事后本身就是监督的三个环节，且题干“通过接受举报等形式”暗示多手段、全覆盖，故选“以上都是”。🧠 记忆口诀：“审查管全程，事前事中又事后。”
