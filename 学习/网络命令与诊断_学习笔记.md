# 网络命令与诊断 · 零基础系统学习笔记

> 内容来源：题库「网络命令与诊断（23 题）」
> 学习目标：零基础学员通过通俗讲解 + 类比 + 内嵌自测，掌握常用网络诊断命令，并能独立完成全部 23 道练习题。

## 📖 故事线：一次「上不了网」的排查之旅

把全部命令串成一条排查线，零基础也能「长在一条线上」记住：

1. **① 看自己**：电脑网卡有没有 IP？DHCP 给了没？→ `ipconfig`
2. **② 验连通**：网关 ping 得通吗？邻居 MAC 是谁？→ `ping` / `arp -a`
3. **③ 查路径**：数据包往哪走？路由表怎么排？经过几跳？→ `route print`（= `netstat -r`）/ `tracert`
4. **④ 解域名**：输入网址打不开，是 DNS 坏了吗？→ `nslookup`
5. **⑤ 换系统**：在 Linux 上这些活儿谁干？→ `ifconfig` / `netstat -nr`
6. **⑥ 上安全**：门怎么守？分支怎么连？证书怎么管？→ 防火墙 / VPN / 证书 / cipher / 活动目录

## 模块一 · 为什么要用网络命令（诊断思路）

### 1.1 网络命令是「医生的听诊器」

电脑上不了网，肉眼看不见网线里发生了什么。网络命令就是给我们的「听诊器」——它们把系统内部看不见的网络状态（IP 地址、路由表、DNS、连接情况）变成**文字输出**，让我们能「看见」问题出在哪。

> **生活类比**：网络像人体的血管系统。上不了网 = 身体某个地方「堵了」。医生不会靠猜，会用听诊器、验血、CT 逐项查；我们排查网络，也不用猜，而是用 `ipconfig` 先看「血压」（IP 在不在）、`ping` 测「心跳」（通不通）、`route print` 看「路线图」（路对不对）。

### 1.2 排查的通用思路：由近及远、由本机到远端

记住一个黄金顺序：**先本机 → 再网关 → 再远端**。

| 步骤 | 看什么 | 用什么命令 |
|------|--------|-----------|
| 本机配置 | 网卡有没有 IP、DHCP 给了没 | `ipconfig` |
| 本地连通 | 网关能不能通、邻居 MAC | `ping` / `arp -a` |
| 路径路由 | 数据包走哪条路 | `route print` / `netstat -r` |
| 域名解析 | DNS 服务器工作不 | `nslookup` |

### 1.3 内嵌考点自测

**【自测 1】** 当电脑「上不了网」时，第一步最该查的是（  ）。
A. 直接重装系统　B. 先看本机有没有拿到 IP 地址　C. 立刻换路由器　D. 拔掉所有网线

> **解析**
> 🎯 答案解析：选 **B**。排查讲究「由近及远」，先确认本机 IP 配置是否正常。
> 📚 知识点讲解：网络命令的价值就是「先看清本机状态」。`ipconfig` 能立刻告诉我们 DHCP 有没有分配 IP——这是一切排查的起点。
> 💡 解题思路：题目问「第一步」，按顺序本机优先，选 B。
> 🧠 记忆口诀：「上网先查本机 IP，由近及远不抓瞎。」

## 模块二 · Windows 基础查看命令（ipconfig）

### 2.1 ipconfig 是干什么的

`ipconfig`（IP Configuration）是 Windows 下查看**本机网络配置**最常用命令。它能告诉你：
- 本机 IP 地址、子网掩码、默认网关
- 是不是 DHCP 自动分配的
- DNS 服务器地址

**关键考点（第 9、22 题）**：在 Windows 中，可以通过 `ipconfig` 命令查看 **DHCP 服务器分配给本机的 IP 地址**。

> **生活类比**：`ipconfig` 就像你家的「门牌号登记表」。IP 地址 = 门牌号，子网掩码 = 这个范围归谁管，默认网关 = 出小区的门。DHCP 是物业自动给你发的门牌（动态分配），`ipconfig` 就是去物业查「我的门牌号是几」。

### 2.2 常用用法

| 命令 | 作用 |
|------|------|
| `ipconfig` | 显示基本 IP 配置 |
| `ipconfig /all` | 显示全部详细信息（含 MAC、DHCP 服务器、租约时间） |

> ⚠️ **易混点**：`ipconfig /all` 能看到 MAC 地址，但**由 IP 查 MAC 要用 `arp -a`**（见模块三），别把两者搞混。`ipconfig` 是「看自己」，`arp` 是「看邻居」。

### 2.3 内嵌考点自测

**【自测 2】** 在 Windows 中，查看 DHCP 服务器分配给本机的 IP 地址，应使用（  ）。
A. nslookup　B. ifconfig　C. ipconfig　D. tracert

> **解析**
> 🎯 答案解析：选 **C**。`ipconfig` 显示本机 IP 配置，含 DHCP 分配的地址。
> 📚 知识点讲解：`ipconfig` 是 Windows 专属的「本机配置查看器」；`ifconfig` 是 Linux 的（模块五）；`nslookup` 查 DNS；`tracert` 查路径。
> 💡 解题思路：关键词「Windows + DHCP 分配 IP」 → `ipconfig`。
> 🧠 记忆口诀：「Windows 看本机，ipconfig 最行。」

## 模块三 · 连通性与地址解析（ping / arp -a / IP 安全策略）

### 3.1 ping：测「通不通」

`ping` 命令向目标发送 ICMP 回显请求，看对方是否回应。是最基础的连通性测试工具。

> **生活类比**：`ping` 就像你对着山谷喊一声「喂——」，看有没有回声。有回声说明路通着；没回声可能是对方不在、路断了、或者对方「捂耳朵不听」（被防火墙/安全策略禁了）。

### 3.2 arp -a：由 IP 查 MAC

`arp -a`（Address Resolution Protocol）显示 **IP 地址 ↔ MAC 地址** 的映射表。它是**由 IP 地址查询 MAC 地址**的 Windows 命令（第 7、20 题）。

> **生活类比**：`arp` 表像公司的「花名册」——你只知道同事工号（IP），查花名册就知道他坐哪（MAC）。`arp -a` 就是翻出整本花名册看「谁对应谁」。

### 3.3 IP 安全策略：能「禁 ping」

**第 11 题（判断）**：通过启用本机的 **IP 安全策略（IPSec）** 可以**禁止**其它系统对本机的 PING 操作。→ **正确**。

原理：IPSec 策略可以过滤特定类型的包（比如 ICMP），把「回声」堵上，别人就 ping 不到你了。

> **生活类比**：`ping` 是喊话，IP 安全策略就是「禁止喧哗」的告示牌——贴上之后，别人喊你你不回，自然 ping 不通。

### 3.4 内嵌考点自测

**【自测 3】** 在 Windows 中，由 IP 地址查询 MAC 地址，应使用（  ）。
A. tracert　B. arp -a　C. ipconfig /all　D. netstat -s

> **解析**
> 🎯 答案解析：选 **B**。`arp -a` 显示 IP↔MAC 映射表，是由 IP 查 MAC 的命令。
> 📚 知识点讲解：ARP 协议负责「已知 IP 求 MAC」。`arp -a` 列出当前缓存的所有映射。
> 💡 解题思路：关键词「IP 查 MAC」 → `arp -a`（不是 `ipconfig`，那是看自己）。
> 🧠 记忆口诀：「IP 查 MAC，arp -a 它。」

**【自测 4】** 启用本机 IP 安全策略可以禁止其他计算机对本机进行 PING。这个说法（  ）。
A. 正确　B. 错误

> **解析**
> 🎯 答案解析：选 **A（正确）**。IPSec 策略可过滤 ICMP 包，从而禁 ping。
> 📚 知识点讲解：PING 基于 ICMP 协议，IP 安全策略能针对性拦截，实现「隐形」。
> 💡 解题思路：IP 安全策略 = 本机包过滤规则，能禁特定流量 → 正确。
> 🧠 记忆口诀：「IP 安全策略上，PING 进不来。」

## 模块四 · 路由与路径查看（route print / netstat -r / tracert）

### 4.1 路由表是什么

路由表是操作系统决定「数据包下一跳去哪」的地图。**第 10、23 题**：`route print` 命令可查看本机路由表。

> **生活类比**：路由表像你手机里的「导航收藏夹」——去公司走 A 路、去机场走 B 路。`route print` 就是把这张「导航图」打印出来给你看。

### 4.2 route print = netstat -r（等价命令，高频考点！）

**第 3、6、18、19 题**反复考：`route print` 和 `netstat -r` **功能完全相同**，都能显示路由表。`netstat -r` 就是 route print 的另一种写法。

| 命令 | 作用 | 备注 |
|------|------|------|
| `route print` | 显示路由表 | Windows |
| `netstat -r` | 显示路由表 | 与 route print **等价** |
| `tracert` | 显示到目标经过的每一跳 | 看「路径」不是看「表」 |

> ⚠️ **反直觉陷阱**：`netstat` 家族很多参数（`-a` 看连接、`-s` 看统计、`-n` 看数字），但**只有 `-r` 才是「看路由表」**。题目把 `netstat -r` 换成 `route print` 考你等价关系，记住「r = route = 路由表」。

### 4.3 tracert：追踪路径（不是看表）

`tracert`（trace route）利用 TTL 递增，显示数据包到目标**经过的每一跳路由器**。它和 `route print` 不同：一个是「实际走过的路」（tracert），一个是「本机地图上的路线」（route print）。

### 4.4 Linux 下同功能：netstat -nr

**第 8、21 题**：在 Linux 中，能显示本机网络路由信息的命令是 `netstat -nr`。`-n` 表示用数字显示（不解析主机名），`-r` 仍是「路由表」。

> **生活类比**：`route print`（Windows）和 `netstat -nr`（Linux）就像同一个导航 App 在安卓和苹果上的两个名字，干的活一模一样——都是「打印路由表」。

### 4.5 内嵌考点自测

**【自测 5】** 与 `netstat -r` 具有同等功能的命令是（  ）。
A. route print　B. ipconfig /all　C. arp -a　D. tracert -d

> **解析**
> 🎯 答案解析：选 **A**。`netstat -r` 与 `route print` 等价，都看路由表。
> 📚 知识点讲解：`netstat -r` 中 `-r` = routing，就是调出路由表，和 `route print` 输出一致。
> 💡 解题思路：记住「r=route=路由表」，等价命令就是 route print。
> 🧠 记忆口诀：「netstat -r，route print 替。」

**【追问】** `tracert` 和 `route print` 一样吗？
> 不一样！`route print` 看本机「地图」（路由表），`tracert` 看数据包「实际走了哪几跳」。一个静态一个动态。

## 模块五 · DNS 与 Linux 命令（nslookup / ifconfig）

### 5.1 nslookup：查 DNS 工作状态

**第 5、17 题**：采用 `nslookup` 命令查看**域名服务器（DNS）工作状态**。比如你输入 `www.baidu.com` 打不开，用 `nslookup www.baidu.com` 看 DNS 能不能解析出 IP。

> **生活类比**：DNS 像「电话簿」——把人名（域名）翻译成电话号码（IP）。`nslookup` 就是翻开电话簿查「这个名字能不能查到号」。查不到，说明电话簿（DNS）出问题了。

### 5.2 ifconfig：Linux 下的「ipconfig」

**第 4、16 题**：在 Linux 命令中，`ifconfig` 用来**显示和设置网络接口的配置信息**——相当于 Windows 的 `ipconfig`。

| 系统 | 看本机配置 | 看路由表 |
|------|-----------|---------|
| Windows | `ipconfig` | `route print` / `netstat -r` |
| Linux | `ifconfig` | `netstat -nr` |

> ⚠️ **易混点**：`ifconfig`（Linux）≠ `ipconfig`（Windows），只差一个字母，但分属不同系统。题目常把两者混着考，看清楚题干说「Linux」还是「Windows」。

### 5.3 内嵌考点自测

**【自测 6】** 在 Linux 中，用来显示和设置网络接口配置信息的命令是（  ）。
A. ifconfig　B. ipconfig　C. route　D. nslookup

> **解析**
> 🎯 答案解析：选 **A**。`ifconfig` 是 Linux 下查看/设置网卡配置的命令。
> 📚 知识点讲解：`ifconfig` = interface config；`ipconfig` 是 Windows 版（差一个字母）。题干中明确「Linux」，选 ifconfig。
> 💡 解题思路：关键词「Linux + 网络接口配置」 → `ifconfig`。
> 🧠 记忆口诀：「Linux 配接口，ifconfig 走。」

**【自测 7】** 查看域名服务器工作状态，应使用（  ）。
A. ipconfig　B. nslookup　C. netstat　D. route

> **解析**
> 🎯 答案解析：选 **B**。`nslookup` 专查 DNS 解析。
> 📚 知识点讲解：DNS 是域名解析系统，`nslookup`（name server lookup）就是为它而生的诊断工具。
> 💡 解题思路：关键词「域名服务器工作状态」 → `nslookup`。
> 🧠 记忆口诀：「DNS 好不好，nslookup 查。」

## 模块六 · 安全与管理命令（防火墙 / VPN / 证书 / cipher / 活动目录）

### 6.1 防火墙：内外网之间的「门卫」

**第 2 题**：关于防火墙，正确说法是——**防火墙是一个或一组在两个不同安全等级的网络之间执行访问控制策略的系统**。

错误说法要排除：
- ❌ 「防火墙通常处于企业局域网内部」 → 错，它在**边界**（内外网之间）
- ❌ 「用于禁止局域网内用户访问 Internet」 → 错，它是**按策略控访问**，不是单纯禁内网
- ❌ 「必须要有专用的硬件支持」 → 错，软件防火墙也存在

> **生活类比**：防火墙像小区大门的保安，站在「小区（内网）」和「马路（外网）」之间，按规矩放行或拦人。他不是小区里的住户，也不是只拦住户出门。

### 6.2 VPN：公共网络上的「加密专线」

**第 12 题（判断）**：**VPN 支持企业通过 Internet 等公共网络与分支机构或其他公司建立连接，进行安全通信。** → **正确**。

> **生活类比**：Internet 是公开的马路，谁都能看。VPN 就像在马路上给你和分公司之间拉了一根「加密管道」，外面的人看不清里面运的货，但你们俩能安全通信。

### 6.3 证书导出：浏览器里一步步点

**第 13 题**：证书导出步骤：浏览器中依次点击 **工具 → Internet 选项 → 内容 → 证书**。即「内容」选项卡里管理证书。

> **生活类比**：证书像你的「数字身份证」，要导出给别人用，得先到「身份证管理窗口」（内容选项卡）去拿。

### 6.4 活动目录安装：管理工具里配

**第 14 题**：安装活动目录的方法：**「管理工具」 / 「配置服务器」**。

> 活动目录（Active Directory）是 Windows 域的「户口本中心」，集中管理用户、计算机、权限。

### 6.5 cipher：创建数据恢复代理证书

**第 15 题**：在 Windows 中，使用 **`cipher`** 命令可以创建用于**数据恢复代理**的证书和私钥。

- `cipher` 原本是加密文件系统（EFS）管理命令
- `CHKDSK` 是磁盘检查，不是证书
- `netstat` 看连接/路由，`nslookup` 查 DNS，都不管证书

> **生活类比**：`cipher` 像保险柜的「备用钥匙管理员」——它生成的恢复代理证书，相当于给管理员一把能开所有人保险柜的「万能备用钥匙」（用于员工离职后恢复加密文件）。

### 6.6 边角题（了解即可）：Linux 开发环境

**第 1 题**：问「下面哪个环境是 Linux 系统下使用的」，答案 **A**（原始题库选项 OCR 严重乱码：A.GC.　B.VC.++　C.V++NET　D.B.uilD.er60，实际应为 GCC / VC++ / V++.NET / Builder6 之类，Linux 下用 GCC）。因选项损坏，**本题了解即可**，记住「Linux 下的编译环境是 GCC（对应选项 A）」即可，不必深究。

> 🧠 记忆口诀：「恢复代理证书，cipher 生。」

## 🃏 速查卡

| 命令 | 系统 | 作用 | 易混提醒 |
|------|------|------|---------|
| `ipconfig` | Windows | 看本机 IP/DHCP/DNS 配置 | `/all` 看全量含 MAC |
| `ifconfig` | Linux | 看/设网络接口配置 | 比 ipconfig 少一个 o，属 Linux |
| `ping` | 通用 | 测连通性（ICMP） | 能被 IP 安全策略禁掉 |
| `arp -a` | Windows | 由 IP 查 MAC（看映射表） | 不是 ipconfig |
| `route print` | Windows | 看路由表 | 等价于 `netstat -r` |
| `netstat -r` | 通用 | 看路由表 | = route print |
| `netstat -nr` | Linux | 看路由表（数字显示） | Linux 版 |
| `tracert` | Windows | 追踪到目标经过的每一跳 | 看「实际路径」，非「表」 |
| `nslookup` | 通用 | 查 DNS 工作状态 | 「域名服务器」专属 |
| `cipher` | Windows | 创建数据恢复代理证书 | EFS 相关，非磁盘检查 |

**关键等价关系**：`route print` ≡ `netstat -r`（看路由表）；Linux 下 `netstat -nr` 同理。

## ⚠ 反直觉陷阱（最容易选反）

1. **`netstat -r` = `route print`**：很多人以为 `netstat` 只管连接，其实 `-r` 是看路由表，和 `route print` 一毛一样。
2. **`ipconfig` ≠ 由 IP 查 MAC**：看自己用 `ipconfig`，由 IP 查邻居 MAC 用 `arp -a`，别混。
3. **`ifconfig`（Linux）≠ `ipconfig`（Windows）**：差一个字母，分属两系统，看题干。
4. **防火墙在「边界」不在「内网内部」**：它守内外网之间，不是局域网里的一台普通设备。
