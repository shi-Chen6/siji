# 模块一 Windows 系统安全基础

## 1.1 系统文件与安装:Windows 住在哪、怎么启动

**大白话解释**:Windows 系统文件默认安装在 **C:\Windows** 目录下(从 Windows 2000 以后都是这个约定)。从光盘全新安装系统时,要让电脑先"读光盘",需要在 CMOS(BIOS 设置)里把第一启动设备(Boot First Device)设为 **CD-ROM**。

> 🎯 **类比**:电脑开机就像"排队进闸机"——CMOS 决定"先让谁先进"(第一启动设备)。装系统时想让光盘先进,就把光盘排在队伍最前面;平时想让硬盘先进,就把硬盘排最前。

> 💡 **实际例子**:新电脑装 Windows 7,开机按 Del 进 BIOS,把 Boot 顺序调成光驱优先,插入系统光盘重启,电脑就从光盘启动开始安装了。装完再改回硬盘启动,不然每台都读光盘。

## 1.2 NTFS 文件系统:安全与效率兼得

**大白话解释**:Windows 支持 FAT、FAT32、NTFS 三种文件系统。**NTFS 是功能最强、最安全**的一种——服务器和重要电脑都要用它。

**NTFS 的优点(对比 FAT/FAT32)**:
1. **磁盘利用率高**:NTFS 的簇(分配单位)可以更小,减少空间浪费;
2. **访问速度快**:NTFS 使用索引结构(MFT),查找文件更快;
3. **支持安全控制**:可以对文件/目录设置权限、加密(EFS)、压缩。

> 🎯 **类比**:FAT 像**老式公共储物柜**——谁都能开、不分权限;NTFS 像**高档公寓的门禁系统**——每扇门谁可以进、谁只能看,都管得清清楚楚。

**Windows 服务器主机应对文件系统实施保护**,能实现这一要求的文件系统格式就是 **NTFS**(FAT/FAT32 没有权限控制能力)。

> ⚠️ **关于题库 #54 的说明**:该题 B 选项文字"硬盘"疑为转录乱码(原意应为"支持安全控制"之类),答案 ABC 不变,考试按答案作答即可。

## 1.3 注册表:Windows 的"中枢神经"

**大白话解释**:**注册表(Registry)** 是 Windows 保存系统配置、软件设置、硬件信息的大数据库——相当于 Windows 的"中枢神经/总账本"。

**进入注册表编辑器**:在"开始 → 运行"中输入 **regedit**,回车即可打开。

> 🎯 **类比**:注册表就像**人体的神经系统**——所有器官(软件/硬件)都要跟它"汇报"和"领命"。改错注册表,就像神经搭错线,系统可能"瘫痪"。

> ⚠️ 注册表很脆弱,改之前**一定要备份**,否则一个键值改错可能导致系统无法启动。

## 1.4 系统安全基础概念:漏洞、源码、存储保护

**大白话解释**:几个基础安全概念一次讲清:

**① 系统安全漏洞**——从系统整体看,安全漏洞包括:
- **产品缺少安全功能**(设计缺陷);
- **产品有 Bugs**(代码缺陷);
- **缺少足够的安全知识**(人的问题);
- **人为错误**(操作失误)。
> 🎯 **类比**:房子的安全漏洞不只是"门锁坏了"(Bugs),还包括"根本没装锁"(缺少安全功能)、"住户不知道要锁门"(缺安全知识)、"出门忘锁门"(人为错误)。

**② Windows 源代码**:**不公开**。Windows 是**闭源商业软件**,源代码由微软保密(开源的是 Linux)。
> 💡 **例子**:这正是"为什么大家都猜 Windows 有没有后门"的原因——因为代码不公开,只能靠外部测试发现漏洞。

**③ 存储保护**——操作系统安全的基本要求,采用**硬件和软件结合**处理:当发生越界或非法操作时,**硬件产生中断**,进入操作系统处理。
> 🎯 **类比**:小区安保 = 硬件(围墙+监控)+ 软件(保安巡逻)。有人翻墙(越界),监控(硬件)报警,保安(操作系统)来处理。

**④ 安全专用产品销售**——国家对计算机信息系统**安全专用产品**的销售**实行许可证制度**,不是随便卖。

**⑤ 等级保护《基本要求》**——分为技术和管理要求,技术要求包括:**物理安全、网络安全、主机系统安全、应用安全和数据安全**。

## 1.5 系统安全评估等级:TCSEC(了解)

**大白话解释**:**TCSEC(可信计算机系统评估标准)** 把计算机系统安全划分为 4 个大等级:**D、C、B、A**(从低到高)。

- **D 级**:最低,无保护;
- **C 级**:自主保护(有用户权限控制)——**UNIX 和 Windows NT 操作系统符合 C 级**(具体为 C2 级);
- **B 级**:强制保护;
- **A 级**:最高,验证保护。

> 🎯 **类比**:TCSEC 像**餐厅卫生评级**——从"无证经营"(D)到"五星级"(A)。UNIX 和 Windows NT 是"三星级"(C 级):有门禁(权限控制),但还不是全封闭的"最高安保"(A)。

## 2.1 Windows 用户组体系:谁管谁

**大白话解释**:Windows 用"用户组"来批量管理权限。**组**就像"职位",**用户**就像"员工"——员工进哪个组,就有什么权限。

**Windows 常见用户组(从高到低)**:
- **Administrators(管理员组)**:**管理权限最高**,能改系统、装软件、管所有用户——相当于"总经理";
- **Power Users(高级用户组)**:比管理员低一档(旧系统),能装部分软件;
- **Users(普通用户组)**:普通员工权限,只能用自己的文件;
- **Guests(来宾组)**:访客,权限最低。

**关键认知**:
- **Administrators 组权限最高**(考试必考);
- **Users 组可以创建本地组,但只能修改自己创建的本地组**(不能改别人的);
- **域控制器没有本地用户账户**——因为域账号都集中在活动目录里管理。

> 🎯 **类比**:公司里,Administrators 是**老板(最高权限)**,Users 是**普通员工**,Guests 是**访客**。员工(Users)可以自己建"小组"(本地组),但只能管自己建的那个组,管不了老板的组。

## 2.2 密码安全:密码策略三兄弟

**② 屏幕保护密码**:经典 Windows 的**屏幕保护程序密码不区分大小写**。

## 2.3 共享安全:共享是双刃剑

**大白话解释**:**共享(Share)** 让别的电脑能通过网络访问本机的文件夹,方便协作,但也可能成为**黑客进入本地系统的入口**——所以系统安全加固要管好共享。

**关键认知**:
- **Windows 系统安全加固**需要防止恶意用户利用**共享**作为进入本地系统的入口(共享开太多、权限太大 = 给黑客开门);
- **默认共享**(如 C$、ADMIN$):Windows 默认开启的管理共享,**关闭默认共享符合公司桌面终端管理要求**——❌"关闭默认共享不符合要求"是错的(关闭才是对的)。

> 🎯 **类比**:共享像**家门口的开放快递柜**——方便收件,但也可能被坏人顺手拿东西。安全做法:**只开该开的柜子(共享)、关掉默认全开的(默认共享)**。

## 3.1 域与域控制器:企业的"中央集权"

## 3.2 活动目录的结构:森林、域树、域、OU

**大白话解释**:**活动目录(Active Directory,AD)** 是域环境的"总数据库",它的**逻辑结构**分四层:

> **森林(Forest)> 域树(Domain Tree)> 域(Domain)> 组织单位(OU)**

- **森林**:最大的容器,包含所有域树;
- **域树**:共享连续命名空间的一组域;
- **域**:管理单元;
- **组织单位(OU)**:**活动目录中最小的管理单元**,用来分组管理用户/计算机(可以设组策略)。

> 🎯 **类比**:AD 结构像**一家大集团**——集团(森林)下面有多个子公司群(域树),每个子公司群下有子公司(域),子公司内部按部门分组(OU,最小的管理单元)。

**活动目录由 组织单元、域、域树 和 域林 构成层次结构。**

**活动目录的架构(AD Schema)**:定义 AD 中可以存储哪些"类和属性"。

## 3.3 配置文件:桌面环境的"随身行李"

**大白话解释**:域环境中,用户的桌面设置(壁纸、图标、收藏夹等)可以保存在不同配置文件中:

- **本地配置文件**:只保存在当前这台电脑上,换台电脑就没有了;
- **漫游配置文件(Roaming Profile)**:保存在服务器上,**无论用户在哪台电脑登录,都能获得上一次的桌面环境**,修改也能保存;
- **强制配置文件**:只读,用户改了不保存;
- **临时配置文件**:登录异常时临时生成。

> 🎯 **类比**:本地配置 = **东西锁在工位抽屉里**(换工位就没有);漫游配置 = **随身携带的行李箱**(在哪张工位都能打开同一个箱子,还能往里面加东西)。

> ⚠️ **关于题库 #52 的说明(重要)**:题目问"无论使用哪台计算机都能获得前一次登录使用的桌面环境,可修改并保存",标准答案应为**漫游配置文件**;题库给定答案为 C(本地配置文件),与标准知识矛盾,疑为题库错误。考试按题库答案作答,但**理解上务必记住:跨机器同步桌面环境靠漫游配置文件**。

# 模块四 组策略与安全策略

## 4.1 组策略基础:统一管控的"规章制度"

**大白话解释**:**组策略(Group Policy)** 是 Windows 域环境中的"统一规章制度"——管理员制定一套规则,批量应用到所有计算机/用户。

**组策略关键认知**:
1. **能做什么**:应用程序安装、控制面板限制等都能设置;
2. **不能做什么**:**操作系统版本更新**无法通过组策略完成(组策略管"配置",不管"升级系统版本");
3. **生效方式**:组策略更改后**立即生效**(客户端刷新策略后生效);
4. **适用版本**:**不是所有 Windows 版本都支持组策略**——仅专业版/企业版/服务器版支持,**家庭版没有组策略**;
5. **组策略包含两部分**:**"计算机配置"和"用户配置"**——一个管机器,一个管人。

> 🎯 **类比**:组策略像**公司规章制度**——管机器的(计算机配置)像"设备使用规定",管人的(用户配置)像"员工行为规范";规章制度(组策略)只在"正规公司"(专业版/服务器版)才有,"皮包公司"(家庭版)没有。

# 模块五 审计、日志与监控

## 5.1 审核策略:该记的账要记

**大白话解释**:**审核(Audit)** 是 Windows 的"记账功能"——把重要操作记到日志里,事后可查。

**审核策略建议**:
- 建议审核:**用户登录及注销、用户及用户组管理、系统重新启动和关机**等安全相关事件;
- **不建议审核**:**用户打开/关闭应用程序**——事件太频繁、量太大,全部审核不现实,还淹没重要记录。

> 🎯 **类比**:审核像**小区监控**——重点盯大门(登录)、门禁管理(用户组管理)、总电闸(重启关机);但"每户开关自家灯"(打开关闭应用)就不用都录了,录不过来也没意义。

## 5.2 Windows 日志类型:三类日志

**大白话解释**:Windows 的**事件日志**主要有三类:

1. **系统日志(System Log)**:记录系统组件事件(驱动、服务、硬件问题);
2. **安全日志(Security Log)**:记录安全相关事件(登录成功/失败、权限使用)——**审计记录就在这**;
3. **应用程序日志(Application Log)**:记录应用程序运行事件(程序崩溃、报错)。

> 🎯 **类比**:三类日志像**三本账**——系统日志是"设备运行台账",安全日志是"门禁出入记录",应用程序日志是"各软件的工作日志"。

> ⚠️ **注意**:Windows 日志**没有**"用户日志(UserLog)/账户日志"这种分类(常见陷阱选项)。

# 模块六 服务、应用与命令

## 6.1 IIS:Windows 的"服务生"

**大白话解释**:**IIS(Internet Information Services)** 是 Windows 自带的 Web/服务组件,用来提供 **Web 网站、FTP 文件传输**等服务。

**关键认知**:
- **提供 FTP 服务**:安装 **IIS 组件**即可创建 FTP 站点 ✅;
- **IIS 不能构建 DNS 服务器**:DNS 服务由 **DNS 服务器角色**提供,IIS 管不了 ❌(IIS6.0 构建 DNS 是错的);
- 干扰项识别:IE 是浏览器、Outlook 是邮件客户端、WMP 是播放器,都提供不了 FTP 服务。

## 6.2 匿名 FTP 与网络命令

**大白话解释**:
- **匿名 FTP**:允许用户不注册账号直接下载文件,**用户名固定用 `anonymous`**(或 ftp)。
- **tracert 命令**:追踪数据包到达目标主机的**路径(经过几跳)**。参数 `-h` 指定最大跳数。
  - 例:"查找从本地出发经过 5 跳到达名字为 abc 的目标主机的路径" → 命令为 **`tracert -h 5 abc`**(参数 -h 5 在前,目标主机在后)。
- **WinPcap**:Wireshark 抓包软件安装时可选装的组件,作用:**提供底层的抓包能力**(让网卡能捕获原始数据包)。不是 GUI、不是包过滤、不是分析增强。

> 🎯 **类比**:anonymous 像**访客通道**——不用办员工卡(账号),报一声"我是访客(anonymous)"就能进;tracert 像**查看快递轨迹**——看包裹经过哪些中转站(每跳),-h 5 就是"最多看 5 站"。

## 6.3 DHCP 服务与租约

## 7.3 杀毒与故障排查

**大白话解释**:
- **杀毒注意事项**:应及时升级杀毒软件;即使 Windows 系统下杀毒,也应制作一张 DOS 环境杀毒盘备用;杀完毒后及时打补丁。
- ⚠️ **不正确说法**:**"杀毒前应先对杀毒盘进行杀毒"**——杀毒盘应是**干净可信**的启动介质,不需要(也无法在干净状态下)对它杀毒;正确做法是用干净启动盘引导杀毒。
- **故障排查**:重装系统后无法添加网络打印机,报错"0x000003e3"——常见于 **Windows 7** 打印服务(Print Spooler)相关问题。

### ✏️ 真题演练 73(题库 #4)

**【单选】计算机杀毒时,说法不正确的是 ____。**
A. 应及时升级杀毒软件
B. 杀毒前应先对杀毒盘进行杀毒
C. 即使是在 Windows 系统下杀毒,也应制作一张 DOS 环境下的杀毒盘
D. 杀完毒后,应及时给系统打上补丁

<details><summary>📖 点击查看答案与解析</summary>

**答案:B**

**详细解析**:
1. A 对:及时升级杀毒软件(更新病毒库);
2. C 对:准备 DOS 环境杀毒盘,用于系统级杀毒;
3. D 对:杀完毒打补丁,防止再次感染;
4. **B 错(本题答案)**:杀毒盘本身应是**干净可信**的引导介质,不需要"先对杀毒盘杀毒"——这是不正确说法。

**结论**:选 **B**。
</details>

# ⚠️ 常见误区警示

1. **"所有/一定/任何"太绝对基本是错的**:如"组策略适用于任何 Windows 版本""关闭默认共享不符合要求"。
2. **剪切 ≠ 删除**:剪切进剪贴板,删除进回收站(S8 考点)。
3. **IIS 不等于一切服务**:IIS 提供 Web/FTP,**不能提供 DNS**(S23 考点)。
4. **域与工作组互斥**:一台电脑不能同时加入域和工作组(S79 考点)。
5. **默认共享要关**:关闭默认共享(C$、ADMIN$)是安全加固的正确做法(S80 考点)。
6. **密码长度看复杂性要求**:Windows XP 复杂性要求最短 6 位,不是 8 位(S2 考点)。
7. **Windows 日志只有三类**:系统、安全、应用程序;没有"用户日志/账户日志"(S30/S32 考点)。
8. **家庭版没有组策略**:组策略仅专业版/企业版/服务器版支持(S53 考点)。
9. **屏保密码不区分大小写**:不是"需要分大小写"(S52 考点)。
10. **Users 组权限有限**:可以建本地组,但只能改自己创建的那个组(S70 考点)。
