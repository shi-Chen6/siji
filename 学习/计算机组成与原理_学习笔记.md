## 📖 故事线：把电脑当「一家工厂」

电脑像一家工厂——控制器是厂长（发指令）、运算器是车间（算数）、存储是仓库（放料）、输入输出是收发室。9 个模块从“工厂全貌”拆到“拧螺丝排故障”，再把数据库、安全、布线收尾。

**生活类比**：厂长看“生产计数本”（程序计数器）决定下一步做啥；热门料放手边小货架（Cache）不用每次跑大仓（内存）。

**Q1. 字长是指CPU 一次可以处理的二进制的位数，它直接关系到计算机 的计算速度、速度等指标；运算速度是指计算机每秒能执行的指令条 数，通常以()为单位来描述。**

选项：A.Mb　B.Hz　C.MIPS　D.BPS

> **答案：C**

- **🎯 答案解析**：🎯 答案解析：选 <b>C</b>。运算速度＝每秒执行指令条数，单位 <b>MIPS</b>（百万条指令/秒）。
- **📚 知识点讲解**：📚 知识点讲解：字长是 CPU 一次处理的二进制位数（如 32/64 位），决定计算精度与速度；运算速度衡量 CPU 干活快慢，MIPS 是标准单位。Mb 是兆比特（带宽单位）、Hz 是频率、BPS 是比特率，都不对。
- **💡 解题思路**：💡 解题思路：关键词“每秒指令条数”→ 指令条数对应 MIPS。
- **🧠 记忆口诀**：🧠 记忆口诀：“运算速度看 MIPS，每秒百万条指令。”

**Q24. 十六进制92H的八进制表示为()。**

选项：A.442　B.222　C.234　D.444

> **答案：B**

- **🎯 答案解析**：🎯 答案解析：选 <b>B</b>。92H=10010010₂，三位一组 010 010 010＝<b>222₈</b>。
- **📚 知识点讲解**：📚 知识点讲解：十六→二→八：每 1 位十六进制＝4 位二进制，每 3 位二进制＝1 位八进制。92H=1001 0010，从右分组 010/010/010=222。
- **💡 解题思路**：💡 解题思路：先转二进制再三位一组→222→选 B。
- **🧠 记忆口诀**：🧠 记忆口诀：“十六转八先转二，三位一组 222。”
**Q12. 设机器字长为8,则-0的()表示为11111111。**

选项：A.反码　B.补码　C.原 码　D.移码

> **答案：A**

- **🎯 答案解析**：🎯 答案解析：选 <b>A</b>。8 位中 <b>−0 的反码＝11111111</b>（原码取反符号位不变）。
- **📚 知识点讲解**：📚 知识点讲解：反码里 +0=00000000、−0=11111111（两种 0）；补码里 0 唯一全 0。原码 −0=10000000。
- **💡 解题思路**：💡 解题思路：−0 全 1 是反码特征→选 A。
- **🧠 记忆口诀**：🧠 记忆口诀：“反码负零全是一，补码零唯全零。”

**Q3. 机器字长确定后，()运算过程中不可能发生溢出。**

选项：A.定点正整数X与定点正整数Y相加　B.定点负整数X 与定点负整数Y 相加　C.定点负整数X 与定点负整数Y 相减　D.定点负整数X 与定点正整数Y 相减

> **答案：C**

- **🎯 答案解析**：🎯 答案解析：选 <b>C</b>。两负整数相减（X−Y，X、Y 均负）结果不会超出负数范围，<b>不会溢出</b>。
- **📚 知识点讲解**：📚 知识点讲解：溢出发生在“正+正得负”或“负+负得正”。负−负 = 负+正，结果仍落在可表示区间，故不溢出。
- **💡 解题思路**：💡 解题思路：负减负等于负加正，符号不会翻反→不溢出，选 C。
- **🧠 记忆口诀**：🧠 记忆口诀：“负减负=负加正，符号不翻不溢出。”

## 模块3 CPU 组成与指令执行（Q4、Q15、Q19、Q5、Q6、Q17、Q16、Q20、Q61）

CPU = 运算器 + 控制器。取指令、译码、执行，靠程序计数器指路。

**Q4. CPU中不包括()。**

选项：A.直接存储器 ( DMA) 控制器　B.算逻运算单元　C.程序计数器　D.指令译码器

> **答案：A**

- **🎯 答案解析**：🎯 答案解析：选 <b>A</b>。<b>DMA 控制器不在 CPU 内</b>，它是独立的总线部件，负责外设与内存直接搬运数据。
- **📚 知识点讲解**：📚 知识点讲解：CPU 内含运算器（算逻单元 ALU）、控制器（程序计数器 PC、指令译码器、指令寄存器）。DMA 控制器是芯片组/外设侧的独立硬件。
- **💡 解题思路**：💡 解题思路：DMA 是直接存储器访问控制器，属外设总线部件，不在 CPU→选 A。
- **🧠 记忆口诀**：🧠 记忆口诀：“DMA 在 CPU 外，直接搬数据。”
