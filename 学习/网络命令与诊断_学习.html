1 模块一 为什么要用网络命令（诊断思路）

1.1 网络命令是「医生的听诊器」

电脑上不了网，肉眼看不见网线里发生了什么。网络命令把系统内部看不见的网络状态（IP 地址、路由表、DNS、连接情况）变成文字输出，让我们能「看见」问题出在哪。

生活类比：网络像人体血管系统——上不了网 = 某处「堵了」。医生不靠猜，用听诊器、验血、CT 逐项查；我们排查网络，也用 ipconfig 看「血压」、ping 测「心跳」、route print 看「路线图」。

1.2 黄金顺序：先本机 → 再网关 → 再远端

步骤看什么命令
本机配置网卡有没有 IP、DHCP 给了没ipconfig
本地连通网关通不通、邻居 MACping / arp -a
路径路由数据包走哪条路route print / netstat -r
域名解析DNS 服务器工作不nslookup
【自测1】当电脑「上不了网」时，第一步最该查的是（ ）
A. 直接重装系统　B. 先看本机有没有拿到 IP 地址　C. 立刻换路由器　D. 拔掉所有网线
▸ 显示解析
🎯 答案解析：选 B。排查讲究「由近及远」，先确认本机 IP 配置。 📚 知识点讲解：网络命令价值就是「先看清本机状态」。ipconfig 能立刻告诉我们 DHCP 有没有分配 IP——这是一切排查的起点。 💡 解题思路：问「第一步」，按顺序本机优先，选 B。 🧠 记忆口诀：「上网先查本机 IP，由近及远不抓瞎。」

2 模块二 Windows 基础查看命令（ipconfig）

2.1 ipconfig 是干什么的

ipconfig（IP Configuration）是 Windows 下查看本机网络配置最常用命令：本机 IP、子网掩码、默认网关、是否 DHCP 分配、DNS 服务器地址。 关键考点（第 9、22 题）：在 Windows 中可通过 ipconfig 查看 DHCP 服务器分配给本机的 IP 地址。

生活类比：ipconfig 像你家「门牌号登记表」。IP = 门牌号，子网掩码 = 范围归谁管，默认网关 = 出小区的门。DHCP 是物业自动发的门牌，ipconfig 就是去物业查「我的门牌号是几」。

2.2 常用用法与易混点

命令作用
ipconfig显示基本 IP 配置
ipconfig /all全部详细信息（含 MAC、DHCP 服务器、租约时间）
⚠ 易混点：ipconfig /all 能看到 MAC，但由 IP 查 MAC 要用 arp -a（模块三）。ipconfig 是「看自己」、arp 是「看邻居」。
【自测2】在 Windows 中，查看 DHCP 分配给本机的 IP 地址，应使用（ ）
A. nslookup　B. ifconfig　C. ipconfig　D. tracert
▸ 显示解析
🎯 答案解析：选 C。ipconfig 显示本机 IP 配置，含 DHCP 分配地址。 📚 知识点讲解：ipconfig 是 Windows 专属「本机配置查看器」；ifconfig 是 Linux 的（模块五）。 💡 解题思路：关键词「Windows + DHCP 分配 IP」 → ipconfig。 🧠 记忆口诀：「Windows 看本机，ipconfig 最行。」

3 模块三 连通性与地址解析（ping / arp -a / IP 安全策略）

3.1 ping：测「通不通」

ping 向目标发 ICMP 回显请求，看对方是否回应，是最基础的连通性测试工具。

生活类比：ping 像对着山谷喊「喂——」看有没有回声。有回声说明路通；没回声可能是对方不在、路断、或对方「捂耳朵不听」（被防火墙/安全策略禁了）。

3.2 arp -a：由 IP 查 MAC

arp -a（Address Resolution Protocol）显示 IP ↔ MAC 映射表，是由 IP 查 MAC 的 Windows 命令（第 7、20 题）。

生活类比：arp 表像公司「花名册」——只知道工号（IP）就查花名册知座位（MAC）。arp -a 翻出整本看「谁对应谁」。

3.3 IP 安全策略：能「禁 ping」

第 11 题（判断）：启用本机 IP 安全策略（IPSec） 可禁止其它系统对本机 PING。→ 正确。IPSec 能过滤 ICMP 包，把「回声」堵上。

⚠ 反直觉：很多人以为「禁 ping 是错的」——其实 IP 安全策略就是本机包过滤，能精准禁掉 ICMP，此题为正确。
【自测3】在 Windows 中，由 IP 地址查询 MAC 地址，应使用（ ）
A. tracert　B. arp -a　C. ipconfig /all　D. netstat -s
▸ 显示解析
🎯 答案解析：选 B。arp -a 显示 IP↔MAC 映射，是由 IP 查 MAC 的命令。 📚 知识点讲解：ARP 协议负责「已知 IP 求 MAC」；arp -a 列出当前缓存映射。 💡 解题思路：关键词「IP 查 MAC」 → arp -a（不是 ipconfig）。 🧠 记忆口诀：「IP 查 MAC，arp -a 它。」

4 模块四 路由与路径查看（route print / netstat -r / tracert）

4.1 路由表与 route print

路由表是系统决定「数据包下一跳去哪」的地图。第 10、23 题：route print 可查看本机路由表。

生活类比：路由表像手机「导航收藏夹」——去公司走 A 路、去机场走 B 路。route print 就是把这张「导航图」打印出来。

4.2 route print = netstat -r（等价命令，高频考点！）

第 3、6、18、19 题反复考：route print 和 netstat -r 功能完全相同，都显示路由表。

命令作用备注
route print显示路由表Windows
netstat -r显示路由表与 route print 等价
tracert显示到目标经过的每一跳看「路径」不是看「表」
⚠ 反直觉陷阱：netstat 家族很多参数（-a 看连接、-s 看统计、-n 看数字），但只有 -r 才是「看路由表」。记住「r = route = 路由表」。

4.3 Linux 下同功能：netstat -nr

第 8、21 题：Linux 中能显示本机网络路由信息的命令是 netstat -nr（-n 数字显示，-r 仍是路由表）。

图：route print ≡ netstat -r；Linux 下用 netstat -nr
【自测5】与 netstat -r 具有同等功能的命令是（ ）
A. route print　B. ipconfig /all　C. arp -a　D. tracert -d
▸ 显示解析
🎯 答案解析：选 A。netstat -r 与 route print 等价，都看路由表。 📚 知识点讲解：netstat -r 中 -r = routing，调出路由表，输出等同 route print。 💡 解题思路：记住「r=route=路由表」，等价命令即 route print。 🧠 记忆口诀：「netstat -r，route print 替。」

5 模块五 DNS 与 Linux 命令（nslookup / ifconfig）

5.1 nslookup：查 DNS 工作状态

第 5、17 题：采用 nslookup 查看域名服务器（DNS）工作状态。打不开网页时，用它看 DNS 能不能解析出 IP。

生活类比：DNS 像「电话簿」把人名（域名）翻成号码（IP）。nslookup 就是翻开电话簿查「这个名字能不能查到号」。

5.2 ifconfig：Linux 下的「ipconfig」

第 4、16 题：Linux 中 ifconfig 用来显示和设置网络接口配置信息——相当于 Windows 的 ipconfig。

系统看本机配置看路由表
Windowsipconfigroute print / netstat -r
Linuxifconfignetstat -nr
⚠ 易混点：ifconfig（Linux）≠ ipconfig（Windows），只差一个字母，分属不同系统。看题干说「Linux」还是「Windows」。
【自测6】在 Linux 中，用来显示和设置网络接口配置信息的命令是（ ）
A. ifconfig　B. ipconfig　C. route　D. nslookup
▸ 显示解析
🎯 答案解析：选 A。ifconfig 是 Linux 下查看/设置网卡配置命令。 📚 知识点讲解：ifconfig = interface config；ipconfig 是 Windows 版（差一个字母）。 💡 解题思路：关键词「Linux + 网络接口配置」 → ifconfig。 🧠 记忆口诀：「Linux 配接口，ifconfig 走。」
【自测7】查看域名服务器工作状态，应使用（ ）
A. ipconfig　B. nslookup　C. netstat　D. route
▸ 显示解析
🎯 答案解析：选 B。nslookup 专查 DNS 解析。 📚 知识点讲解：DNS 是域名解析系统，nslookup（name server lookup）即其诊断工具。 💡 解题思路：关键词「域名服务器工作状态」 → nslookup。 🧠 记忆口诀：「DNS 好不好，nslookup 查。」

6 模块六 安全与管理命令（防火墙 / VPN / 证书 / cipher / 活动目录）

6.1 防火墙：内外网之间的「门卫」

第 2 题：正确说法——防火墙是一个或一组在两个不同安全等级的网络之间执行访问控制策略的系统。错误项：A（应在边界非内网内部）、B（按策略控访问非单纯禁内网）、C（软硬皆可，非必须硬件）。

生活类比：防火墙像小区大门保安，站在「小区（内网）」与「马路（外网）」之间按规矩放行/拦人。他不是小区住户，也不只拦住户出门。

6.2 VPN / 证书 / 活动目录 / cipher

考点要点
VPN（第12题·判断）借 Internet 等公共网络与分支/他司建加密连接，安全通信 → 正确
证书导出（第13题）工具 → Internet 选项 → 内容 → 证书
活动目录（第14题）安装方法：「管理工具」/「配置服务器」
cipher（第15题）创建数据恢复代理的证书和私钥（EFS 相关；CHKDSK/netstat/nslookup 均无关）
生活类比：cipher 像保险柜「备用钥匙管理员」——生成的恢复代理证书等于给管理员一把开所有人保险柜的「万能备用钥匙」（用于员工离职后恢复加密文件）。
⚠ 边角题（了解即可）：第 1 题问「Linux 下的开发环境」，答案 A（原题 OCR 严重乱码，原意为 GCC）。Linux 下用 GCC 编译，记住即可，不必纠结损坏选项。

🎯 答案解析：选 D。防火墙本质是在不同安全等级网络间做访问控制的系统。 📚 知识点讲解：A/B/C 都是常见错误描述。防火墙位于边界，按策略控访问，软硬皆可。 💡 解题思路：找「正确」的——只有 D 是防火墙标准定义。 🧠 记忆口诀：「防火墙守边界，访问控制它裁决。」
【自测9】在 Windows 中，创建用于数据恢复代理的证书和私钥，使用（ ）命令。

🃏 速查卡与反直觉陷阱

速查卡

命令系统作用易混提醒
ipconfigWindows看本机 IP/DHCP/DNS/all 看全量含 MAC
ifconfigLinux看/设网络接口比 ipconfig 少一个 o
ping通用测连通（ICMP）能被 IP 安全策略禁
arp -aWindows由 IP 查 MAC不是 ipconfig
route printWindows看路由表≡ netstat -r
netstat -r通用看路由表= route print
netstat -nrLinux看路由表（数字）Linux 版
tracertWindows追踪每一跳看路径非看表
nslookup通用查 DNS域名服务器专属

反直觉陷阱（最容易选反）

  • netstat -r = route print：netstat 不只是看连接，-r 是看路由表，与 route print 一毛一样。
  • ipconfig ≠ 由 IP 查 MAC：看自己用 ipconfig，由 IP 查邻居 MAC 用 arp -a。
  • ifconfig（Linux）≠ ipconfig（Windows）：差一个字母，分属两系统。
  • 防火墙在边界不在内网内部，且不必须硬件。
  • tracert ≠ route print：一个动态追路径，一个静态看表。
  • IP 安全策略能禁 PING：正确，别当错。
  • VPN 借 Internet 建安全连接：正确。
  • 第 1 题了解即可：Linux 下编译环境为 GCC（选项 OCR 损坏）。
