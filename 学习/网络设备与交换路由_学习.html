1 模块一 网络设备总览与 OSI 分层

1.1 常见设备与它们"在哪一层干活"

网络设备按 OSI 分层，记住"越低层越傻、越高层越聪明"：

设备工作的层一句话定位
中继器 / 集线器物理层（第1层）只放大复制信号，所有口共享一条总线，整机一个冲突域
网桥 / 交换机数据链路层（第2层）按 MAC 地址精准派件，每端口一个冲突域
路由器网络层（第3层）按 IP 地址跨网络投递，隔离广播域
网关传输层及以上连接两个"语言不通"的异构系统
生活类比：把 OSI 想成快递公司 departments——物理层是"搬运工"（只把包裹从 A 搬到 B），数据链路层是"本市分拣员"（按门牌 MAC 派件），网络层是"跨市邮局"（按邮编 IP 投递），网关是"翻译官"（把中文快递单翻成英文交给外国公司）。
图：设备分层——越低层越"傻"（只搬信号），越高层越"聪明"（看懂内容）

1.2 冲突域与广播域

冲突域：同一时间只能一台设备发数据、否则"撞车"的范围。集线器所有口共享一个冲突域；交换机每个端口一个冲突域。广播域：广播帧能到达的范围。交换机整机是一个广播域；路由器不转发广播，能分隔广播域。

生活类比：冲突域像"一条单行道"——两辆车同时上就撞；广播域像"一个广播喇叭覆盖范围"。交换机给每户单独开一条道（分冲突），但喇叭声整栋都听得见（不分广播）；路由器像隔音墙，喇叭声过不去（分广播）。
【自测1】下面关于网桥和交换机的论述，正确的是（ ）
A. 网桥端口比交换机少所以转发快　B. 交换机是多端口网桥，网桥通常只有两个端口　C. 交换机不转发广播帧而网桥转发　D. 都增加冲突域大小
▸ 显示解析
🎯 答案解析：选 B。交换机本质就是"多端口的网桥"。 📚 知识点讲解：网桥和交换机都工作在第二层，都靠 MAC 转发、都分割冲突域；区别只在"口多少"。两者都转发广播帧，也都不增大冲突域。 💡 解题思路：A 错（快慢不取决于口少）；C 错（都转发广播）；D 错（是分割而非增大）；仅 B 对。 🧠 记忆口诀："交换机 = 多口网桥；广播都转发，冲突都分割。"
【自测2】一个 48 端口交换机，冲突域和广播域个数分别是（ ）
A. 1,1　B. 48,48　C. 48,1　D. 1,48
▸ 显示解析
🎯 答案解析：选 C。冲突域 48（每口一个），广播域 1（整机一个）。 📚 知识点讲解：交换机每端口独立处理冲突 → 48 个冲突域；广播帧泛洪到所有端口 → 整台同属一个广播域。 💡 解题思路：交换机"分冲突、不分广播"，冲突域=端口数，广播域=1。 🧠 记忆口诀："口数即冲突域，整机一个广播域。"

2 模块二 交换机工作原理

2.1 交换机怎么"派件"：MAC 地址与映射表

交换机内部有"端口 ↔ MAC 地址映射表"，靠两种方式建立：地址学习（动态）——收到帧时记"来源 MAC + 入端口"；手工添加——管理员写静态表项。转发依据：二层交换机根据 MAC 地址（不是 IP）转发。端口还能绑定 MAC 地址做接入控制。

生活类比：交换机像公司前台，记住"张三在 3 号工位（端口3）"。来包裹写"张三"，查表从 3 号口递进去；新人不认识就先广播"张三在哪"，记住后再精准投递。

2.2 带宽、架构与图元

最大带宽 = 所有端口带宽之和（全双工下每口独享）；架构优点：箱体模块式（维修方便/配置灵活/高可靠→"以上都是"）、模块化（各模块分别规划扩展）；交换机图元含二/三/ATM 交换机，电话交换机不算。

2.3 网线怎么接：直连线 vs 交叉线

交叉线（一端 568A、一端 568B）：接同类设备——PC↔PC、交换机↔交换机（非 Uplink）。直连线：接异类设备——PC↔交换机、PC↔路由器、交换机↔路由器。级联特例：下级有 Uplink 口时用直连线连上级普通口。

图：同类设备用交叉线，异类设备用直连线；下级有 Uplink 口时用直连线

3 模块三 VLAN 虚拟局域网

3.1 什么是 VLAN

VLAN 把逻辑上相关的一批用户/端口划成组，不一定物理连同一台设备。核心特征：是同一广播域内的一组端口；能逻辑地划分网段（最大优点）；建立 VLAN 主要提高管理效率。

生活类比：同一栋楼，财务在 3 层、研发在 5 层，老板要"财务互发广播、别打扰研发"——VLAN 像给两部对讲机编到同一频道，物理位置不重要，逻辑分组才重要。

3.2 VLAN 编号与 Trunk

VLAN ID 范围 0–4095：0 和 4095 保留，可用 1–4094。vlan 1 是默认 VLAN 不能删。跨交换机同 VLAN 互通靠 Trunk 端口，跨厂家标准是 802.1q。易错：Trunk 的 PVID 可改、且并非所有帧都带 VLAN ID（无标签帧打上 PVID）。

3.3 交换机配置模式

配置管理地址必须在 Switch(config-if)# 接口模式；同 VLAN 内主机通过广播互通。

⚠ 反直觉陷阱：很多人以为 vlan 随便删——vlan 1 是默认 VLAN，绝对不能删（no vlan 1 无法执行）。Trunk 上"无标签帧"不打 VLAN ID 也照传，别误以为"Trunk 上帧都带 ID"。

🎯 答案解析：选 A。VLAN 核心价值是"逻辑划分网段、方便管理"。 📚 知识点讲解：VLAN 在一个广播域内部做逻辑分组，不减少广播域数量（广播域靠路由器分隔），也不改变冲突域。 💡 解题思路：VLAN = "逻辑划网段"，其他三项均不符。 🧠 记忆口诀："VLAN 优在逻辑划，不管冲突与广播。"

4 模块四 路由器与路由基础

4.1 路由器是干嘛的

连接"逻辑上分开的多个网络"；是网络层设备（丰富接口、支持多种路由协议）；主要作用：实现多个局域网互联、实现内外网连接；不同网络层协议转换也靠路由器。因特网互连核心就是路由器。

4.2 路由器的"缺点"与转发

缺点：可能成为网络瓶颈（转发差致卡滞）。转发依据路由表（查看网络地址），IP 不合法直接丢弃。

4.3 默认路由（缺省路由）

内部网络对外只有一个出口时最好配缺省路由。命令：ip route 0.0.0.0 0.0.0.0 下一跳。用路由器分段优点：不转发广播帧，避免广播风暴（但路由器并不更便宜/更快，也不"禁止所有广播"）。

⚠ 反直觉陷阱：路由器分段优点只有"隔离广播防风暴"是真话。选项里"路由器更便宜 / 更快 / 禁止所有广播"都是坑，别选。

▸ 显示解析
🎯 答案解析：选 A。路由器三层设备不转发广播，能隔离广播域防风暴。 📚 知识点讲解：路由器工作 IP 层，广播帧不过路由，分段后遏制广播泛滥。B/C 无依据；D 错在"禁止所有广播"。 💡 解题思路：路由器分段核心价值 = "隔离广播防风暴"，仅 A 符合。 🧠 记忆口诀："路由分段，广播不过、风暴不来。"

5 模块五 路由协议（RIP / OSPF / BGP / EIGRP）

5.1 静态路由与路由权值

静态路由由管理员手动配置；路由权值（metric）衡量"哪条路好"，可基于单/多属性，各协议算法不同；路由表含目的/下一站/距离等，不含"时钟"。

5.2 RIP（距离矢量）

按跳数算 metric；最大 15 跳（16 不可达）；默认更新 30 秒；路由保持防环；180 秒未更新变不可达；RIP-1 不支持手工聚合；只关心距离和方向。

图：RIP 核心参数一览

5.3 OSPF（链路状态）

不是距离矢量，是链路状态协议；cost 范围 1–65535；单区域LSDB 相同、路由表不同；Full = 拓扑库同步；DR/BDR 选举：优先级 0 一定不参选；接口类型 HDLC→P2P、ATM→NBMA；链路故障发 link-state update。

⚠ 反直觉陷阱：OSPF 是链路状态不是距离矢量（Q96 的 A 是错误说法）。单区域里路由表各不相同（虽然 LSDB 相同）。

5.4 BGP 与 EIGRP

BGP：在 AS 之间传播路由；公认属性 Origin / AS_PATH / Next_Hop / Local_Pref（MED 非公认）。EIGRP：思科专有。多路径复杂域间控路由用 BGP 最有效。

6 模块六 链路聚合 · 四层交换 · 安全

6.1 链路聚合

把多条物理链路绑成一条逻辑链路：增加带宽、负载均衡、提高可靠性。注意不能避免环路（防环靠生成树 STP）。

生活类比：原来单车道堵，现在并成三车道——更宽（带宽）、车流分摊（均衡）、一条施工还有两条能用（可靠）。

6.2 四层交换

第四层交换：不仅看源/目的地址，还根据数据包内容（端口/应用）决定策略。二层看 MAC、三层看 IP、四层看端口/应用。

6.3 安全设备与机制

防火墙：内外网间检查威胁、控访问抵御攻击；嗅探器：混杂模式收所有帧；IDS：需端口镜像；防 IP 欺骗：RPF 反查 + IP-MAC 绑定；防病毒端口：关 135/445/1433，别关 22（SSH）；上网行为管理：路由 > 网桥 > 旁路。

⚠ 反直觉陷阱：链路聚合不防环（防环是 STP 的事）。嗅探器混杂模式是"全收"不是"只收本机"。IDS 靠端口镜像而非端口映射/混杂模式。

▸ 显示解析

反直觉陷阱（最容易选反）

  • 交换机在第二层，不是第三层（Q82 说"第三层易广播风暴"是错的）。
  • 路由器分段优点只有"隔离广播"，不是更便宜/更快（Q23 的 B/C/D 都是坑）。
  • vlan 1 不能删（很多人以为随便删）。
  • Trunk 上并非所有帧都带 VLAN ID（无标签帧打 PVID）。
  • RIP 最大 15 跳，不是更大（16 跳即不可达）。
  • OSPF 是链路状态，不是距离矢量（Q96 的 A 是错误说法）。
  • BGP 的 MED 不是公认属性（Q49 公认属性不含 MED）。
  • Q98 存疑：题库标"传输层以上互连设备"答案为 A 路由器，但标准应为 C 网关（网关才工作在传输层以上连接异构系统）。考试以题库为准，学习以正确概念为准。
