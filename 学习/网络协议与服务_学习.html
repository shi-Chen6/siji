1 模块1 分层模型与基础概念（协议是什么）

1.1 网络分层：各司其职的「快递流水线」

网络太复杂，于是把它拆成一层层，每层只管一件事。OSI 七层模型是理论标准，TCP/IP 四层模型是实际使用的（考试更常考四层）。

TCP/IP 层对应 OSI 层干的事典型协议 / 设备
应用层5-7 层直接为用户干活HTTP、FTP、SMTP、POP3、DNS、SNMP、Telnet、SSH、DHCP
传输层4 层端到端可靠传输TCP、UDP
网际层3 层寻址与路由IP、ICMP、ARP、路由协议（BGP 等）
网络接口层1-2 层物理收发与帧传输以太网、PPP、802.11、交换机
生活类比：OSI 像「公司部门说明书」（理论 7 个部门），TCP/IP 像实际干的 4 个大组。分工明确：应用层“写什么”，传输层“怎么送得稳”，网络层“送到哪”，链路层“怎么搬上车”。
⚠ 高频定位题：路由器＝网络层（查 IP 路由表）；交换机＝数据链路层（查 MAC 表）；TCP＝传输层；HTTP/FTP/Telnet/SSH/DNS/SNMP 等＝应用层；ICMP＝网络层（不算路由协议）。

1.2 协议与端口：共同语言 + 门牌号

协议是通信双方约定的“共同语言”（格式+规则）；端口是主机上每个服务的“门牌号”，如 FTP=21、SSH=22、Telnet=23、SMTP=25、DNS=53、TFTP=69、HTTP=80、POP3=110、HTTPS=443、SNMP=161/162、BGP=179、DHCP=67/68。

1.3 端口工作模式：单工 / 半双工 / 全双工

三种模式：单工只能一个方向（收音机）、半双工轮流说（对讲机）、全双工同时双向（电话）。

1.4 电路交换 vs 分组交换

电路交换＝打电话，先占一条专用线路（PSTN）；分组交换＝快递分拣，数据切成包各自找路（帧中继 FRN、ATM、X.25、IP 网络）。

2 模块2 应用层协议群（一）：网页 · 文件 · 自动配置 · 域名

2.1 HTTP / HTTPS / URL：上网三件套

HTTP＝超文本传输协议，网页浏览的基础（选项陷阱：它不是资源定位器，也不是文件/远程登录协议）。HTTPS＝HTTP + SSL 加密。URL 结构＝协议://主机名.域名/路径，如 http://www.abc.com/html/index.asp；地址栏输域名默认走 HTTP；www 是主机名，abc.com 才是域名。

HTTP 方法含义
GET获取 URL 标识的资源
POST向指定资源提交数据（表单/上传），数据在请求体
DELETE请求服务器删除资源
CONNECT向服务器发出连接请求（代理隧道；注意是 CONNECT 不是 CONNET）

HTTP 状态码共 5 类：1xx 信息、2xx 成功（200）、3xx 重定向、4xx 客户端错误、5xx 服务器错误（“四类”是错的）。

2.2 FTP / TFTP：文件传输两兄弟

FTP（端口 21）可靠传文件：put 上传、get 下载、dir 列目录；浏览器访问 FTP 站点必须带 ftp:// 前缀。TFTP（端口 69）简单版，跑在 UDP 上，不加密。

2.3 DHCP：自动发 IP 的「物业」

DHCP（动态主机配置协议）自动下发 IP、子网掩码、网关、DNS。四步 DORA：Discover（找）→ Offer（给）→ Request（要）→ Ack（确认）——Offer 只是“预分配”，收到 Ack 才能真正使用 IP。地址有租约，期满收回；服务器等固定设备用保留地址；大型网络每子网至少一台 DHCP（或中继）；Linux 配置文件 /etc/dhcpd.conf；开机得到 169.254.x.x 说明 DHCP 没成功。

2.4 DNS：查名字的「电话簿」

DNS 负责“域名 → IP”。解析顺序：本地缓存（最快）→ 本地 DNS → 根/权威服务器。Windows 的 DNS Client 服务负责本地缓存解析结果。DNS 根服务器被攻击会把正常域名解析到错误地址（域名劫持）。

3 模块3 应用层协议群（二）：邮件与网络管理

3.1 电子邮件：SMTP 发、POP3 收

SMTP（端口 25）负责发送邮件；POP3（端口 110）负责接收邮件（Outlook/Foxmail 收信用它）；IMAP 也是收信协议（在线同步）。邮箱地址结构：账号 @ 域名，如 linxin@mail.ceiaec.org。

3.2 邮件与交易安全：MIME / S-MIME / PGP / SET

协议作用
MIME邮件内容扩展：支持文本、图像、声音、视频
S/MIME基于 PKI 的安全邮件（加密＋数字签名）
PGP安全传输电子邮件（个人邮件加密）
SET安全电子交易协议（网上支付）

3.3 SNMP：网络管理员的「监控探头」

SNMP（简单网络管理协议）用 UDP（161 查询 / 162 上报），轻量不增加网络负载。代理主动上报的报文叫 Trap；SNMPv2 引入通知报文（Inform）和管理站数据库支持分布式管理；SNMPv3 已支持加密认证（“所有版本都明文”是错的）。不用 SNMP 时应该关闭它。

4 模块4 网络层与地址解析：IP · ARP · ICMP · 路由

4.1 ARP：把 IP 翻译成 MAC

ARP（地址解析协议）把 IP 地址解析为物理地址（MAC）（反向是 RARP，域名是 DNS）。MAC 不在表中时，主机向整个局域网发 广播请求“谁是 x.x.x.x？”，目标单播应答——记住“请求广播、应答单播”。免费 ARP 是主机查自己的 IP（防冲突）。PPP 点对点链路不需要 ARP。

4.2 ICMP 与 ping：测连通的「回声」

ping 基于 ICMP 协议（网络层）：发 Echo Request（回显请求），对方回 Echo Reply（回显应答）。ping -l 指定报文字节数。ICMP 封装在 IP 数据报中传送，它不是路由协议。

4.3 traceroute：看每一跳

traceroute 发探测包，中间路由器回 ICMP 超时，到达目的主机时回 ICMP 端口不可达——所以“收到端口不可达＝到站了”。它还能结合 IP 库获取主机地理位置。

4.4 路由：谁给数据包指路

路由器负责寻路转发；让两个协议相同但中间隔着异构协议的网络互通，一般用路由技术。BGP4（边界网关协议）跨自治系统交换路由，报文封装在 TCP（179）中传送。

5 模块5 传输层：可靠快递 TCP vs 轻快 UDP

5.1 TCP：可靠快递（面向连接）

TCP 面向连接、可靠传输。三次握手：① 客户端发 SYN ② 服务器回 SYN/ACK ③ 客户端回 ACK（第二步就是“服务器根据客户端 SYN 回复 SYN/ACK”）。TCP 头包含源端口、目的端口、序号等——TTL 属于 IP 头，不在 TCP 头里。

5.2 TCP vs UDP 速查

对比项TCPUDP
连接面向连接无连接
可靠性可靠（确认重传）不可靠（应用自己负责可靠性）
代表协议HTTP、Telnet、FTP、SMTP、BGPTFTP、DNS、SNMP、DHCP

5.3 流量控制 ≠ 拥塞控制

滑动窗口解决端到端流量控制（防止发送太快压垮接收方），不能解决网络中间设备拥塞（那是拥塞控制的事）。端口扫描手法：TCP SYN 扫描（半开）、FIN 扫描等都是典型类型。

6 模块6 安全协议与远程管理：加密 · 远程 · 边界

6.1 SSL / HTTPS：给传输上锁

SSL（安全套接层协议）为 Web 等应用提供加密；HTTPS 用 SSL；SSL 分握手协议和记录协议，压缩功能可选；通常只需服务器证书（“要求双方都提供证书”是错的）。浏览器内置支持 SSL。

6.2 远程管理：Telnet vs SSH

协议端口特点
Telnet23明文传用户名密码（最大缺陷）、易被会话劫持、可被 SSH 替代；老设备只能用 Telnet 时须加固
SSH22加密安全连接，嗅探/劫持免疫，可替代 Telnet

6.3 无线与接入安全：WEP → 802.11i

802.11 定义了最早的安全协议 WEP（已不推荐）；802.11i（WPA2）采用 802.1x 认证 + 改进密钥架构 + AES 加密，大大加强 WLAN 安全；802.1x 是基于端口的认证协议。注意 802.11a 工作在 5GHz（不是 2.4GHz），覆盖更小。

6.4 防火墙：守边界不查内容

防火墙是两个不同安全等级网络之间执行访问控制策略的系统，在边界不在内网内部，软硬皆可。状态检测能查源/目的 IP、端口、协议号，不能查数据包内容；包过滤防火墙不能“禁止某 IP 使用某 FTP 命令”（那是应用层的事）。网上邻居可见但 ping 不通→对方防火墙挡了 ICMP。

6.5 扫描与会话安全

TCP SYN 扫描利用 Socket 连目标端口侦测端口状态与服务缺陷；FIN 扫描是另一典型手法。会话劫持最喜欢攻击明文无校验的 Telnet；SSH/HTTPS/SFTP 有加密与完整性校验，劫持困难。

6.6 认证与密钥：CHAP 与 Diffie-Hellman

CHAP 三次握手验证：第一次由验证方生成随机报文＋自己的用户名发给被验证方，随机挑战防重放。Diffie-Hellman 可以在不安全的通信信道中安全交换密钥。

7 模块7 数据链路层/物理层与综合规范

7.1 数据链路层：以帧为单位

数据链路层同步协议以 帧 为传输信息单位（物理层传“位”、网络层传“报文”）。交换机做帧交换，查 端口号/MAC 地址映射表决定从哪个端口转发。

7.2 广域网与点对点：PPP / PPPoE / ATM / 帧中继

技术要点
PPP点到点协议，同步/异步线路上封装数据的数据链路层协议
PPPoE分两个阶段：发现阶段、会话阶段（拨号上网）
ATM信元固定 53 字节＝头 5 + 净荷 48
帧中继 FRN分组交换网络的代表（PSTN 是电路交换）

7.3 VLAN：逻辑分区

VLAN 划分方式：基于端口、基于 MAC、基于网络层协议、按策略划分——不包括“基于 IP 地址”。

7.4 安全管理综合（边角题集中营）

  • 错误报告只应包含自定义错误代码，不泄露主机/版本/DNS 信息。
  • 第三方终端管理：备案登记、专人陪同、安全检测、满足防病毒补丁策略。
  • 数据库默认口令（sys、system、aqadm、Dbsnmp）全部要改。
  • 网络服务提供者办接入须实名制；关键岗位人员应从内部选拔并定期信用审查。
  • 应用系统至少监控：主机连通性、中间件端口、数据库端口。
  • 设备选型要考虑价格（“不用考虑价格”是错的）。
  • 被动威胁＝数据流分析（只看不改）；主动威胁＝拒绝、假冒、更改。
  • NIS 服务器通常包括：主服务器、二级服务器、从服务器、域名服务器。

③ 反直觉陷阱（最容易选反）

  • SMTP 是发信不是收信：收信用 POP3/IMAP。
  • SSL 是加密的：题干若说“明文传输是 SSL”，大概率 OCR 反转（Q95 题库答案为 B，原理上 SMTP 才明文）。
  • SNMP v3 已加密：不是所有版本都明文。
  • ARP 应答是单播：只有请求是广播。
  • TTL 在 IP 头：不在 TCP 头。
  • 滑动窗口管流量控制：管不了中间设备拥塞。
  • 169.254 → DHCP 故障：先查 DHCP 服务器。
  • TCP 状态码是 5 类：不是 4 类。
  • ping 基于 ICMP：不是 TCP/UDP。
  • BGP 用 TCP 承载：不是 UDP。
  • 新设备只能 Console 串口配置：没 IP 前 Telnet/浏览器都不行。
  • 隔离装置＝分析＋过滤＋转发；防火墙状态检测查不了内容。
