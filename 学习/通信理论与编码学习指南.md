# 模块一 通信基础:信号、带宽与速率

## 1.1 什么是通信?

**通俗理解**:通信就是"把信息从一处送到另一处"。你给朋友发微信、打电话、看视频,本质都是在通信——把文字、声音、画面"搬运"到对方那里。

一次通信,离不开三样东西:

- **发送方**(信息从哪里来)
- **信道**(信息走的路,比如网线、光纤、无线电波)
- **接收方**(信息到哪里去)

举个最日常的例子:**打电话**。你(发送方)的声音变成电信号,沿着电话线(信道)传到对方手机(接收方),对方听到你的声音——这就是一次通信。

## 1.2 模拟信号 vs 数字信号:连续的水流 vs 开关的灯

信号是信息的"载体"。信号分两大类:

**🔵 模拟信号**
- 特点:**连续变化**,像水流一样平滑。
- 例子:老式电话里你的声音、广播电台的无线电波、老式录音磁带。
- 形象比喻:模拟信号就像**音量旋钮**——可以转到 0、1、2……50、100 任意位置,变化是连续的。

**🟢 数字信号**
- 特点:**离散跳变**,只有 0 和 1 两种状态。
- 例子:电脑里存储的数据、U 盘里的文件、光纤里传的光脉冲。
- 形象比喻:数字信号就像**电灯开关**——只有"开(1)"和"关(0)"两个状态,不存在"半开半关"。

| 对比项 | 模拟信号 | 数字信号 |
|--------|---------|---------|
| 取值 | 连续 | 离散(仅 0/1) |
| 抗干扰能力 | 弱(噪声叠加后就变样) | 强(只要分得清 0/1 就能恢复) |
| 存储/处理 | 难(磁带会磨损失真) | 易(复制多少次都一样,如 MP3) |
| 例子 | 老式电话、收音机 | 光纤通信、U 盘 |

> 💡 **为什么现代通信都爱用数字信号?** 因为数字信号"皮实"——路上被噪声"蹭"了一下,只要还能分辨 0 和 1,就能原样恢复;而模拟信号一旦被噪声污染,就再也回不到原样了(就像复印一份复印件,越复印越模糊)。

## 1.3 频率与带宽:车轮转速与水管粗细

**频率(Hz,赫兹)**:指信号每秒变化的次数。
- 比喻:车轮每秒转几圈就是"转动频率";扇叶每秒转几圈也是"频率"。
- 例:一个信号每秒上下起伏 1000 次,它的频率就是 1000Hz(1kHz)。

**带宽(Hz)**:指一个信道(或信号)能够通过的**频率范围**。
- 比喻:带宽就像**水管粗细**——水管越粗,单位时间流过"水"(信息)越多;信道带宽越大,单位时间能传的信息越多。
- 例:人说话音的频率范围大约在 **300Hz ~ 3400Hz** 之间,所以话音"带宽"约 4kHz(考试常取 4kHz 这个整值)。

> 🧠 **记住两个常用换算**:1kHz = 1000Hz,1MHz = 1000kHz = 1,000,000Hz。

## 1.4 数据速率与单位换算:比特和字节别搞混

**比特(bit,b)**:信息的最小单位,就是 0 或 1 这一个"格子"。
**字节(Byte,B)**:8 个比特组成 1 个字节。**1B = 8b**,这是必须刻进脑子里的换算!

- 比喻:bit 是"个"(1 个字符占 8 个格子),Byte 是"盒"(一盒装 8 个)。

**速率单位**:
- 小写 `b/s`(bps):每秒传输的**比特**数。如 64kb/s 表示每秒传 64000 个比特。
- 大写 `B/s`:每秒传输的**字节**数。如 256KB/s 表示每秒传 256×1024 个字节。

**⚠️ 关键换算(考试高频)**:
- `1B = 8b`(字节与比特)
- `1Kb = 1024b`(考试常用二进制换算:1K = 1024)
- 因此:`2Mbps = 2×1024 Kbps = 2048 Kbps`;再 ÷8 = `256 KB/s`

<details><summary>📖 点击查看答案与解析</summary>

# 模块二 数字化之路:PCM 脉码调制

## 2.1 为什么要数字化?

上一模块说过,数字信号抗干扰强、易存储。但现实世界的声音、画面都是**模拟的**(连续变化)。要把它们送进计算机,得先"翻译"成 0 和 1——这个过程就叫**数字化**。

**PCM(脉冲编码调制,Pulse Code Modulation)** 就是最经典的声音数字化方法,分三步走:

> 🎯 **一句话记忆**:PCM = **采样 + 量化 + 编码**。好比把一段连续的水流,先"连拍照片",再把每张照片"归类归档",最后"编号存放"。

## 2.2 第一步:采样 + 奈奎斯特定理

**采样(Sampling)**:每隔一小段固定时间,把信号当时的"值"抓取(记录)下来。
- 比喻:拍电影!电影每秒连拍 24 张照片(24 帧),连续播放就成了"活的画面"。采样就是给模拟信号"连拍"。
- 每秒采样的次数叫**采样频率**(Hz)。每秒采样 8000 次 = 采样频率 8kHz。

**奈奎斯特定理(考试重点!)**:
> **采样频率必须 ≥ 2 倍信号最高频率**,否则信号会失真(产生"混叠"现象)。

- 比喻:拍**旋转的车轮**。如果快门太慢(采样频率低),拍出来的车轮看起来在"倒转"——这就是采样太慢导致的假象。要看清车轮,拍摄速度必须足够快。
- 公式:**f_采样 ≥ 2 × f_最高**

## 2.3 第二步:量化(Quantization)

**量化**:把采样得到的"连续值"归并到有限的"等级"里。
- 比喻:体重秤。精确到 1kg 的秤,会把 62.4kg 显示成"62kg";精确到 0.1kg 的秤会显示"62.4kg"。**等级分得越细,越接近真实值**,但需要的存储空间也越大。
- 例:量化成 **128 个等级**、**256 个等级**……等级数都是 2 的幂,因为最终要用二进制表示。

## 2.4 第三步:编码(Encoding)

**编码**:给每个量化等级分配一个二进制编号。
- 128 个等级 → 需要 7 位二进制(因为 2⁷ = 128)→ 每个样本占 **7 比特**。
- 256 个等级 → 需要 8 位二进制(2⁸ = 256)→ 每个样本占 **8 比特**。

> 🧠 **口诀**:128 就是 7 位,256 就是 8 位(2 的几次方就是几位)。

## 2.5 PCM 数据速率公式(必考计算)

> **PCM 数据速率 = 采样频率 × 每个样本的比特数 = f_采样 × log₂(量化等级)**

**套公式三步走**:
1. 看采样频率(每秒采样多少次);
2. 看量化等级,算位数(log₂(等级));
3. 相乘,得 b/s。

## 2.6 小结:电话通话的完整数字化流程(把知识串起来)

以打电话为例,你的声音走完整个数字化流程:
1. 话筒把声音变成连续变化的**模拟电信号**;
2. **采样**:每秒抓取 8000 个瞬间值(8kHz);
3. **量化**:每个瞬间值归入 128 个等级之一;
4. **编码**:每个等级用 7 位二进制表示;
5. 于是每秒产生 8000 × 7 = 56000 比特,即 **56kb/s** 的数字话音流,送入网络传输。

# 模块三 线路上的编码:曼彻斯特编码

## 3.1 为什么要"再编码"?

PCM 已经把模拟信号变成了 0/1 数字序列。但在**线路上传输**时,还有个大问题:**接收方怎么知道每个比特从哪开始、到哪结束?**(即"同步"问题)

- 比喻:两个人敲鼓传信息。如果只规定"敲一下是 0,敲两下是 1",但双方节奏不一致,接收方就分不清"咚咚"到底是"两个 1"还是"一个 2 下组合"。需要约定一个**固定节拍**。
- 线路编码(如曼彻斯特编码)就是来解决同步问题的:让每个比特自己"带节奏"。

## 3.2 曼彻斯特编码原理:每个比特中间必有一次翻转

**曼彻斯特编码(Manchester Encoding)规则**:
- 每个比特的**中间时刻必定有一次电平跳变**(从高到低,或从低到高);
- 用这次跳变的方向表示比特值:如"高→低"表示 1,"低→高"表示 0(或相反,具体约定取决于标准);
- 接收方只要盯住"中间跳变",就能准确对齐每个比特——**数据自带时钟**,不用额外传同步信号。

- 比喻:跳舞时,**每拍中间都会"点一下头"**——这个"点头"既是动作的一部分,又帮所有人保持同一节奏。曼彻斯特编码就是让每个比特"边传数据边打节拍"。

**优点**:同步简单可靠(所以早期以太网用它)。
**代价**:传 1 个比特需要 2 个跳变/码元,效率打了对折。

## 3.3 编码效率为什么是 50%?

**编码效率 = 有效数据量 ÷ 实际传输码元量**。

- 曼彻斯特编码中,1 个比特需要用 2 个码元(或 2 倍时长)来携带(一个用于数据表达,一个用于保证中间翻转)。
- 所以效率 = 1/2 = **50%**。

> 🧠 **一句话记忆**:"曼彻斯特,中间翻转,效率一半(50%)"。
> 对比:普通不归零编码(NRZ)效率可达 100%,但没有同步能力,各有取舍。

## 3.4 拓展:差分曼彻斯特编码(了解即可)

- 规则:每个比特**中间仍要翻转**,但"比特值"不由跳变方向决定,而是看**比特开头**有没有跳变——开头有跳变表示 0,无跳变表示 1。
- 优点:抗干扰更强,不易受极性接反影响(常用于令牌环网)。
- 考试中见到"差分"二字,抓住关键词:**看比特开头是否翻转**。

# 模块四 多路复用:一条线路传多路信号

## 4.1 为什么要多路复用?

铺设线路很贵(尤其是长途光缆、海底电缆),如果一条线路只服务一路通信,太浪费。于是有了**多路复用(Multiplexing)**:让**多路信号共用一条物理线路**同时传输。

- 比喻:一条高速公路,不能只让一辆车跑——划出多个车道,许多车并行通过,路的价值才发挥出来。

多路复用有四种经典方式,考试让你识别,记住它们的"车道划分"方式即可:

## 4.2 频分多路复用 FDM(Frequency Division Multiplexing)

**做法**:把整段频率带宽划分成多个**互不重叠的频段**,每路信号占用一个频段,同时传输。
- 比喻:**收音机**!广播电台 88~108MHz 频段里,每个台占用不同频率(如 91.4MHz、97.5MHz),互不干扰,你调台就是在"选频段"。
- 类比生活中的例子:电视的多个频道、ADSL 上网+打电话同时进行。

## 4.3 时分多路复用 TDM(Time Division Multiplexing)

**做法**:把时间划分成一段段**时间片**,多路信号**轮流**占用整条线路。
- 比喻:**轮流发言**!会议室里 4 个人轮流用同一支话筒:你一句、我一句、他一句……每人轮流说一小会儿,大家都"觉得"自己在同时说话。
- 特点:各路信号分时共享,同一时刻只有一路在传。

## 4.4 波分多路复用 WDM 与空分多路复用 SDM

**波分多路复用 WDM(Wavelength Division Multiplexing)**:
- 用于**光纤**。不同颜色的光(不同波长)在同一根光纤里并行传输,互不干扰。
- 比喻:一根光纤里同时跑"红、橙、黄、绿、青、蓝、紫"七束光,每束光传一路数据。

**空分多路复用 SDM(Space Division Multiplexing)**:
- 每路信号用**独立的空间/物理线路**传输,靠"分开的路"来区分。
- 比喻:并排铺设的**多条电缆**,或者不同方向的无线天线波束,各走各的路。

## 4.5 四种多路复用对比表(考试速查)

| 复用方式 | 划分依据 | 比喻 | 典型应用 |
|---------|---------|------|---------|
| 频分 FDM | 频率(频段) | 收音机频道 | ADSL、广播电视、FM 广播 |
| 时分 TDM | 时间(时间片) | 轮流发言 | 数字电话(骨干网) |
| 波分 WDM | 光的波长(颜色) | 七彩光纤 | 光纤通信 |
| 空分 SDM | 空间/线缆 | 多条车道 | 多根电缆、多天线 |

# 模块五 性能计算:信道容量与时延

## 5.1 信噪比 SNR 与分贝 dB

**信噪比(Signal-to-Noise Ratio,SNR)**:信号功率与噪声功率的比值 S/N。
- 比喻:**在嘈杂餐厅里打电话**。你的声音是"信号",周围的喧闹是"噪声"。声音越大、环境越安静,听得越清楚 → 信噪比高;反之信噪比低。
- 信噪比常写成**分贝(dB)** 形式:`SNR(dB) = 10 × log₁₀(S/N)`。

**⚠️ 考试最常考的换算(务必记住)**:
- **30dB** → S/N = 10³ = **1000 倍**(因为 10×log₁₀1000 = 10×3 = 30dB)
- 换算口诀:**"dB 值除以 10,就是 10 的几次方"**:20dB → 100 倍,10dB → 10 倍,40dB → 10000 倍。

## 5.2 奈奎斯特极限(无噪声环境,了解)

在**无噪声**的理想信道中,带宽 W、每个信号取 V 个等级时,最大数据率:`C = 2W × log₂(V)`。考试以香农定理为主,此公式了解即可。

## 5.3 香农定理:有噪声信道的容量上限(必考!)

> **香农定理(Shannon Theorem)**:在带宽为 W、信噪比为 S/N 的信道中,最大数据传输率
> **C = W × log₂(1 + S/N)**(单位 b/s)

- 比喻:信道容量 C 好比高速公路的**"最高限速 × 车道数"**:
  - 带宽 W = 路有多宽(车道越多,能并行的车越多);
  - 信噪比 S/N = 路况好不好(路况越好,车敢开得越快);
  - 两者共同决定这条路**最多能跑多快**——这就是香农定理的物理意义。

**套公式四步走**:
1. 把 dB 换算成倍数:S/N = 10^(dB/10);
2. 计算 1 + S/N;
3. 求 log₂(1 + S/N);
4. 乘以带宽 W,得到 b/s。

> 🧠 **高频考点速记**:`30dB → 1000 倍 → log₂(1001) ≈ 10`。所以 `C ≈ W × 10`。

## 5.4 传输时延:传完一个数据包要多久?(必考计算)

**总时间 = 发送时延 + 传播时延**

- **发送时延(传输时延)**:把数据"装进线路"需要的时间 = **数据量 ÷ 数据速率**。
  - 比喻:快递**装车时间**——货越多、装车越慢。
- **传播时延**:数据在线上"跑路"的时间 = **距离 ÷ 传播速度**。
  - 比喻:快递**在路上的时间**——路越远、时间越长。
  - 考试默认值:电磁波在**电缆**中传播速度约为光速的 2/3,即约 **2 × 10⁵ km/s**。

### ✏️ 真题演练 11(题库 #3 · 时延综合题 · 原题缺答案,已补全)

**【单选】在地面上相距 1000 公里的两地之间通过电缆传输 4000 比特长的数据包,数据速率为 64kb/s,从开始发送到接收完成需要的时间为 ____。**
A. 5ms　　B. 10ms　　C. 62.5ms　　D. 67.5ms

<details><summary>📖 点击查看答案与解析</summary>

**答案:D**(本题目在原试卷中缺答案,另一份试卷(冲刺 200 题)给出答案 D,详见真题演练 11b)

**详细解析(分两步,缺一不可)**:

**第 1 步:发送时延**(数据装进线路的时间)
- 数据量 = 4000 比特;速率 = 64kb/s = 64000 b/s。
- 发送时延 = 4000 ÷ 64000 = **0.0625 秒 = 62.5ms**。

**第 2 步:传播时延**(数据在电缆中跑路的时间)
- 距离 = 1000 公里;电缆中传播速度 ≈ 2 × 10⁵ km/s。
- 传播时延 = 1000 ÷ 200000 = **0.005 秒 = 5ms**。

**第 3 步:总时间**
- 总时间 = 62.5ms + 5ms = **67.5ms** ✓

**干扰项排查**:
- C(62.5ms)只算了发送时延,**漏了传播时延**——最经典的丢分点;
- A(5ms)只算了传播时延,漏了发送时延;
- B(10ms)是随便凑的。

**结论**:选 **D**。核心公式:**"总时间 = 数据量÷速率 + 距离÷速度"**,两段时延一个都不能少。

## 5.5 扩展阅读:流量整形 vs 流量监管(题库 #10 · 真题了解)

题库中还有一道 QoS 题与通信性能相关:

**【单选】与流量监管相比,流量整形会引入额外的 ____。**
A. 时延抖动　　B. 丢包　　C. 负载　　D. 时延

<details><summary>📖 点击查看答案与解析</summary>

**答案:D**

**详细解析**:
1. **流量监管(Policing)**:发现流量超过约定速率时,**直接丢弃**多余报文 → 特点是会**丢包**,但不会额外排队。
2. **流量整形(Shaping)**:把超速的报文先存进**缓冲区(缓存)排队**,等线路空闲再慢慢发 → 特点是**不丢包**,但引入了额外的**排队时延**。
3. 题目问的是流量整形"额外引入"什么 → 答案是**时延**。

**一句话对比**:监管 = 硬性拦截(丢包);整形 = 缓冲平滑(等一等,多花时间)。
</details>

# 📐 公式速查表(考前必背)

| 公式/规则 | 表达式 | 记忆提示 |
|-----------|--------|---------|
| 字节与比特 | 1B = 8b | 1 字节 = 8 比特 |
| 速率换算 | 2Mbps = 256KB/s | Mbps → KB/s:×1024 ÷ 8 |
| 奈奎斯特采样定理 | 采样频率 ≥ 2 × 信号最高频率 | 采样要够快,两倍不嫌多 |
| PCM 数据速率 | 速率 = 采样频率 × log₂(量化等级) | 每秒样本数 × 每样本位数 |
| 量化等级与位数 | 128 级 = 7 位;256 级 = 8 位 | 2 的几次方就是几位 |
| 信噪比换算 | S/N = 10^(dB/10) | 30dB = 1000 倍 |
| 香农定理 | C = W × log₂(1 + S/N) | 带宽 × log₂(1 + 信噪比) |
| 曼彻斯特编码效率 | 50% | 中间翻转,效率一半 |
| 传输时延 | 总时延 = 发送时延 + 传播时延 | 装车时间 + 路途时间 |
| 发送时延 | 数据量 ÷ 数据速率 | 货多则慢 |
| 传播时延 | 距离 ÷ 传播速度(电缆约 2×10⁵ km/s) | 路远则久 |

# ⚠️ 常见误区警示

1. **Mbps 和 MB/s 混淆**——忘掉 ÷8。所有"大 B(字节)"换算都要 ×8 或 ÷8,如 2Mbps = 256KB/s,不是 2000KB/s。
2. **把"采样频率"和"信号最高频率"搞反**——采样频率是**最高频率的 2 倍以上**,不是等于。
3. **30dB 直接代入香农公式**——公式里要的是**倍数** S/N = 1000,不是 30 本身。
4. **认为曼彻斯特编码效率是 100%**——每个比特要 2 个码元(一半用于同步),效率只有 50%。
5. **算时延只算发送、漏掉传播**——1000km 的传播时延虽然只有 5ms,但加不加就是 62.5ms 和 67.5ms 的区别(答案完全不同)。
6. **FDM 与 TDM 混淆**——**频分**是"同时传、各占频段"(收音机);**时分**是"轮流传、各占时间片"(轮流发言)。ADSL 是"同时打电话+上网",所以是频分。
7. **PCM 题被多余条件干扰**——如"信号带宽 3400Hz"只是背景,数据速率只看**采样频率 × 位数**。
